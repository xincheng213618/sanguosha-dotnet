# 征程保存与对局记录

## 使用方式

只有山河图保留可继续的征程。身份、国战、活动、单骑无双等其他模式每次独立新开，完成后保留游戏记录，不创建或提供恢复对局的存档。

- 山河图外层准备页负责选将、配置山河册；进入小游戏后固定本次武将与行装。
- 山河图保存地图、选择、已完成战斗与领奖进度；牌桌的「保存进度」或 F5 可立即保存。未完成牌局的手牌、回合及操作不作为恢复点。
- 「返回战斗」可继续内存中的当前牌局；「保存进度并退出」返回大厅并丢弃本次牌局。下次使用「继续山河图」时，从当前关卡开头重新挑战。
- 战败或未通关不会结束征程：重试恢复进入本关时的体力、铜币、战法、技能、随身牌和装备。关内交易、消耗、重生次数等随本次尝试重置；之前已通关与领取的奖励保留。
- 每次挑战单独记录挑战次数并重新洗牌，不沿用上一次随机起手与后续牌序。桌面开战前可点击「随机换牌」，满意后点击「确定」；随身牌与已安装的装备保留。这些换牌操作只属于本次牌局，不写成可恢复对局。
- 小游戏内点击「结束征程」，可取消或确认。确认后记录为未通关，返回准备页重新选将；已获得的图册、收藏保留，不发放通关奖励。
- 结束命令先写入独立存档，成功后才切换界面。写入失败时保留原征程和当前战斗，可重试或取消。重启不会恢复已经确认结束的战斗。
- 已完成的其他模式仍记入历史战绩；战绩不是可以继续操作的牌局。
- 声音、动画和操作偏好由[本机偏好](PLAYER_PREFERENCES.md)独立保存。

## 文件结构与写入

默认目录为 `%LOCALAPPDATA%\CardGame\Saves`：

| 文件 | 用途 |
| --- | --- |
| `shanhe-campaign.json` | 山河图征程命令记录及待挑战关卡配方；不写入当前牌局 Checkpoint |
| `shanhe-campaign.json.previous` | 上一次成功替换前的征程备份 |
| `autosave.json`、`manual.json`、`Wushuang` 下的旧存档 | 历史兼容文件；当前游戏不读取、覆盖或提供续玩入口 |

征程先在同目录写入完整临时文件并刷新到磁盘，再替换正式文件并保留上一份备份；失败时清理临时文件。自动保存有短暂合并窗口，异常终止只能恢复至最近成功落盘的边界。

底层 [GameSaveFile](../src/CardGame.Wpf/Persistence/GameSaveStore.cs) 及其校验仍保留，用于历史格式、离线回放与诊断；它们不代表桌面继续开放普通对局存档。格式版本以所属类型的 `CurrentFormatVersion` 为准。

## Checkpoint 与回放

[GameCheckpoint](../src/CardGame.Core/Replay.cs) 包含：

| 字段 | 用途 |
| --- | --- |
| `SchemaVersion` | Checkpoint 结构格式 |
| `Options` | 种子、座位、模式选项、AI 策略及推进设置 |
| `Commands` | 按顺序接受的完整命令前缀 |
| `Revision` | 提交次数，必须与命令条数一致 |
| `ModeId` | 当前模式 |
| `ContentPackages` | 有序内容包 ID 与版本签名 |
| `ContentHash` | 内容定义的规范化指纹 |

结构版本以 `GameCheckpoint.CurrentSchemaVersion` 为准。`GameReplay.Restore` 先检查元数据完整性、结构版本、包签名和内容指纹，再创建独立引擎，按当前实现逐条提交命令。每条命令重新检查行动者、Revision、PromptId 和合法候选；回放结束还需匹配记录中的模式与 Revision。

随机序列、询问、候选、牌区、程序帧和父子结算由命令前缀确定性重建。存档保存的是可重放输入，运行中的结算栈不作为独立恢复入口。命令集合在接受时复制冻结，调用者或观察者不能事后污染已记录的选择。

`CreateCheckpoint` 要求健康会话全部由 `Submit` 驱动，且 Revision 与命令记录一致。直接通过兼容适配 API 推进的混合状态不能捕获为 Checkpoint。可信存档包含种子与私有命令，不属于可发送给其他玩家的快照。

## 恢复与失败保护

山河图按当前配置读取并重放征程命令，不因整份关卡配置指纹变化而拒绝读取，也不重建旧版配置。记录中的征程身份保留，用于校验已完成战斗的实际日志、任务与奖励；牌局本身仍执行命令和配方校验。节点缺失、命令无效、重放失败等实际错误会重置到出征准备页，确认新出征前保留原文件。

不对旧失败日志裁剪命令或自动回退；正常读取成功的已结束征程保持结束。

底层兼容加载器仍检查本地座位、模式、人数和速度选项，供离线回放检查与诊断使用。相关测试通过专用夹具加载 Checkpoint，不依赖已经取消的桌面恢复按钮。

规则执行异常会停止会话。诊断报告在独立目录保存最后可信命令前缀和失败命令，参见[异常日志与复现材料](EXCEPTION_REPORTS.md)。

本地文件替换和备份不能提供跨进程共同写入同一槽位或断电后的文件系统保证；当前恢复以实际通过结构、内容和命令校验为准。
