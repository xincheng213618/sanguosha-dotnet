# 单骑无双 · 单机 AI 版

单骑无双是一场独立的 1v1。山河图则是多关闯关：沿路线收集山河策、解锁战法并配置初始构筑，后续迎战更强敌人。两者可以复用已实现的战法规则和界面素材，但货币、商店价格、成长与存档分别管理；单骑不使用山河图的银两、山河策或征程解锁条件。

## 本地规则与流程

模式 ID 为 `wushuang:solo`。玩家与一名 AI 公开敌对，复用现有选将、响应、结算与实体牌移动系统。

| 环节 | 本地实现 |
| --- | --- |
| 先后手 | 随机决定；先手 4 张、后手 5 张。不模拟叫分、付费豆子和 OL 账号资源。 |
| 初始战法 | 正式出牌前从随机 3 个候选中免费选 1 个。必须选择，15 秒未操作由本地主机选择首项。 |
| 起始虎符 | 0；每个自然回合开始双方各得 1，新一轮开始双方另得 1。额外回合不另发基础收入。 |
| 经验 | 无经验、无商店等级和付费升级；商品 `level` 指品质。旧快照相关字段保留为固定兼容值，不参与规则。 |
| 购买阶段 | 每个自然回合结束、结束阶段及其子结算完成后开放，双方依次处理；玩家 20 秒，AI 自动购买。额外回合不另开商店。 |
| 商品栏 | 从当前可用的技能、战法、卡牌商品中混合随机抽取 4 个，不固定类型数量或顺序；商道增加一个随机商品展示位。可连续购买本页不同商品。官方服务端权重未知，本地按可用商品条目等权、不重复抽取。 |
| 刷新与锁定 | 购买结束准备下一页；回合中可预览，回合结束的购买窗口开放同一页。手动刷新优先消耗免费次数，次数耗尽时花 1 虎符；锁定保留整页及已售位置，手动刷新仍换页并保留锁定开关。 |
| 技能槽 | 原武将技能不占槽；额外技能初始最多 2 个，满槽购买需先明确选择替换项。战法、卡牌不占槽。运筹帷幄增加 1 槽；一忘皆空允许替换初始技能。 |
| 购买结束 | “结束”、Esc 或 20 秒超时提交结束购买，继续牌局；购买期间不能绕回出牌询问。回合中的预览只显示下一页，不允许购买、刷新或锁定；免费商品使用绿色按钮，虎符不足的价格标红，技能满槽显示“已满替换”。 |

战法表保留 194 条来源记录，购买价格和商品品质取 `hd_1v1_rogue.Tactics`；共享肉鸽表只提供名称、效果与关联编号。单骑禁用其中 18 条：护甲、铁布衫各版本、隔山打牛、剔甲术、依赖借刀杀人的巧取豪夺，无距离规则下无收益的关刀之脊、远击技、妙手空空，以及只增加目标数的横江锁、双刃和双刃Ⅱ。初始奖励与普通商店共同使用准入限制；不会通过武将原技能或额外获得技能继续叠加护甲。基础防具的减伤、判定与回复仍有效，山河图的护甲规则保持不变。以“游戏开始时”“开局”开头的其余战法只进入初始奖励池；获得牌等子结算返回后不会再次支付或发放。

本地单骑平衡另移除稳定体质 `2020` 和体魄Ⅲ的开局版 `2056`、普通商店版 `2263`。稳定体质以一虎符固定七点体力上限，体魄Ⅲ一次增加三点体力上限并回复三点；免费开局和二十行动回合按当前体力判胜会放大这些数值优势。体魄的一、二阶成长继续保留。原始商品资料、原生技能及明确的旧配置机制检查仍保留，平衡禁售不把已拥有的技能当作无效绑定；数值护甲等原有严格准入限制维持原样。

红色品质（`Quality=4`）不再进入免费开局奖励。抽样在完整候选上使用原生随机顺序，再过滤并补足三项合格奖励，双方与 AI 使用相同候选规则。普通商店仍可出售未被单独禁售的红色战法，开局专属的红色条目不会挪到普通商店。该项属于本地模式平衡，不改变来源表价格、效果或其他玩法。

技能表共有 218 条商品记录，217 条有完整官方名称、正文及版本身份，按 `spellId` 绑定可执行版本，使用各自虎符价格和品质；不再统一为经典技能和 2 虎符。同名版本中的关键差异包括：豹变获得界挑衅与界神速、节命摸至体力上限且至多五张、旧奇谋不摸牌、魂姿觉醒回复一点体力、严整以装备区牌转化无懈可击。商品 `3337` 关联的 `spellId=3596` 在同一客户端配置中只有索引，没有名称和规则正文，保留原始空值并禁止上架，没有用相似技能填充。

可执行绑定保存在 `src/Activities/Wushuang/Content/runtime-bindings.json`，新增规则位于同目录的 `Skills/`，其他技能复用准确版本的现有规则。规范化商品配置与绑定共同参与单骑内容指纹，价格、版本或绑定变更均会改变该模式内容哈希；仅刷新核实时间或无关来源元数据不改变内容指纹。复现来源的脚本为 `tools/sync_wushuang_reference.py`；脚本只抓取公开客户端资源并保存规范化配置及各层 SHA-256，不将解码中间文件写入仓库。

模式准入另存于 `src/Activities/Wushuang/Content/eligibility.json` 并参与单骑内容指纹。技能商店排除离间、求援、乱战、誓仇、完杀、连破、征南、托孤及暗箭九条没有单挑收益或需要第三人的条目。观虚、攻心，以及仍有单挑收益的利驭、福绵、神戟等保留，不因正文提到多目标就整条删除。技能的模式限制也用于实际绑定，额外获得技能不会绕回已禁用的护甲能力。

卡牌资料保存 121 条来源记录，其中装备 41 条；来源存在不代表在单骑开放。当前正常商店只提供 89 条（76 条手牌、13 条基础武器与防具商品）。宝物、坐骑、修罗炼狱戟、刑天破军斧等特殊扩展装备及四种花色的借刀杀人不上架；共用规则和其他模式中的这些装备不删除。价格、品质、花色、点数使用单骑条目；装备购买后直接装备，离开装备区时销毁，费用支付、牌移动与冷恢复沿用统一原生结算。作为转化、弃置或储存费用时，按本次真实销毁记录结算一次，不重复移牌，也不会凭空产生储存牌；转化出的即时效果及响应继续处理，延时锦囊的原实体已经销毁时不能再置入判定区。手牌购买日志只公开“一张手牌”，不泄露对手购买的具体牌。

单骑使用独立的 `wushuang:duel-deck`，从经典军争逐张牌堆移除所有进攻、防御坐骑和借刀杀人，保留其余牌的花色、点数和数量；奇策等技能的普通锦囊选项也不提供借刀杀人。依据包括[入门攻略](https://www.taptap.cn/moment/572241938573428721)的无坐骑牌堆与额外装备说明，以及本次用户实测修正。按用户确认的无距离规则，双方战斗距离固定为 1，义从等距离增减不再阻止使用杀、顺手牵羊或兵粮寸断；其他模式的距离规则保持原样。

将池按具体版本排除辅助型及依赖数值护甲的武将，不整包禁用标准、风或界限突破。吕蒙、孙权及截图确认的界张角保留；全局武将库不受单骑排除影响。用户提供的截图中可辨认名单及待实现版本见 [将池实现核对](WUSHUANG_ROSTER_AUDIT.md)。截图中的“未开通”、个人禁将、招募与强制开启状态不构成本地限制。

已拥有的技能和同编号战法不会重复进入候选。单骑的同名战法按商品编号绑定，例如关公刃 `2045` 为红桃杀伤害 +2，不使用共享表中同名 `2046/2047` 的 +1 版本。AI 使用同一资源、价格和技能槽约束，按实际能力、手牌配合、当前生存压力和替换代价选择；同一窗口可连续购买，必要时有限刷新或锁页储蓄，不再只按战法价格排序。兵权Ⅰ自己的自然回合额外获得 1，兵权Ⅱ每个自然回合额外获得 1，兵权Ⅲ将自然回合收入翻倍；持久战Ⅱ在虎符历史数量达到 5 后增加每回合收入。轮次基础奖励单独发放。免费刷新累计次数、原技能替换及扩展槽位均由原生商店命令恢复。

## 范围与尚未复现部分

技能 3596 因官方缺失正文暂不可用；没有准确可执行绑定的卡牌不参与抽取。客户端另有“进入激战阶段，每回合获得虎符增加”的文本，但未核实激战触发轮次与数值，本地暂不臆造该阶段。尚未核实 OL 当前逐张牌表和完整活动武将池；不将当前配方、本地抽取权重或本地平衡排除项声称为服务器原表。

全局限时 15 分钟，商店和思考期间继续计时；经过时间由主机命令记入日志，离线时间不补计。时间或配置的回合上限到达后，比较双方当前体力：较高者获胜，相同才和局；不比较体力比例、体力上限、手牌或虎符，让防御与回血也能争胜。超时关闭未完成子结算，已经支付的牌不重复支付或退回。AI 自动对打按用户要求使用20个角色行动回合上限，按胜 1、和 0.2、负 0 计算收益，单独报告击杀胜及体力判胜；平局只提供低收益保底。

稳定承载与信手拈来以体力上限替换手牌上限的基础值；急攻等当回合明确设定优先覆盖该基础，其他正常加减修正仍保留。

商店 AI 对已知手牌上限修正按购买前后的实际容量差估值，保留 Set 优先级、加法及零下限；已有同类设定时不重复计收益，满技能槽替换也扣除失去的容量收益。受伤且确实需要保留更多手牌时，提高有效容量的购买价值。

AI 决策策略 11 专门识别双方公开的无双战法，包括固定伤害、有限减伤和反伤：避免无效攻击或非终结的反伤自杀，有足够独立实体杀与出杀额度时仍可消耗有限减伤。商店只读取本座位的商品及玩家视角，对方隐藏手牌和商店不参与决策。 丈八等组合操作先选择同时满足当前材料限制和目标限制的完整牌组，再选择兼容目标，避免把不同牌组的合法目标混用。公开局势明显不利时提高持续防御的购买价值，临近时限降低长期经济的收益；仍保留当前可用的进攻和终结机会。 摸牌能力按原生规则计算购买前后的实际增量：将摸牌数设为5只比基础2张增加3张，已有加法、优先级和替换损失也一并计算；未知条件或相互冲突的假想组合不会被当作确定收益。

打法随当前本体技能、已购技能、战法和手牌变化：受伤后能稳定补牌的构筑重视安全血线及回复，杀有增伤或封牌能力的构筑重视独立杀、酒和及时爆发。新增、替换或失去技能后重新估值；濒死收益按实际救援机会折扣。受伤换牌只考虑已知、安全的小额普通伤害，临近到限时优先当前体力结果。当前页没有有效购买时可以支付 1 虎符刷新；急缺救援或爆发组件时最多付费刷新两次，并保留相应购买预算，普通搜索只刷新一次并保留四虎符。遇到适配但尚未买得起的商品会优先锁页，满技能槽的有效替换也可储蓄；健康时最多等待四个行动回合，低血线时最多两个，期间按实际虎符和构筑重新判断，临近到限不再等待长期商品。

策略 12 进一步区分技能实际受益者、互斥选项、判定结果的期望及已知后续费用。对手控制的选择按对自己不利的分支估计，不能把回复对手算成自己的收益，也不把四种判定花色当作四份固定收入。单挑中没有第二名连环角色且没有当前技能联动时优先重铸铁索；已有独立合法杀、公开空手目标及可靠斩杀增量时，可先装备古锭刀再出杀。准备动作只选当前合法装备操作，结算后重新判断，不承诺对手的未知响应。策略 11 及更早版本保留各自原评分路径，用于旧局回放与配对比较。

横江锁及双刃／双刃Ⅱ只增加目标数，在双人局没有额外收益，从本模式商品中移除。将池新增排除经典公孙瓒（只有纯距离义从，界版保留）、文聘·OL（镇卫需第三人）、界朱治·移动版（安国只救援对手）、步骘·OL（队伍局没有反贼，定叛次数为零）、经典步练师（安恤需第三人，追忆不能救自己）、关索·OL（击杀后成长及纯距离技能无收益）；全局注册及其他玩法不受影响。

按用户的玩法偏好，鲁肃各版本整体移出单骑将池，包括经典、界、移动版（`mobile:lu-su`）、谋、欢乐神鲁肃、移动神鲁肃和势鲁肃七个版本；这是本模式的选将取舍，不表示这些版本的技能全部失效。已发现的定州与相关结算问题仍修复并保留回归，其他模式继续提供这些武将。

欢乐神大小乔使用两套独立体力池，没有单一“当前体力”，暂不进入单骑将池。身份与商店等纯信息查询保留未定义体力，不替姐妹默认选池、求和或取最小值；单骑到限判胜也不为这种构筑臆造比较规则。

本轮另排除兀突骨·OL和王双·OL两个具体版本。前者十五点基础体力在当前体力到限判胜中形成过大的起点差距；后者追猎依赖攻击范围外目标，固定距离一使其主要分支无法生效，八点体力也偏离普通构筑。其全局定义、燃殇的火焰弱点及其他模式的追猎规则保留，普通神将与受伤收益玩法继续开放。

策略 13 在只剩一次普通出杀、有独立非斩杀杀和无中生有时，优先摸牌扩展当回合选择；已经公开可斩杀、酒效果、必要救命和可靠装备斩杀仍保留原优先级，不预知摸到什么牌。英略按实际受益者一起计算失去体力、下次摸牌和下次弃牌阶段手牌上限的代价，商店购买与出牌选人使用同一净值；临近回合或时间上限时降低尚未兑现的收益。

## 存档与验证

单骑自动与手动存档在 `%LOCALAPPDATA%\CardGame\Saves\Wushuang`，与普通对局和山河图分开。初始选择、购买、锁定、刷新、获得战法和计时均由原生命令与所属结算帧恢复；按玩家视角投影，私有商店不会暴露给对方。

针对性检查使用现有名称过滤器 `Wushuang mode`、`Wushuang pools`、`Wushuang skills`、`Wushuang combat`、`Wushuang UI`；例行检查由 `tools/Test-Changed.ps1` 选定范围。完整检查只在用户明确要求时运行。
