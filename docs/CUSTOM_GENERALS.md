# 自定义武将与可视化技能编辑

在大厅左侧点击“自定义武将”，或点击牌桌顶部“自定义”，打开本地武将库。可新建、复制、编辑、停用和删除武将；修改在点击“保存武将库”后生效。

## 创建武将

1. 点击“新建”，填写姓名、势力、性别和体力；可另外指定初始体力，并从现有武将选择头像。
2. 搜索已有技能并勾选。相同技能名可能对应不同版本，请结合版本编号与完整规则描述选择。复用的是原技能实现及其发动条件。
3. 也可添加自捏技能，设置名称、发动时机、条件、目标、每回合次数及效果。
4. 查看自动生成的规则预览，修正界面列出的错误，再保存。Ctrl+S 保存，Ctrl+N 新建。
5. 开始新的普通身份对局，在“自选武将”的“自定义”分类中选择。支持五人、八人及八人双将身份对局。

## 自捏技能

可视化编辑生成真实可执行规则；无需写脚本。可选主动出牌阶段技能，或回合开始、出牌阶段开始／结束、回合结束、造成／受到伤害后的触发技能。条件可选无附加条件、已受伤、没有手牌或体力不高于指定值；目标可选自己、一名其他角色或任意一名角色。

每个技能可以顺序组合摸牌、回复体力、造成伤害、失去体力等效果，并分别设置数值；伤害可以选择普通、火焰、雷电或冰冻属性。效果按界面中的顺序结算，前面的真实摸牌、伤害等结算完成后才执行后面的效果。触发技能可设置为自主发动或必定发动。

当前编辑范围为每名武将至多12个技能、体力1至20、每技能1至8条效果、每条数值1至10、每回合1至10次。预览由实际编译的规则生成；编辑器未提供的复杂专属机制仍可通过选择现有技能复用。

## 保存和对局

武将库保存在 `%LOCALAPPDATA%\CardGame\custom-generals.json`。成功替换前会完整验证，旧文件保留为 `.previous`；读取失败会明确提示，不会自动覆盖。

保存库不会改变已经开始的对局，也不会改动当局技能或头像。新的普通身份对局使用保存后的库；停用或删除的武将不会再进入新局。正在进行的对局及其存档携带创建该局时的自定义内容快照，因此之后编辑、删除本地库，仍能按原技能恢复该存档。

自定义内容仍参与普通内容指纹及命令验证。篡改或缺少当局内容的存档会被拒绝，读取失败时原存档继续保留。自定义内容不加入国战、活动专属选将或联机房间的固定名单。
