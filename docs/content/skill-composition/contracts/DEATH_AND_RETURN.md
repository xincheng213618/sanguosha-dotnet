# 死亡与返场

死亡帧从原生伤害濒死、体力上限归零或技能直接死亡的对应父帧返回。它保留死亡时的体力、击杀归属和本次是否进入休整。直接死亡保留原体力，且不进入求桃窗口。体力上限归零会将体力置零，也不进入求桃窗口。

角色的休整资格在进入死亡结算时锁定。当时需要具备正数体力上限。依赖技能的休整规则读取原有技能授予和当时的有效性。这一判定先于死亡引起的技能期限结束。之后仍清理牌区、发布死亡事实并处理相应触发。休整跳过身份揭示、击杀奖惩及本次胜负判定。其他角色随后永久退场时，胜负规则仍把等待返场的座位计入其阵营。

休整中的角色暂时离场。常规目标、席距、救援和额外回合继续使用在场资格。正常回合游标保留休整座位，轮到该座位时按当前体力上限恢复体力并返场。返场发生在该正常回合的开始前，恢复入口通过原命令记录重建。

`causeOwnerDeath` 可作为 `turnBeforeStart` 或 `afterTurnEnded` 的独立拥有者触发效果。执行器核对原实际回合窗口、拥有者和技能绑定，死亡作为原技能结算子帧返回。该操作适用于【亿金】的无金死亡和【殁亡】的回合结束死亡。

开局资源各自由发放它们的技能保管。十常侍的未使用储备随休整保留，返场时由【党锢】结党。取得技能本身不会重新发放开局储备。

【殁亡】要求仍拥有【党锢】且自身有效。已发放的当组技能在【党锢】暂时失效期间保留，永久失去【党锢】或死亡时回收。返场结党按届时的【党锢】有效性判断。

【追思】要求目标已永久退场，读取其主副将印刷的非主公技能。同一死者只能被追思一次。获得方保留原有的用量与已发行效果。开局标记与临时授予仍由原规则保管。

规则依据见[经典规则集的死亡定义](https://gltjk.com/sanguosha/rules/glossary/flow.html#死亡)、[移动版十常侍](https://www.sanguosha.cn/index.php/hero-detail-554.html)、[常侍技能发布说明](https://www.sanguosha.com.tw/newsinfo_1073.html)和[追思修复公告](https://www.sanguosha.com.tw/newsinfo_1410.html)。
