# 界黄忠、界魏延规则与工程裁定

项目选定的普通 OL 正文及补充解释见[来源档案](https://github.com/xincheng213618/sanguosha-dotnet/blob/77ab25557053b2e6c1033af6c6f392484c5b71dd/docs/content/sources/fenglin-thirteenth-2026-10-02.json)。人物资料绑定 boundary:liegong-current、boundary:qimou-current，并复用 boundary:kuanggu。

## 烈弓

slashRangeFromEffectiveRank 只替代具体实际杀的普通范围项：正有效点数按本杀点数计算，玩家通用攻击范围保持自己的查询值，明确距离豁免仍有效。真实丈八转换使用两材料点数和、上限 13 的工程约定；其他无点数杀沿普通范围。

最终目标窗口在原费用之后冻结双方手牌数与体力。一次可选发动分别判断：目标手牌不多于使用者时防止抵消；目标体力不小于使用者时本目标伤害 +1；两项均满足时同时执行。

每个目标的凭据保存在 CardUseFrame，包含动作、实际使用者、目标和指令来源。多目标各自判断；增伤只在原目标伤害应用一次，连环传导不再增加同一份。已发事实保留原对象，目标死亡或移除不转赠。

防止抵消保留真实闪、转换闪、八卦及代供的支付和响应子窗，再使抵消失败。防具使杀无效、其他免疫与伤害防止仍按自身规则处理。

## 奇谋

chooseOwnerHpLoss、drawPaidHpLoss、grantPaidHpLossDistance、grantPaidHpLossSlashLimit 组成有限四步。正式出牌阶段激活消费整局额度，数量选择为 1 至当前体力。

原程序在真实体力应用后、规则及救援子窗前冻结实际损失 X。救援和摸牌子窗完成后仍读同一凭据，分别执行摸 X、距离 −X 和杀次数 +X；两个修正保留各自指令与真实账本关联，X 由实际损失决定。

付款前检查来源有效；付款后同实际回合的精确已付尾段允许存活拥有者完成收益，来源失效不重复付费。死亡或终局终止剩余收益。已经发放的本回合修正在原实际回合结束时到期，额外出牌阶段沿用，额外回合不继承已过期修正。

配置与入口见[当前技能配置](RUNTIME.md)，帧和父返回见[结算协议](../../RESOLUTION_PROTOCOLS.md)。

## 工程裁定

依据当前普通 OL 官网[界黄忠26](https://www.sanguosha.com/hero/26)、[界魏延456](https://www.sanguosha.com/hero/456)完整正文；原文、API元数据、HTTP UTC及原始立绘SHA见[来源档案](https://github.com/xincheng213618/sanguosha-dotnet/blob/77ab25557053b2e6c1033af6c6f392484c5b71dd/docs/content/sources/fenglin-thirteenth-2026-10-02.json)。API无gender字段，男性沿仓库已有同角色定义；initial_hp零值不作游戏实际初始体力。

烈弓只改变具体杀的范围：正有效点数替代该杀普通范围，既有明确无距离限制资格保留，玩家通用攻击范围不变。2016官网托管[黄忠攻略](https://sanguosha.com/news/20161026_7095_5710)明确标为自编FAQ，其丈八两牌点数和上限13只作为真实丈八转换的有限参考。当前正文未说明其他无点数杀，沿普通范围为工程默认，不从任意多成本牌求和或最大值。当前正文优先，历史攻略的不能响应与当前不能抵消不可互换。

指定目标后采用现真实finalized窗口，流离后最终目标分别固定双方HP/手牌，杀已经支付。一个可选发动按两条件分别生效：手牌条件防抵消、HP条件伤害+1，同时符合两项一起执行。多目标各自receipt、各自增伤，不把一名目标条件授予全体；链伤不再多一份增伤。当前正文未给完整多目标/timingFAQ，这些是工程解释。

不能抵消保留真实闪、八卦及代供响应的支付和子窗，再令抵消失败；不能使用闪或不能响应是另一语义。防具/技能原有无效与免疫不自动被烈弓穿透。增伤、酒、白银狮子、藤甲、减伤与转移继续走成熟结算。

狂骨复用已有逐实际伤害点、伤害时距离冻结的boundary:kuanggu，不变成旧只能回血定义。奇谋整局一次，实际出牌阶段本人发动，选1..当前HP；范围参考2016官网托管[魏延攻略](https://www.sanguosha.com/news/20161026_9772_0011)的自编FAQ，不能称当前正式FAQ。旧攻略奇谋没有摸X张，当前456正文才是当前完整效果依据。

X在本次真实体力apply后、规则事实与救援/HP/gain子窗之前固定，按实际loss摸X，不用救援后HP差或先前损失。四段有限序列为付款、摸牌、减距、杀次数；各自只执行一次。活着的付款者在精确同实际回合已付tail内来源失效仍完成收益，真实死亡则终止剩余收益，为明确工程默认；已发回合修正来源失效不撤销，实际回合结束到期。额外Play保持修正与整局限次，真正额外回合不继承已过期修正。
