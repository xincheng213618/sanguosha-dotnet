# 公共结算与表达式抽象

日期：2026-10-30。基线为 `cd7912641`，承接[数量表达式首批迁移](AMOUNT_EXPRESSIONS_MIGRATION.md)。本批完成的是可复用的窗口协议、帧内数值/牌集合读取，以及公开牌堆选择和分配组合；独特的付款、用牌修改及私选协议继续由其原生操作负责。

## 窗口协议推广

把严格相同的五窗口链集中到已有 `TryBeginProgramChildWindows`：回复替换 → 武将状态 → 体力变化 → 牌移动 → 技能变更。

- 迁移 **167 个方法、167 个人物 Runtime 文件**，其中 `AwaitedProgramMovement` 120 个、`Program` 47 个；加上原试点，共 170 个包装入口。
- 只接受按值 `long` 或不可变程序帧 `.Id`，五个调用参数完全一致、两个续接种类相同的表达式方法。
- 每个迁移以当前公共方法展开并替参后，逐 token 与原表达式比较；方法体以外的字节保持原样。严格同形内联链剩余零个。
- 94 个不符合项不改：顺序不同 73、参数/续接或额外语法 17、窗口增删或不同 4。不以名字相近为由改变规则顺序。

该批生产 C# 净减少 **42,713 UTF-8 字节**，统一 LF。没有新增状态、事件、注册或回放字段。共同顺序的窗口修改集中于一处；其他顺序仍由其原机制控制。

## 共用表达式与原帧状态

继续使用 `ProgramExpressions`，没有另建解释器：

| 能力 | 语义与边界 |
| --- | --- |
| `when(bool, int)` | 条件为真才取整数，否则未知；用于明确保留“有体力值才计算”等旧资格 |
| `onUnknownAmount: cancelBinding` | 未知时走原整绑定取消、`Completed=false` 和清理路径；默认仍跳当前步骤 |
| HP 依赖查询 | 取消型数量和 `captureNumber.valueExpr` 的实际 HP 读取沿原帧询问独立体力池，冷恢复不重付、不重算 |
| `revealTopCards.amountExpr` | 保留原公开展示、移动原因和结果绑定；未知须取消整绑定，已知零仍创建空集合 |
| `captureNumber` / `number` | 不可覆盖的帧内命名整数，允许零和负数；原生复合动作也可声明同样的输出 |
| `boundCount`、花色/单牌元数据 | 只读已生产的集合；不消费实体，不把分配后的剩余集合当作原集合 |
| 加载期资源验证 | 读取必须有前置生产者，数值/牌集合/选择等结果名不能冲突，消费仍沿既有别名和支付检查 |
| AI 取消路径 | 未知冻结或 `cancelBinding` 停止估算后续收益，保留已发生的成本和收益；默认 `skip` 继续后续步骤 |

数值和游标均留在原帧，签发事件与帧、玩法哈希、指令及来源精确匹配。玩家视图继续由 `CreateSnapshot(viewerSeat)` 准备，绑定及可信诊断帧不直接变成玩家数据。牌面读取遵循公开或拥有者可知的绑定；AI 对未知牌面保持未知。

没有提高规则 schema、包版本、全局规则 epoch，也没有改变 checkpoint、命令或回放格式。`damage` 按前一阶段约束保留原协议。

## 冻结事实条件

`boundary:fuli` 的入口阵营数与伤害历史使用同一帧内命名整数，原回执只保留父帧、游标和已发摸牌状态。末步变为通用 `turnOver` 与冻结数值比较，原特殊摸牌原因 `program.frozen-faction-recovery.draw` 保留，翻面的一次性由指令游标保证。

删除 `TurnOverIfFrozenFactionCountExceedsGameDamage` 的枚举、描述符、处理器和运行方法：专用片段毛删除 2126 字节；扣除新增资源声明等，该机制及枚举净减少 460 字节。保留旧 AI 翻面先验，避免改写带来无意的评分变化。规则事件和翻面效果不变，普通日志措辞统一为通用的“翻面”。

真实对局检查在回复与摸牌子结算中改变存活阵营和伤害历史，仍按入口的冻结值决定正反两种翻面结果；四个实际获得牌实体都经过原子窗口，并在两处冷恢复后各完成一次。

## 选择绑定与循环分配

经典和移动通博改为：交换 → `selectPublicPile` → 带绑定表达式条件的 `distributeBoundCards`。来源技能、容量和受益者类别以参数提供，两版共用同一套公共处理，不添加版本专属分配器。

先选择确切来源再读取花色。`boundSuitCount` 排除 `Suit.None`；为保留旧通博包含 None 的 distinct 判定，使用 `boundDistinctSuitCount == 4`。实际覆盖普通四花色，以及三种真实花色加 None 的旧边界。

分配复用原 `ProgramPublicPileDraft`、公开牌堆 action、逐张私选、原移动原因和父帧返回。条件只在发行时判断一次，已付款子窗口结束后按原游标继续剩余实体，不再重评门槛。只接受原始公开堆选择输出，禁止任意手牌/Processing 绑定与重复消费。

选定实体及花色有新的精确签发事件和帧证明，集合由 `CommittedEventProjection` 冻结；既有选牌冻结证明保留原限制。真实签发事件的两个集合均验证只读及观察者不能改写历史。没有假设实体花色永远不变，避免生成牌换面后错误重算。

公开堆原本已有公共状态机，本批是使其可组合。旧 If 描述符/处理器毛删除 587 字节，新选择、绑定化分配及来源证明等六个生产文件净增加 13,752 字节。这个成本与窗口链删除分别报告，不能混作净减少。
