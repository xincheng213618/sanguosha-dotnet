# 数量表达式迁移记录

日期：2026-10-30；源码基线 `07d54975a`。这是 [运行时表达式](RUNTIME_EXPRESSIONS.md) 的数量阶段，后续还有绑定读取、受控随机与循环、跨版本参数化。每一阶段先确认等价、实施小批次，再用实际行为与回放验证；不按枚举名字批量替换。

## 本轮能力与边界

复用 `ProgramExpressions` 的类型树、解析与只读求值，为 `draw`、`recover`、`loseHp` 增加 `amountExpr`，与 `amount`、`numberExpression` 互斥。未知跳当前步骤，负数归零；不开放 `damage` 或 `revealTopCards`。新增通用 `handLimit` 读取和 `floorDiv` 运算，没有人物专用事实。

正数只在实际步骤开始时求一次，复用原帧 `NumberBindings` 和游标签发记录。真实摸牌、回复、体力变化及濒死子返回验证已签发金额，不能在子结算改变事实后重算。通用表达式树在加载时复制并冻结参数集合；未提高规则 schema 或包版本，未修改 checkpoint、命令或回放格式。

AI 沿同一求值器读取公开上下文，保留原有装备数量事实。原 `FourMinusHandCount`、`HandLimitMinusHandCount` 未在旧 AI switch 中处理，会回落为零；本次同步使它们按实际表达式估值，并验证前一步摸牌对后一步估算的影响。这是显式的估值一致化修复，实际游戏行为仍按原规则。
