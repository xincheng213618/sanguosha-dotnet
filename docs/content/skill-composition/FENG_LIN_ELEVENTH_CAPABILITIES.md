# 界甄姬、界黄月英规则与工程裁定

项目选用的普通 OL 正文与工程默认见[来源档案](../sources/fenglin-eleventh-2026-10-02.json)。内容由对应人物的 boundary 资料、规则和展示注册。

## 洛神

boundary:luoshen 使用 repeatJudgment，并保留 skill.luoshen 判定原因。最终判定结果冻结花色、判定 ID 和实体；只有实际由该判定移入拥有者手牌的实体才获得本实际回合的精确牌号手牌上限豁免。

豁免凭据记录实际回合、受益者、实体、判定及移动事实；被改判换下、未入手、被其他能力取得或移去游戏外的牌不会制造豁免。已实际获得的奖励按本回合期限保留。离手再回到原受益者时仍有效，在其他角色手中不享有该豁免，这是工程默认。

原判定程序、Judgment、最终结果窗口及其直接收益程序按相邻父链核对；合法死亡和实体清理也由精确帧关系返回。暂停不重复判定或领取。当前 AI 对 ActualTurn 豁免的重复判定使用公开取牌先验，不读取未观看牌堆或消耗随机数。

## 集智与奇才

boundary:jizhi-current 的 requireNoCardConversion 检查被冻结动作的完整转换链，覆盖普通及延时锦囊和真实无懈使用。重铸、单纯打出、延时牌传递及后续判定不构成再次使用。

集智先绑定本次实际摸牌，再提供保留或弃置选择。只有本次仍可用的基本牌真正弃置，才发本实际回合手牌上限 +1；原有手牌和其他获牌不能替代收据。

boundary:qicai-current 按实际弃置者、实体原区及 Discard 意图保护本人装备区的防具和宝物。获得、转移、替换、本人费用和死亡清理按各自意图处理，不能只看目的地为弃牌堆就判断外方弃置。

卡牌选择生产者将实际选择者冻结在绑定的 SelectionActorSeat；过滤和子集沿用该事实。SelectOwnedCards 与 SelectSourceCard 分别保留其真实决定者，MoveBoundCards 的弃置以该选择者校验。选择、支付和移动前复验当前保护，实际费用及返回仍属于原程序帧。

配置与入口见[当前技能配置](RUNTIME.md)，返回权限见[结算协议](../../RESOLUTION_PROTOCOLS.md)。

## 工程裁定

依据当前普通三国杀 OL 官网[界甄姬444](https://www.sanguosha.com/hero/444)与[界黄月英441](https://www.sanguosha.com/hero/441)完整技能正文，来源时间、原始字节 SHA、结构化体力与原始立绘另见[来源档案](../sources/fenglin-eleventh-2026-10-02.json)。官网结构化性别缺失；两位 Female 取既有同人物定义，不能说是官网 API 明示。

洛神取得的具体判定牌本回合不计入手牌上限，不能等同全部本回合所得牌，也不能把数值上限简单加取得张数。实际最终花色、实际获得实体及真实回合必须分别冻结；改判前的旧牌与未实际入手的牌不记奖励。倾国复用成熟黑色手牌转闪。判定 reason 保留 `skill.luoshen`，延续既有天妒排除。

工程解释：同一实体在本实际回合离手又回原受益角色，仍按具体牌豁免；在别人手中没有原角色的豁免。最终黑色牌被另一个真实能力取走，仍允许依冻结黑色结果继续判定，但零实际洛神获得就零豁免。这两项属于工程默认。

集智正文为“非转化锦囊牌”，资格查使用时已经冻结的转换链，包含普通与延时锦囊及真实使用无懈；重铸、普通打出、延时牌后续传递或判定不算再次使用。摸牌结果只处理本次实际收据，实际弃置其中基本牌才加当前实际回合手牌上限；子技能移走的牌不可拿此前旧手牌替代。

奇才对其他角色弃置本人装备区防具或宝物提供保护。弃置角色与动作意图来自真实操作，不从牌移动 reason 或当前回合角色反推；本人支付弃牌、取得、转移、装备替换与死亡清理按各自原意图执行。工程默认从弃置候选中排除受保护牌；无其它可弃牌则不提供该弃置动作，强制多牌不足时按实际合法子集有限完成。这些候选和不足处理没有额外官网 FAQ 证明。

新集智、奇才使用独立 `boundary:jizhi-current`、`boundary:qicai-current` ID；旧 `batch9-support` 定义保持。新能力选择入口与旧缺省分支分别核验，不按人物升级全局规则、JSON schema 或内容包。
