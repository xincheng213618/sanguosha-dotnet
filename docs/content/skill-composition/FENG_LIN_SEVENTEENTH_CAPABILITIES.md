# 界荀彧、界孙坚、界夏侯渊规则与工程裁定

当前冻结普通三国杀 OL 当前官网的界荀彧515、界孙坚458、界夏侯渊453。结构化身份、技能原文、立绘 URL、HTTP 状态和摘要见 [来源台账](../sources/fenglin-seventeenth-2026-10-03.json)。界孙坚采用 API 的体力上限5、初始4；网页社交摘要中的“4体力”不作为上限依据。

| 能力 | 内容消费者 | 结算边界 |
| --- | --- | --- |
| `drawThenDiscardHandToMaximumHp` | 界荀彧节命 | 在摸牌前冻结目标和 X=min(目标体力上限,配置上限)。真实摸X；等待移牌、体力子结算返回后，按当前手牌计算并冻结弃置差额。弃牌提示只对目标公开。死亡拥有者仅在原死亡帧及当前绑定一致时继续。 |
| `payHpToGrantOneUseDamageShield` | 界孙坚武烈 | 一次选择等量其他目标与体力付款。付款回执保留于原 ProgramSkillFrame；濒死、死亡、体力与移牌子帧返回后才授盾。付款者死亡或失去来源技能不重付、不撤销已付效果；游戏结束取消未授盾尾部。 |
| 独立一次伤害盾 | 武烈的“烈” | 标量来源凭据与公开标记计数一致；一次正伤害消耗一个盾，防止整次伤害。凭据持续到消耗，赠与者死亡不清除。原依赖来源存活的橘标记机制保留。 |
| `characterTurnedOver` | 界夏侯渊设变 | 正反两方向均记录不可变的前后状态。程序翻面、设置真实不同朝向及自然翻回正面共用既有 CharacterState 续接；已有仅翻回正面的窗口先处理。没有新窗口依赖的旧内容不产生新增事实。 |
| 翻面子结算的伤害游标校验 | 伤害触发中的设变 | 仅识别连续且身份一致的新翻面窗口、候选程序、移牌/体力观察帧和濒死返回；不放宽所有生命周期帧。原伤害程序在子结算返回后继续。 |
| 摸后弃阈值子结算的伤害游标校验 | 伤害触发中的节命 | 精确匹配已执行指令、冻结草稿、原伤害候选身份和真实摸牌/弃牌账本，允许连续的获牌、体力与濒死观察子帧返回。死亡入口不进入伤害游标白名单。 |
| 对应装备区移动的可选禁止替换 | 设变 | `prohibitReplacingEquipment` 增量允许装备区来源及已选二人引用。选牌时过滤被占用的对应槽，执行时再次校验；没有合法牌则走既有 `skipIfNoCards`。旧手牌来源及未启用标记的冻结行为保留。 |

驱虎、英魂、阶段跳过、无距离虚拟杀、对应装备区移动和标记显示复用现有能力；没有增加武将专用 Host 判断、Runner 开关或重复定义快照。新规则节点为可选增量，版本判断以 Replay.cs、SkillPrograms.cs、StandardClassicGeneralPackage.cs 的来源为准。

新的公开事件只包含标量或嵌套的不可变标量记录。付款与弃牌选择中的集合在原拥有帧冻结；玩家视图继续通过 CreateSnapshot(viewerSeat) 投影，ResolutionStack 只供可信诊断。

## 工程裁定

冻结来源是普通 OL 的 [界荀彧515](https://www.sanguosha.com/hero/515)、[界孙坚458](https://www.sanguosha.com/hero/458)、[界夏侯渊453](https://www.sanguosha.com/hero/453)，不合入移动版、国战或其他产品线的同名技能。已注册的界张辽2018、界许褚2014仍保留既有冻结版本；官网当前突袭目标限制、裸衣看牌后决定的差异记录为后续版本更新候选，没有覆盖既有选择。

- 节命按每点伤害分别完整结算；死亡入口走既有死亡窗口。X在摸牌前冻结，摸牌触发改变体力上限后不重算X；弃牌差额在摸牌所有子结算完成后计算。目标死亡或匹配来源失效时终止未完成步骤，已经摸到的牌不回滚。此续接与冻结时点属于引擎执行契约，不能标成官网 FAQ。
- 武烈数量上限采用 min(付款前当前体力,其他存活角色数)，允许支付全部当前体力。先冻结目标再失去体力；真实付款完成后，死亡或来源技能失效不改换目标，不重付体力。目标在付款子结算中死亡时不为其授盾，不另选替代目标。这些取消口径属于工程默认。
- 每个独立盾消耗一次并防止整次正伤害；无效或零伤害不消耗。已有无言防伤先处理，独立盾在原 BeforeDamage 程序窗口前处理；多个同类盾按已授顺序消耗。官网未提供复杂同级防伤排序 FAQ，该顺序是现引擎默认。
- 武烈 AI 只使用自身及目标的公开状态与既有关系评分；发动前须存在足以覆盖失体力成本的目标。没有正收益目标及仅能自杀付款时拒绝发动。此为 AI 策略，不是技能规则。
- 神速第二项可弃置手牌中的装备牌或装备区的牌；第三项在弃牌阶段入口跳过该阶段并真实翻面，先完成设变和移牌子结算，再执行该项无距离限制的虚拟杀。
- 设变沿现有对应区移动选择形态，先选有序的来源/目的二人，再选可合法移动的装备。所选二人之间没有合法装备时，`skipIfNoCards` 结束本次设变且不移动牌；通过可选禁止替换标记排除目的区已有同槽装备，不自动重选。普通 OL [蔡夫人攻略](https://www.sanguosha.com/news/20161121_8702_5915) 明示窃听移动装备不能替换，并参照巧变；将该移动规则用于设变是据此作出的推断，未取得设变专属 FAQ。旧有未启用该标记的内容维持冻结行为。
- 真正改变朝向才产生翻面事件；设置为当前朝向不产生事件。翻回正面保留既有窗口在先、新窗口在后的顺序；自然翻正面的跳过回合仍完成其原有回合结束流程。
- 据守/举荐/闭月的旧回合结束检查原先在命令之外将拥有者设为背面。新增真实翻面事实使该未入日志的前提在冷回放中暴露；检查现改用夹具的真实准备命令，再验证同一三技能顺序、已背面据守、即时新牌付款及闭月暂停恢复。未放宽重放或更改据守行为。

以上默认与官网技能正文分别留档；尚未取得的官方裁定不作已核实结论。
