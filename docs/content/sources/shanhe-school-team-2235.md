# 队友流套装2235

当前S5 [tactics.json](https://s.xiaochao.org/data/tactics.json)条目2235为“队友共享你的等阶效果（最低3阶效果）”。同版manifest需求为2普通、2稀有、1史诗。[本季原作者攻略](https://game.xiaomi.com/viewpoint/1624366642_1791880781253_13)也将其说明为队友获得自身等阶加成。

实际共享复用山河图现有等级表，最低按3阶：3阶体力上限和体力各加1、初始手牌加1、出杀次数加1；4阶体力加1、初始手牌加2、摸牌数加1、出杀次数加1；5阶体力加2、初始手牌加2、摸牌数加1、出杀次数加1，另有重生。各项叠加到队友已有属性，不能复制玩家整套战法加成。增加体力时保留伤势，不算回复。只影响真实存活公共队友，不加给主将或敌人。

入场已集齐时，初始手牌加成通过正常初始发牌实现，固定起手牌保留，不计为技能摸牌。战斗中买齐时，首次初始化为每名队友增加等级体力，并用真实摸牌补发等级初始牌；逐名等待体力、获牌和技能变化子流程完成后继续，不重复初始化旧实例。中途补发属于本地对即时购买的约定，公开资料未说明这一时点。

五阶共享的是“重生”，原程序回复至5点体力并摸5张牌，不套用其他涅槃的弃牌、翻面或解锁横置效果。[平台公告](https://my.4399.com/yxsgs/xinwen/64713/)说明重生整场征程仅一次，但没有说明队友共享后如何计次。按“共享你的初始特质”采用本地约定：主将和每名队友各自每征程一次，任一角色发动不消耗其他角色的资格。主将沿用自身重生消耗字段；开局与招募队友按其稳定角色标识记录，关卡自带队友按遭遇、位置及角色标识记录。下一战根据最终队友阵容转成冻结的已用席位列表；未成套时也保留该列表，使战斗中买齐套装只给尚未用过的队友授予唯一一份重生技能。真实技能使用事实分别归属原受益者，不靠重新开战刷新。

为使原五件配方实际可凑齐，补齐队·甲2200的300铜币稀有商品映射及默认库存，加入唯一的史诗500铜币队·体2199及其研习89。队·牌2201、队·初2202、羁绊2204继续使用原生效果。和光盟2219为稀有、和光盟Ⅱ2220为史诗，开局实际携带后也进入同一套精确品质配方；没有商店条目不影响其来源归属。套装本身不作为商品或额外奖励，不占普通技能槽，仅山河图模式按实际持有激活。预览和难度计算保留原始同行阵容，体力、初始发牌、摸牌与出杀加成分别沿唯一的模式/原生技能路径应用一次。
