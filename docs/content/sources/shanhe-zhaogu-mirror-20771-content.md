# 照骨镜：来源20771的实体、商品和牌面

规则资料来自官方OL [Config.sgs](https://web.sanguosha.com/220/h5_2/res/config/Config.sgs)，冻结外包 SHA256 为 `d663d5542f5a63a61611b5dbc1ae736e5e0328eedaab2c498e18c3287c289ce6`。解码成员 `hd_roguelike.sgs` 为 `97dbdb465d902e771e575ed5165df3d193e1a689e3dae7ae67b9cb5033f18c72`，`sys_playcard.sgs` 为 `05584b30f7986c06158ee6e47f78417b3d5f1c7fbc61174cfad26e12a5ee64ab`，`cha_spell.sgs` 为 `e8885a11c46c3b25f37a6fcd8882b0d339ab1d1873c140900d3be93826fdd219`。

`GamePlayCards.card[a=20771]` 名称为照骨镜，`c=3,d=9,f=1,g=2,m=6018,n=6018,p=ZhaoGuJing`。它是宝物，不是防具；来源20335的同名普通装备行也具有相同规则和牌面字段。独立实体ID为 `shanhe:zhaogu-mirror-20771`，CardKind为 `ZhaoguMirror=20771`，宝物槽授予 `shanhe:zhaogu-mirror-6018`，装备来源为 `equipment:shanhe-zhaogu-mirror`。

6018原文为：出牌阶段结束时，你可以展示手牌中一张基本牌或普通锦囊牌，视为你使用之。内容束 `shanhe-zhaogu-mirror-6018` 使用自己的真实 `playEnding`、`owner/own` 可选触发，仅交给独立原生操作 `resolveShanheZhaoguMirror` 执行；不设锁定标签，不借用客户端动画名对应的其他宝物规则。

[官方2022年测试服公告](https://www.sanguosha.com/news/20220720_7268_4011)列出的照骨镜描述与上述技能一致；[OL3.3.3更新公告](https://www.sanguosha.com/news/20220913_8450_4211)还明确修复展示后不能使用时卡操作的问题。因此实现保留“先展示，随后可能没有合法用法”的实际分支。

原生流程在本人真实出牌阶段结束窗口开始：先私下选择一张基本牌或普通锦囊手牌，公开展示这张原牌，不移动它；原生展示产生的子流程返回后，才按已展示的牌种列出当前合法用法。基本牌沿既有虚拟基本牌流程，普通锦囊沿原生锦囊使用、选目标、响应与无懈可击流程；单一合法方案也提供用法选择，可在展示前或展示后取消。原技能帧等待实际用牌及其伤害、摸牌、响应等孩子完成后，再返回原出牌阶段结束窗口。

闪、无懈可击没有可主动使用的响应上下文，或杀次数已耗尽、目标和牌禁等条件使牌无法使用时，仍完成这次真实展示，然后正常结束该技能，不补造响应或视为使用。原有距离、次数、目标和用牌限制继续适用。

原实体保留在手牌、复制出的使用不支付实体材料，并采用无花色、无颜色、无点数的虚拟牌外观，是本地复用通用零实体用牌机制的执行约定，并非本批已取得的服务器专项裁定。展示原牌的红黑、花色、点数不会转移到虚拟使用上；无色也不会被当成黑色。该约定同样适用于基本牌与普通锦囊，模板自身不会进入处理区或因这次复制而弃置。

照骨镜按真实宝物装备授技。宝物被替换或移出装备区时，该实体授予的技能随即移除，后续出牌阶段结束不再提供镜子效果；已经发行的原生用牌孩子仍按其原始帧和回执返回，不因此重复展示、付款或恢复装备技能。本批实现、内容接线与定向检查已完成，覆盖真实闪、无懈付款、无中摸牌、决斗伤害、无法使用和宝物替换。

商品价格和品质直接取同一官方缓存的 `Root.Card[id=4060]`：`cardid=20335,isequip=6,autoequip=1,level=4,money=600`。因此本地商品为 `codex-card-4060`、600铜币、品质4，类别“装备”。它通过现有 `CurrentShopCardSources` 链生成商品、奖励、元数据与可用货品，不另造价格。原 `autoequip` 字段不改变当前市场“购买取得实体手牌，再原生使用装备”的合同。

同份官方 `saijitianfu` 没有引用4060、20335或20771，当前S5山河册也没有照骨镜节点。沿用无固定节点货品的本地默认供货，未编造研究节点或解锁费用。
