# 移动版界华佗

核对日期：2026-10-25。独立身份 `boundary:hua-tuo-mobile`，群、男性、三体力，无主公技，画像键 `boundary-hua-tuo-mobile`。急救完整复用 `boundary:jijiu`，青囊独立为 `boundary:qingnang-mobile`。

- [移动版Wiki界华佗](https://wiki.biligame.com/msgs/%E7%95%8C%E5%8D%8E%E4%BD%97)（2025-11-13更新）列出相同三体力身份、红牌续发和旧除疠版本；但目标限制写成每名角色每阶段一次。官网明确为本回合不重复，本实现采用官网的实际回合范围，文档保留这一差异，不默认为两者相同。已检索后续官方技能改版与调整，未找到取代该官网完整正文的修订。

现有OL界华佗是急救与除疠，不能直接作为移动版人物。急救规则相同，复用其回合外红色手牌或装备转桃的原生响应资格；移动版不授予除疠。青囊也不能完整引用普通一次青囊，否则会丢失红牌的连续发动规则。

青囊继续使用原生手牌单张选择、`discardSelected` 实体付款、任意存活受伤目标及 `recover` 一点恢复。每次发动在原 `ProgramSkillFrame` 冻结具体手牌、有效花色、原目标及 `SkillGrantPhaseExpiry` 的实际回合、出牌阶段角色和原生阶段编号；实际弃牌移动后才确认付费事实。

阶段次数仍由现有 `_programPhaseUses` 消耗并在实际出牌阶段重置。自有动态额度只将同一原生阶段中每次已付红牌增加为一次额外额度：红牌支付后可继续，黑牌支付仍完成此次恢复，但恰好耗尽当前额度。没有另建次数、pending或使用ID集合。目标选择和提交验证均从真实已付事实过滤本回合已经选择的角色；不同出牌阶段可恢复基础次数，但不会清除本回合目标记录。

原弃牌、牌移动子流程、原生恢复及其后续孩子都沿原帧执行，已付费后失去来源仍保留原恢复。专用移动返回钩子核对原弃牌事实、原指令、原实体、原技能实例和哈希，并等待全部付款孩子返回，才给原 `SelectedCardPaymentResult` 写入完成并进入恢复；不重新检查来源或重新付款。恢复次数按原生恢复事实，不将弃牌数、点击次数或预计回复代替实际支付与结算。新事件只含不可变标量及标量记录，不暴露未付手牌身份或新增可变事件集合。

新增一条 `BoundaryHuaTuoMobileChecks.RedContinuesBlackStopsAndOriginalRecoveryReturnsCold`：两张真实红手牌依次治疗不同目标，其中首张弃牌的原生移动孩子冷恢复；再弃黑牌治疗后停止当前阶段。通过真实当先进入同回合另一个出牌阶段，验证基础额度恢复、本回合旧目标仍被排除。最后一次付款孩子中通过原生技能替换真正移除青囊，失源后冷恢复并返回原已付恢复。四张原弃牌、四次实际一点恢复和四个原帧完成各一次，不复制急救已有检查。
