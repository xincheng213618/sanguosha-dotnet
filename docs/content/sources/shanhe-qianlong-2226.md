# 潜龙2226

当前固定S5的[tactics.json](https://s.xiaochao.org/data/tactics.json)中的2226为普通潜龙、200铜币，原文为“每有一个已解锁的空技能槽，则出杀次数+2”，归属多刀流。沿实际普通战法奖励、商店及初始携带接入，图标复用已缓存2226原图。套装仍按不同来源组件计数。

空槽数是已解锁的额外技能容量减去实际已占用的征程额外技能，最低为0。武将印刷技能、战法及等阶重生不占这些槽；沉默或战中暂失技能不等于退还已经购买的槽位。常驻集市使用当前已提交的容量和技能清单，买技能、满槽替换、增加容量和购入潜龙后，在原生杀次数查询时立即重新计算；已经使用的杀仍占本阶段次数，不重置、补造或退款。

未开启常驻集市的战斗，从征程入场配置冻结额外技能容量，配合原有额外技能清单计算，排除其中的等阶重生。只有山河图玩家席0读取该构筑；同场其他角色或普通模式即使取得同名程序也不会借用玩家的空槽。加成复用现有数值规则表达式和杀额度，实体付款、目标限制、响应与伤害沿原生流程。
