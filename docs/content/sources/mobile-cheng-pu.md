疠火：使用普通杀时可改为火杀；只有以此法转化的火杀造成过伤害，才在结算结束后失去1点体力。使用火杀可多选一个目标，无论是否由疠火转化。完整复用 `classic:lihuo`，包括原生转换来源、火杀额外目标和整张杀完成后的伤害事实。

醇醪：结束阶段没有醇时，可将任意张手牌中的杀存为醇；角色濒死时可移去一张醇，视为该角色使用酒。完整复用 `boundary:chunlao-mobile`：它与此普通移动版醇醪正文完全相同，允许不设张数上限的杀牌族选择并等待真实移动子结算。没有复制旧 `classic:chunlao` 的20张选择上限。

本实现没有采用界程普的疠火规则、其他版本移去火杀回复/雷杀摸牌奖励，或“存任意基本牌”。官网及当前普通移动条目均无这些条款。检索官方后续调整未发现覆盖普通程普该正文的修订。
