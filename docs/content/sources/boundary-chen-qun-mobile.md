# 移动版界陈群

核对日期：2026-10-24。角色登记为`boundary:chen-qun-mobile`，魏、男性、3体力，定品和法恩分别使用独立的`boundary:dingpin-mobile`与`boundary:faen-mobile`。

## 来源及版本边界

[移动版官网界陈群406](https://www.sanguosha.cn/pc/hero-detail-406.html)给出了当前定品：出牌阶段弃置一张本回合未使用或弃置过类型的牌，可以指定包括自己在内的一名角色判定；黑色令目标摸其当前体力值、至多三张，然后本回合不得再次对该目标定品；红桃仅将本次定品成本排除出弃置类别限制；方块令陈群翻面。该页列有法恩标题，正文缺失，但玩法明确提到陈群翻面触发法恩、翻回正面亦可收益。

补充核对了[移动版普通陈群176](https://www.sanguosha.cn/hero-detail-176.html)，该页同样漏列法恩正文，不能据此推断为OL“翻至正面”版。移动资料[界陈群专页](https://wiki.biligame.com/msgs/界陈群)与[法恩/界陈群](https://wiki.biligame.com/msgs/法恩/界陈群)均记载翻面或横置后可令该角色摸一张牌，与406玩法相符。[官方2014年陈群介绍](https://sanguosha.com/news/20141103_3211_3217)及[官方2015年陈群攻略](https://www.sanguosha.com/news/20150112_8300_2116)作为历史补充，也明确区分翻下、翻回正面及进入连环三种时机，解除连环不触发。本实现按移动当前资料完整接入这三个时机；历史官方文章用于补足遗漏，不用于替换406的当前定品。

现有`classic:chen-qun`是OL品第及仅翻至正面法恩；[移动势陈群673](https://www.sanguosha.cn/pc/hero-detail-673.html)是每轮最大失牌定品及用牌前后执行相反选项的法恩。三者分别登记，规则互不替代。

## 原生结算说明

定品复用原生HE单牌选择、整批逻辑弃置、判定及公开最终判定值。改判结果按原生最终花色生效；判定牌被其他技能获得后，既有`outcomeBind`仍保留该次判定值，不凭实体当前位置改变规则结果。判定完成后按实时目标体力冻结摸牌请求，使用原生摸牌请求与替代结算；目标封锁在该请求及移动子窗返回后签发，按原实际回合到期。

类别限制读取共享实际使用账本与原生逻辑弃置材料，使用采用生效牌类别，弃置采用原实体类别；基本牌、锦囊牌、装备牌分别归类。仅打出或重铸沿用原生语义，不伪造为使用或弃置。红桃签发对本次实际成本的精确豁免，保留完整全局弃牌事实，不移除其他同类使用、其他弃置或后继子窗中的独立弃置记录。

所有新增付款及黑判摸牌状态保存在原`ProgramSkillFrame`，使用既有判定值绑定和原生摸牌typed return，Resume/Movement返回与移动子窗来源证明同时登记。法恩完全复用原生翻面、进入连环及摸牌DSL；重复设置同一连环状态和解链不制造发生次数。

核心检查聚焦三种定品结果、当前体力与三张上限、自选目标、实际使用与弃置类别、回合封锁到期，以及代表性的已付款、最终判定和摸牌子窗冷恢复。未复制定义快照或逐人物隐私矩阵。
