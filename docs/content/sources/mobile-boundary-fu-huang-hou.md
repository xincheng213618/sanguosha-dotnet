# 移动版界伏皇后

## 规则来源

- [三国杀移动版官网：界·伏皇后，394](https://www.sanguosha.cn/index.php/pc/hero-detail-394.html)，核对日期：2026-10-25。两技能正文完整：惴恐每轮一次，在其他角色实际回合开始且其体力不小于自己时可拼点；赢则限制该角色本回合用牌目标，没赢则先取得其原拼点牌，再由其视为对伏皇后使用普通杀。
- [移动版 BWIKI：界伏皇后](https://wiki.biligame.com/msgs/%E7%95%8C%E4%BC%8F%E7%9A%87%E5%90%8E)、[求援/界伏皇后](https://wiki.biligame.com/msgs/%E6%B1%82%E6%8F%B4/%E7%95%8C%E4%BC%8F%E7%9A%87%E5%90%8E)（技能页标注更新日期 2026-01-10），同版身份正文将求援表述为另一名其他角色交非杀基本牌或成为原杀的额外目标。因此排除伏皇后本人及原使用者；没有扩到伤害锦囊或同类不同牌名的非基本牌。
- [官方规则集 3.0 镜像：群势力武将，伏皇后求援](https://gltjk.com/sanguosha/rules/card/hero/neutral.html) 明确额外目标合法性检测不检查距离，其他目标禁选仍有效。该页讲解的是早期求援；这里把其距离检测说明作为相同额外目标操作的辅助解释，而非冒称移动版官网额外 FAQ。移动版“另一名其他角色、成为此杀额外目标”的范围沿此解释，仅对本版求援开放，保留存活、原使用者、自身、目标禁选和护罩等原生限制。

独立武将 `boundary:fu-huang-hou-mobile`，技能 `boundary:zhuikong-mobile`、`boundary:qiuyuan-mobile`，变体 `boundary-mobile`、规则集 `sanguosha-mobile`；群、女性、三体力。不采用旧惴恐的自身已受伤条件，也不采用 OL 求援对伤害锦囊的范围。

## 原生流程

惴恐复用原生 `ForeignActualTurnStartWindowFrame`、拼点输入与 `resolveForeignTurnPindian`。仅移动版资格按实际双方体力比较；原输入牌、可拼点条件与实际回合拥有者仍由原机制校验。`usageScope: round` 复用共享每轮次数，拒绝发动不消耗次数，发动后同轮其他合格回合不重复询问。

赢的分支发行绑定原实际回合和原角色的 `selfOnly` 用牌目标限制，不是跳过出牌阶段或禁止所有使用。平局属于没赢：取得原结果中对方的真实拼点实体，等待其实际得牌及相关子窗，之后才由该角色原生视为使用一张普通杀。原拼点来源、移动付款、虚拟用牌与 typed return 都在原拥有帧；不建立并行 pending 或重新取得一张同名牌。

求援复用已有实际用牌援助协议，但触发牌种只开放原生杀分类（含属性杀）及已有无 Action 的虚拟杀目标窗口。对杀而言，共享“同类型且不同牌名”正好是非杀基本牌，并把属性杀折叠为同一杀牌名排除。真正赠与沿 `NativeGive` 和实际原实体移动，完成得牌子窗后返回原杀；拒绝则向原 `CardUseFrame` 增加目标，不生成第二张杀，不重复支付原物理牌。

## 必要行为检查

公开 API 的四人身份夹具加载本版正式技能，以技能来源包装将仅补足观察暂停及保留原手牌；每个座位使用正式选将、输入、拼点、使用和响应命令，未访问内部牌区。检查覆盖健康角色的体力条件、每轮一次及低体力对手不合格；真实平局取得原对方牌的得牌子窗冷恢复与后续普通杀；以及非杀基本牌中的桃实际赠与后冷恢复，或拒绝并成为同一实体杀的超距离额外目标。没有另造私库、历史或回放矩阵。
