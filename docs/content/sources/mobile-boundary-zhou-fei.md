# 移动版界周妃

本目录是 `boundary:zhou-fei-mobile`，吴势力、女性、3体力，立绘键 `boundary-zhou-fei-mobile`。与仓库经典周妃的手牌数比较、每回合首次游戏内外移动和旧版仅自己准备存琴相互独立。

## 来源与版本

- [三国杀移动版官网：界周妃，编号663](https://www.sanguosha.cn/pc/hero-detail-663.html)，2026-10-25核对完整技能正文。良姻取消手牌数限制，覆盖全场武将牌上的置入和获得，并增加轮末唯一目标奖惩。箜声可以在准备、本人回复或直接失去体力后，将当前回合角色的任意张牌扣在该角色武将牌上；其结束阶段周妃可以使用其中一张，其获得其余。
- [移动版WIKI：良姻／界周妃](https://wiki.biligame.com/msgs/%E8%89%AF%E5%A7%BB/%E7%95%8C%E5%91%A8%E5%A6%83)明确写明按一名角色武将牌上的任意张牌作为一次移动时机，轮末查看曾经成为目标的角色，而非发动次数。
- [移动版WIKI：箜声／界周妃](https://wiki.biligame.com/msgs/%E7%AE%9C%E5%A3%B0/%E7%95%8C%E5%91%A8%E5%A6%83)的同版完整文字包含“若如此做”后接该角色结束阶段的延时效果。本次直接读取的技能子页显示2026-08-03更新。每次发动各自发行一个延时结算，因此同一持有者被分次扣牌，各次在其结束阶段分别可使用一张并返还本次余牌；不会将不同原发起帧混为一个总池。
- [官方规则集3.0镜像：区域](https://gltjk.com/sanguosha/rules/glossary/zone.html)区分角色拥有的牌和角色判定区。箜声写的是该角色的牌，不是其区域内的牌，因此使用其手牌与装备，不包括判定牌。

## 具体裁定

### 良姻

按原生移动批次，分别观察置于同一角色武将牌上、或同一角色从另一角色武将牌上获得牌。同批同一对象的多张牌合为一次时机，不按牌数重复。检测依据实际物理移动，覆盖其他技能的牌堆，不依赖箜声来源。获得要求进入角色手牌；直接从将牌使用、弃置或销毁不冒充“获得”。

目前引擎明确表示武将牌上／旁存放的区域包括权、不屈创、醇、公开与私密持久牌堆、私密储备、公开延迟存牌、破军暂扣、带来源的回合暂扣及轮暂扣。普通手牌、装备、判定、处理和牌堆不算；销毁／游戏外废弃位置不算，木牛流马的载牌也不算。该分类独立于旧经典良姻的广义游戏内外判断。

目标可以是自己，摸牌走原生摸牌；被要求弃牌的角色自行选弃一张真实手牌或装备。每轮记录本周妃实际指定过的摸牌和弃牌目标集合，重复指定同一人不增加集合大小。轮末若只有一个曾经目标且其仍存活，可令其回复；若只有一个存活角色从未成为目标，可令其直接失去体力。这是两种可选结果，未选择的结果不执行；轮末奖惩不反过来新增本轮摸弃目标记录。

### 箜声

“失去体力”与受到伤害分别处理：仅原生直接失血或实际回复产生的对应体力变更窗口，伤害不冒充直接失去体力。准备窗口属于自己；回合角色固定读取实际回合游标，避免临时插入的他人阶段错误改换持有者。

扣外人手牌时复用现有不透出牌面／实体ID的区域牌槽选择；装备保持其原本公开的选择信息。先选择任意张，再作为同一原生批次扣置。实体仍在原持有者武将牌的独立私密牌堆中，发动者、原持有者及原发起帧各有独立身份，不借用虚拟手牌。

隐私是按原生扣置与选择需要解释的实现裁定，官网没有另列查看FAQ：原持有者可查看自己的私密存牌，第三人只能看到数量。周妃不是从扣牌起自动看见外人暗手牌；仅在该次结束阶段实际选择使用时，通过既有私看投影局部查看当前存牌。存牌事件只带来源、位置、数量及移动边界，不带暗牌清单。真正使用后才按原生用牌公开该实体。

结束阶段通过原生合法动作生成器，允许周妃选择一张真正可以使用的存牌与合法目标；保留距离、禁止、护罩和原始实体付款，非出牌阶段使用不错误消耗普通出牌次数。真实用牌通过类型化母帧返回后，再将本次仍在原牌堆的余牌交给原持有者。每次扣置保持各自独立位置与延时游标。

扣置已支付后，发动者死亡或失去箜声只撤销其选用权，不撤销活持有者应取得余牌的义务。持有者死亡则沿原生死亡清理处置其实际剩余牌，不制造归还或重新生成实体。合法子窗与冷恢复不会再次扣原牌、重复使用或重复返还。

## 必要行为覆盖

Core检查用另一项实际公开武将牌堆能力验证良姻全局置入、获得后弃牌，以及轮末唯一曾经目标回复和唯一未被指定角色失血。另一检查通过外人回合内真实失去／回复体力形成两个独立扣牌批次，验证暗手牌不提前公开、付款后的原生子窗冷恢复、每批真正使用一张及余牌归还；另以现有技能变更操作使已付款来源失效，冷恢复并继续其原始返还。WPF复用同一份公开API场景操作真实区域牌槽、使用选项和返还路径。
