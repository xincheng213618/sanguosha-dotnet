- 同版交叉核对：[移动版 BWIKI：奋激](https://wiki.biligame.com/msgs/%E5%A5%8B%E6%BF%80)，2025-12-19更新，明确身份版为“一名角色的回合结束时，若其没有手牌，你可以令该角色摸两张牌，然后你失去1点体力”，与官网完整正文一致。区分 OL 因他人弃置或获得手牌立即触发且先失体力的奋激。

不屈沿用已存在的原生濒死回应、翻顶牌及公开创区、重复点数弃置、回复至一与创数手牌上限机制，不复制程序或创建第二套创状态。它与普通周泰历史上体力小于一仍不死亡、回复后移去创的版本不同；当前移动版恢复体力不移去已获得的创。

奋激观察真正的 `afterTurnEnded`，包括本人及其他存活角色的实际回合结束，不在其结束阶段提前发动，也不监听手牌移动。原生回合结束返还及已有结算完成后，核对该回合实际结束者仍没有手牌。本人回合直接摸二，其他角色回合沿原生事件来源选定唯一结束者后让其摸二；均在真正摸牌及所有获取子窗返回后，才沿原帧原生 `loseHp` 自失一点体力。失体力引发的濒死、不屈与后续返回继续沿原生类型化子结算，没有新 pending、额外支付状态或枚举。

不屈的不同点数、重复点数、原生回复及创数手限继承已有共享行为检查。新增最少行为检查专门覆盖移动奋激的本人／他人实际回合边界、空手条件、先摸牌后失体力、原生摸牌子窗冷恢复及随后濒死不屈，避免重复整套不屈矩阵。
