# 常驻市场的本地执行合同

本地新建的2026诸侯伐董征程启用 `PersistentMarket`。市场使用已核实的现有技能、战法及实体牌报价；常驻入口、战斗中购物和章节货架寿命是本次用户要求采用的本地流程，不据此宣称公开资料给出了同样的市场时机。

市场基础上限为每类5件，持有商品+1／+2时按真实加成增加；候选不足按实际供货，同一取得身份不重复占位。购买、补货、品质提升、免费刷新优先、付费刷新和同类商品每购一次加100的规则均复用现有交易 Session，不另写一套价格算法。旧节点式商店仅在未启用新选项时沿用原流程。

新流程的地图跳过商店模板，将其相邻路线透明连接。每章共享一份货架、已购状态、同类加价及已用免费／付费刷新次数；关闭重开市场、普通地图移动、事件或奖励选择均不重置。进入另一章时才生成本章货架并重置这些本店计数，钱包、已购技能、战法和随身资源继续保留。这个逐章寿命是明确的本地约定，最终结算不再开放市场。

地图、事件和奖励选择时，征程 Session 接受独立购买命令。战斗时由引擎持有独立交易 Session，外层征程同时拒绝购买，避免两处扣款。战斗输入只携带冻结的精简市场定义、选项和实际钱包／构筑／货架种子，不嵌入历史征程 checkpoint 或交易历史命令。购买先使用同一无副作用预验证，再在原生战斗购买流程中应用已支付的真实效果；交易侧健康仅投影当前原生体力和上限，不作为额外钱包或最终战斗体力来源。

战斗结束沿用既有的初始 setup 严格绑定及独立命令重放。征程只从该已验证战斗的真实市场 Session 导入钱包、永久构筑及本章货架变动，再结算战斗收益。最终剩余体力取重放后的玩家状态，不能由市场 transfer 的体力字段替代。界面自报成功或任意钱包数值均不是结算输入。
