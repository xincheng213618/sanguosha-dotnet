# 界姜维（移动版）

核对日期：2026-10-25。蜀、男性、4体力，完整技能为挑衅、志继；志继授予完整界观星。

- [移动版官网武将291](https://www.sanguosha.cn/pc/hero-detail-291.html)：挑衅每出牌阶段一次，选任意一名其他角色，除非其对自己使用一张杀，否则自己弃置其一张牌。隐藏志继全文只有准备阶段空手觉醒：先回复1或摸2，再减1上限并得界观星。
- [官网各版本姜维攻略（2023-07-05）](https://www.sanguosha.cn/pc/guide-info-147.html)：明确界挑衅可以对攻击距离够不到自己的角色发动，以此稳定拆牌；界观星沿用界诸葛亮的完整技能，区别于普通姜维。
- [移动版 BWIKI 人物正文](https://wiki.biligame.com/msgs/%E7%95%8C%E5%A7%9C%E7%BB%B4)（标注2025-12-30更新）、[志继子页](https://wiki.biligame.com/msgs/%E5%BF%97%E7%BB%A7/%E7%95%8C%E5%A7%9C%E7%BB%B4)：人物正文为其他角色选正常出杀或被拆；志继只在准备阶段，授予界观星。注意[挑衅子页](https://wiki.biligame.com/msgs/%E6%8C%91%E8%A1%85/%E7%95%8C%E5%A7%9C%E7%BB%B4)2026-01-11内容转引OL站，带“必须伤害且失败后限两次”的OL规则，与移动官网及人物正文不同，本实现采用移动官网完整定义。未找到后续官方公告取代这一规则。

本仓库现有OL挑衅限定目标攻击范围，出杀后仍可能因未伤害而拆牌，并可能再发动一次；OL志继也可在结束阶段发动，授予普通观星。这些均不能引用。普通挑衅也限制目标范围；普通志继只授予普通观星，因此两技能使用独立移动版配置。

挑衅仍消费原生出牌阶段次数，使用完整原生受令出杀流程，将同一原 `ProgramSkillFrame.AssistedSlashRequest` 的目标固定为挑衅者。对方普通杀、元素杀、转换杀和多材料杀均经过原生目标、材料和距离资格，实际付款、响应和完成返回原帧；没有无距离或额外目标权限，也不消费对方通常出牌杀次数。对方没有合法反击手段时进入弃置其一张手牌或装备的分支；使用杀后即不拆牌，不要求造成伤害。不存在第二套pending或用牌编号侧车。

志继使用已有选择、原生恢复/摸牌、体力上限和共享grantSkills换技流程，每局只发动一次。授予已有 `boundary:guanxing-current`：准备看5张，存活不足4人看3张，全部置底可于结束阶段再次观星。该技能完整复用，不复制观星fixture。
