## 实现边界与裁定

窃听读取原 `DeferredTurnEndFrame` 对应的 `TurnStartedEvent` 至 `TurnEndedEvent` 之间已实际应用的正值、有来源伤害。仅本实际回合角色作为伤害来源、受伤者与其不同的记录阻断；被防止的伤害、失去体力、对自己造成伤害以及该回合结束后新发生的结算均不算。未造成伤害的对他人用牌不阻断。选项付款、原始回合资格和所有子窗继续复用蔡夫人既有 `OrdinaryQietingReceipt`。

“观看其两张手牌”不表示可先看全手牌再挑两张。实现从该角色当前真实手牌无放回随机取至多两张；不足两张时观看全部现有手牌、无手牌时此选项不可选。这是正文对隐藏牌的通常执行解释，官网没有另外明示取样算法。随机前后状态、原手牌候选和取样留在私密原帧，读档不重抽。只有蔡夫人的当前私看表面获得这至多两张牌的身份，其余手牌及第三方视角保持原有可见范围。新观看事件只记录人数和张数，不公开牌实体 ID。取得其中一张原实体后隐藏私看表面，原得牌子窗回到原母帧。

置入装备选项使用原生装备合法性、栏位容量及正常替换：有同栏装备时先按原生理由弃置旧装备，再移动对方的那张实体。木牛流马附属牌和白银狮子离区回复等沿原生移动孩子结算，不能改成虚拟装备或重新付款。普通版空栏限制保留在其原规则分支。

献州完整复用 `donateAllEquipmentAndOfferRecipientBenefits`：一次付出全部可交出的真实装备，以实际交付数量冻结 X，等待原生失去／获得牌子窗后，由实际收者决定回复，或在其当前攻击范围内选择至多 X 名角色（允许零名）依次造成伤害。限定使用记录在真实付款后消费，后续不重新支付。此纯复用部分继承全装备赠与既有行为覆盖，不新增人物配置快照或复制通用赠与矩阵。
