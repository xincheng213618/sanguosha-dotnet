# 董白·移动版（2026年正式重制）

核对日期：2026-10-26。独立身份 `mobile:dong-bai`，群势力，女性，3体力，SP武将组5。经典形象画师Sonia Tang。

[移动官网2026-05-15公告](https://www.sanguosha.cn/pc/news-detail-2313.html)明确公布5月16日董白重制上线；[移动版BWIKI董白](https://wiki.biligame.com/msgs/董白)当前页面 oldid=38487（2026-05-12 更新）将新旧连诛、黠慧分别列出。采用已正式上线的重制规则，不能把当前页面的新版当作仍未上线的爆料，也不能整技复用现有OL旧版。

新版连诛每个实际出牌阶段可展示并交给另一名角色一张手牌或装备牌。直到该实际出牌阶段结束，董白对该实体牌的当前持有者使用牌不受距离和次数限制，对其实际造成伤害后可以获得此牌。此阶段内每次有角色获得该实体，获得者须选择：交给董白一张除此实体之外的其他牌，然后把此实体交给自己的上家；或者令董白摸两张牌。

初始选牌和展示复用现有captureSelectedCards、revealBoundCards；展示返回后由同一Prepare操作的原帧续段调用共享多来源实体移动与NativeGive交付。现有await的moveBoundCards普通主动入口限点数和赠牌合同，因此不把董白塞进该旧专属许可。标量签发事实记录真实实体、原来源区域、技能实例、内容hash和实际Play身份；权限每次读取实体当前所有者，进入下一实际Play或离开原Play后不延长。获得事件沿原始移动batch和index形成typed context，包含初始装备来源及其他区域重新获得，不伪装成旧手牌失去事实。

连诛获得者的分支和每一段已支付移动留在原所属ProgramSkillFrame。先完成其他牌的原生交付及其子窗，再读取当前存活上家并传递原实体；传递引起的新获得继续走原生窗口。选择摸牌时使用BeginOperationProgramDraw及NativeDrawOutcome，保留替换摸牌和原生子窗返回，不用人工把牌堆顶移动两张代替摸牌。已付款状态通过标量付款事实核对，冷恢复不重复给牌或传递。

新版黠慧继续使用已有黑牌手牌上限豁免、黑牌获得限制、用牌/打出/弃牌检查，以及体力减少和实体离开手牌时的释放。移动版额外对本Play的连诛实体签发同一套限制，红色实体同样受限；限制一旦签发，不因原Play结束就解除，仍等待获得者真实体力下降或实体离开其手牌。此部分独立运行代码补充新版规则，保留OL旧版行为。

正文未提供的细分解释：上家按逆座位方向最近的存活角色确定，支付其他牌并完成子窗后才读取；若已付款子窗内原实体已离开原持有者，后续不追索不存在的原持有材料。获得者就是董白本人时，“交给你”不提供没有实际交牌成本的自交分支，保留令自己摸两张牌。连诛新授予的距离、次数与获得时的传递义务限原实际Play；已签发的黠慧实体限制按其自身终止条件保留。上述解释与正式正文区分记录。
