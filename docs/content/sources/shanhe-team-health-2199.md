# 队·体2199

来源为当前S5的[tactics.json](https://s.xiaochao.org/data/tactics.json)：2199，名称“队·体”，史诗，500铜币，队友流，效果“你的所有队友体力+3”。S5研习节点89对应这一来源。沿商店、普通战与精英战奖励和初始战法取得，不作为普通武将技能占槽。

公开描述没有区分体力值和体力上限。本地约定：令实际在场的每名存活公共队友体力上限与当前体力各增加3，保留原有伤势；自己、敌军及死亡角色不获得加成。该增加属于体力调整，不产生回复事件，也不被药理等回复加成放大。初始携带在开局初始化一次，战斗中购买由原付费帧初始化一次；后续购买不重复给旧实例加成。

该成员属于队友流的一份史诗战法，不能直接当作完整队友流套装效果；等阶共享仍须满足实际持有的四品质组合要求。
