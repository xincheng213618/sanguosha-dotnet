# 移动版界高顺

- 独立武将 `boundary:gao-shun-mobile`，群势力、男性、四体力；规则集 `sanguosha-mobile`，版本 `boundary-mobile`。技能为 `boundary:xianzhen-mobile`、`boundary:jinjiu-mobile`。
- 主来源：[三国杀移动版官网武将详情 358](https://www.sanguosha.cn/index.php/pc/hero-detail-358.html)，核对日期 2026-10-25。完整列出陷阵及禁酒三段，陷阵的胜负效果限于本出牌阶段，只有杀的手牌上限豁免持续本回合。
- 官方后续文字规范：[部分技能描述规范化调整，2022-07-26](https://www.sanguosha.cn/pc/news-detail-1272.html)，把禁酒第一段明确为酒“只能当做普通杀使用或打出”，保留酒杀减伤与本人回合禁他人使用酒两段。故酒用于拼点仍按实体印刷种类和原生有效点数判断，禁酒自身不把拼点酒改为杀或点数K。
- 同版交叉核对：[移动版 BWIKI：界高顺](https://wiki.biligame.com/msgs/%E7%95%8C%E9%AB%98%E9%A1%BA)，2026-08-06版本仍为相同规则，补充清楚胜负效果“直至此阶段结束”，以及禁酒第二段为受到杀伤害时减去影响此杀的酒张数。没有采用 OL 的K点数、额外指定目标、整回合距离及次数效果，也没有采用谋高顺把酒杀伤害直接改为一点的规则。

陷阵沿用真正的原生拼点及其支付、结果绑定、移动清理与原母帧返回。原生比较结果确定时，记录其实际发起者的实体牌、点数、对手及原始出牌阶段；只看高顺本人的拼点牌，不看对方的牌。杀的各种属性属于同一杀牌族。完成比较后，原帧发行绑定实际阶段标识的胜负效果：赢时对该对手使用牌无距离和次数限制并无视防具；没赢时仅禁止使用杀，仍可打出杀响应决斗或南蛮入侵。下一出牌阶段即失效，即使它仍在同一实际回合内；已发行的效果不会因随后失去来源技能而被撤销。本人拼点实体为杀时，不论胜负，调用共享原生手牌上限豁免，持续到本实际回合结束。

禁酒的酒身份及其他角色用酒禁令复用原生身份、响应及用牌权限，不改变物理实体、花色或印刷点数。酒杀减伤使用原杀帧在消耗酒效果时冻结的 `ConsumedAlcoholBonus` 与其原生事实，核对同一实际用牌者、动作和伤害来源；减伤沿用原生 `ReduceProgramCurrentDamage`，不反推伤害差额，也不取消其他技能带来的增伤。没有消耗酒的杀不触发此减免。没有新增并行 pending、额外支付或用牌 ID 状态表。

必要行为检查覆盖真实拼点及其冷恢复、远距离连续杀和白银狮子绕过、同回合第二个出牌阶段的胜负效果到期、手限豁免跨阶段保留与实际回合结束清除、酒拼点保留原点数和牌类、未赢时允许酒作普通杀打出，以及原杀的酒消耗冷恢复后只减酒增伤、无酒的后续杀不误减免和真实其他角色濒死用酒禁令。
