# 移动版界步练师

核对日期：2026-10-25。独立版本 `boundary:bu-lian-shi-mobile`，吴势力、女性、3体力，画像 `boundary-bu-lian-shi-mobile`。

## 完整来源

[移动版官网371](https://www.sanguosha.cn/index.php/pc/hero-detail-371.html)提供当前安恤完整正文：出牌阶段限一次，让一名其他角色获得另一名其他角色的一张牌；原始来源不是装备区时，步练师摸一张；之后可以让两者手牌较少者摸一张。该页列出追忆的名称，但缺正文；玩法段落仅说明死亡时令队友摸牌和回复，不能单独据此补全受益人限制。

[同版移动WIKI·界步练师](https://wiki.biligame.com/msgs/%E7%95%8C%E6%AD%A5%E7%BB%83%E5%B8%88)与[移动WIKI·追忆](https://wiki.biligame.com/msgs/%E8%BF%BD%E5%BF%86)都给出死后追忆：可选一名其他角色，但排除杀死自己的角色，摸三张并回复1体力。[官网2015普通步练师攻略](https://www.sanguosha.cn/pc/news-detail-37.html)也有相同追忆正文，但它的安恤是旧普通版，这里只作为追忆的官方历史旁证，不借它替换当前安恤。

不采用 OL 当前界步练师的“自己拿两人各一张，再展示交牌”，也不采用结束阶段提前固定追忆受益人的 OL 规则；追忆必须在实际死亡时选人。

## 安恤的参与者与结算

- 第一个目标是获得者，也是实际私密选牌者；第二个是牌的原持有者。两人都不是步练师且彼此不同，原持有者须有手牌或装备牌。没有手牌大小顺序限制，获得者可以本来就比原持有者手牌更多。
- 未指定区域的获得牌按通常角色的牌限定手牌和装备区；判定区牌不属于该角色的牌，不扩到判定区。原生选择隐藏手牌时使用不含实体ID的槽位；公开装备正常按实体选择。
- 获得通过现有原生 Obtain 执行，包括其 Processing 中转。原帧在真实源区离开和真实到手时冻结两笔移动凭据；源区判断不是读移动完成后的当前位置或物理牌类别。装备牌原来在手牌区也会满足非装备区来源；装备区牌转成手牌也不会反过来获得步练师摸牌奖励。
- 原生移动、失装备回复及得失牌子技能全部返回后，才执行步练师的非装备来源摸牌。该牌在得牌孩子中又被移走，不会抹掉原来真实获得过的事实。步练师摸牌的孩子完成后，再比较原来两人的真实当前手牌数并选择是否追加摸牌。
- “较少”按严格小于处理。相等时没有较少者，不任选一人补摸；在找到的官网和同版WIKI中未见“相等可任选”的补充裁定，因此此项是依原文字义采用的工程解释，非额外官方FAQ。若取得被原生替换为未到手，不制造本次获得后的奖励。

## 机制与检查

真实取得牌、原生摸牌、选项、死亡时选人及回复都复用既有 DSL。两个窄操作只冻结实际来源奖励见证并将原目标对窄化为较少者；没有另建付款或并行pending。追忆沿用原生 `ownerDied`、`otherLivingExceptSource`、摸3和回复1。

行为检查覆盖获得者实际私密选择、获得者手牌较多时也可发动、牌被得牌孩子移走后仍按手牌来源奖励、原帧冷恢复、取得白银狮子后的原生回复及真实手牌比较、相等无较少者，以及真实死后追忆排除击杀者、摸牌孩子冷恢复后回复。共享隐私和技能变更机制矩阵不在此重复。
