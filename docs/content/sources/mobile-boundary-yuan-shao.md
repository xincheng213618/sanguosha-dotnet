血裔完整复用 `classic:xueyi` 的存活其他群势力人口与主公资格，不采用 OL 界袁绍的“裔”标记、初始群人口标记或出牌阶段起始消标摸牌。乱击独立为 `boundary:luanji-mobile`，不复用 OL 同花色两牌或减少万箭一个目标，也不采用谋袁绍每阶段一次及自己摸牌上限三次的版本。

任意两张真实手牌均可成为万箭材料，可以花色相同或不同；一张材料的花色一旦在本实际回合用于发动乱击，后续乱击材料不能再用该花色。只在实际用牌接受后消费原 turn 范围账本，目标或声明失败不提前扣除；同一次两张同花色只登记一次，两个不同花色分别登记。合法动作及命令验证沿同一花色过滤，实际新回合才重置。

花色支付订阅真实 `ProgramViewAsConvertedEvent`，再按原 FrameId 反查原万箭实际使用、转换链技能实例及两张原手牌材料，必须与已付款转换事实完全对应。普通锦囊的 `CardActionAcceptedEvent` 是否发布还取决于当局是否有最终目标订阅者，不能依靠这一可选窗口来记录必须发生的乱击花色支付，也不同时监听两个事实重复扣除。

真实万箭的闪响应结算完成后，沿原生 `cardResponseCompleted`、原父万箭实体及实际打出者给予一张真实摸牌；不要求万箭一定来自乱击转化，也不把别人的万箭、其他牌的闪或无实际响应当作资格。全牌尾奖沿 `cardUseCompleted` 的单次实际使用窗口，以冻结的本牌是否造成过伤害及原指定目标数决定，不按目标逐人重复开奖，也不按本回合所有伤害推断。

所有奖励用原生摸牌孩子和原乱击程序帧的付款续接；冷恢复继续核对原父牌、原技能实例、指令、受益者及实际移动，不能重复摸牌。新增代表检查以固定场景真实使用两种花色、真实闪响应和全牌结算完成，并验证一次已付摸牌孩子恢复。血裔与普通万箭结算继续沿既有共享覆盖。
