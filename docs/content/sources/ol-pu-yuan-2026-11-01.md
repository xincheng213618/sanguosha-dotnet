# OL 蒲元：神工、奇思与锻造装备

2026-11-01 对照用户截图和公开的 [OL 蒲元规则及问答](https://wiki.biligame.com/sgsol/%E8%92%B2%E5%85%83)、[神工](https://wiki.biligame.com/sgsol/%E7%A5%9E%E5%B7%A5)、[神工装备一览](https://wiki.biligame.com/sgsol/%E8%92%B2%E5%85%83%E7%A5%9E%E5%B7%A5%E7%BB%93%E6%9E%9C%E4%B8%80%E8%A7%88) 和 [4399 的 OL 攻略](https://my.4399.com/yxxsgs/ziliao/48991/)。这是公开页面的规则口径，不表示已经登录线上服务器验证。

## 已确定的规则与本地选择

[官方武将页](https://www.sanguosha.com/hero/510) 的蒲元技能正文与截图一致；立绘使用同一官方武将资源，来源和摘要记录在通用美术目录。

- 蜀，男性，4 体力；技能为神工、奇思。没有加入截图中属于模式的重生、护甲或洗练特质。
- 神工在每个实际出牌阶段按武器、防具、坐骑或宝物三组分别限一次；材料来自本人手牌或装备区。坐骑与宝物共用次数，产物都是宝物。
- 用户明确要求暂不实现助力、妨害小游戏，改由发动者选择“完美锻造／锻造成功／锻造失败”，分别随机观看 3／2／1 件对应装备，然后选择一件及其装备对象。候选只抽取一次，取消重开、存档续接不能重抽或重复支付。
- 装备的身份与寿命属于实体来源，不属于牌名。神工装备从装备区转移到别人装备区、进入手牌或牌堆均保留；实际进入弃牌堆时销毁。无双商店的离开装备区销毁规则保持独立。
- 依当前规则的“一张或多张”口径，一批销毁于本回合结束阶段摸一张，独立批次可叠加；不是每回合只摸一次，也不是同一批按实体数累加。旧攻略逐张叙述不能覆盖当前规则中的批次限定。
- 奇思开局只从当前牌堆取两件不同副类别装备并置入装备区；摸牌阶段可少摸一张，声明武器、防具、坐骑或宝物，从当前牌堆或弃牌堆中随机获得。坐骑按截图合为一类；不会凭空领取锻造库装备。

## 锻造库

每种牌面在锻造库中只有一项；已由该库生成且仍在游戏内的同名实体不再进入候选。销毁后可再次锻造；其他模式或牌堆中的普通同名装备不占用神工来源。

装备效果复用已有装备定义及共享技能。补充的六件装备使用同一装备授技层；天机图的离区触发在移动开始时冻结有效来源，只给自己的原移动窗口授权，不把已失去的技能伪装成继续持有。
