# 蹋顿·移动版

核对日期：2026-10-26。独立身份 `mobile:ta-dun`，群势力，男性，4体力，SP武将组4；经典形象画师NOVART。

规则来源：[移动官网198](https://www.sanguosha.cn/pc/hero-detail-198.html)、[移动版BWIKI蹋顿](https://wiki.biligame.com/msgs/蹋顿)（当前页面版本 oldid=8119，2022-06-03 更新）。BWIKI注明正常消耗400将魂合成或招募获得，页面另外列出缘蹋顿歧义入口，本实现采用普通蹋顿的已公开正式规则。

乱战仅在自己实际造成伤害后获得1枚标记，按每次伤害事件计，不按伤害点数计；仅受到别人造成的伤害不获标，自伤因自己仍是伤害来源而获1枚。使用杀或有效黑色普通锦囊牌时可以额外选择至多标记数名合法目标，最终指定目标角色数不足当前标记数时移去所有标记。移动官网与当前移动BWIKI对此实质一致。

现有 `ol:luanzhan` 同时因造成或受到伤害获标，目标不足时仅移除半数且向上取整，因此移动版使用独立 `mobile:luanzhan`。获标声明现有 `damageSource` 触发主体；追加目标复用 `addDamageMarkerBudgetTargets`，以可选 `shortfallPolicy: removeAll` 声明移动版清空规则。省略该配置的OL程序继续使用原半数规则。

追加额度在原用牌询问时冻结，完成整个指定目标窗口后按真实有效目标角色数和当时标记数量判定清标。目标合法性、借刀目标对、原生杀和锦囊结算、技能实例与动作来源、集合冻结及冷恢复均复用现有DamageTargetBudget流程；不复制多人用牌机制或新增待决状态。清标策略从内容hash匹配的原来源节点读取，失去技能不撤销此前签发的目标调整与最终扣标。
