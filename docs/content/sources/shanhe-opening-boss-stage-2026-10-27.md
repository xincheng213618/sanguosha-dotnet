# 开局伤害与首领二阶段

本地三章首领遵守第一阶段体力打空后进入第二阶段的规则。此前转换限定真实回合数大于0，导致开局摸牌引发的伤害可以跳过第二阶段。实际组合可用筹备2064/2065/2066摸到六张牌，神龙摆尾Ⅱ2143触发基础1点伤害，再由技艺Ⅱ2172、Ⅲ2173共加5点，打空5体力的第一形态。

开局转换原席替换首领形态并发放配置的补牌，保留原开局窗口、已付摸牌和后续候选，继续处理完整开局。不制造第0回合结束，不重发已经处理过的初始牌或战法初始化，正常首回合顺序保留。回合中打空第一阶段继续沿原模式中断流程，清理已付牌和旧结算树，再开始首领的新自然回合。

两条路径共用一次性形态标记。行为检查使用真实两形华雄和六件生产战法，分别检查开局致命伤害与回合中致命伤害；第二形态仍正常死亡并结算胜负，不执行存档恢复。
