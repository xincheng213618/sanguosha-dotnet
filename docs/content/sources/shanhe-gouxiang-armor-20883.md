# 钩镶

来源为[官方公开配置包](https://web.sanguosha.com/220/h5_2/res/config/Config.sgs)的 `sys_playcard.sgs / GamePlayCards.card`：实体行 `a=20883,b=钩镶,c=3,d=2,m=14088,p=GouXiang,f=2,g=3`，即防具、2点、花色编码3。按本地既有映射 `3=梅花` 安装为真实梅花2防具。该解码成员 SHA-256 为 `05584b30f7986c06158ee6e47f78417b3d5f1c7fbc61174cfad26e12a5ee64ab`。

同包 CardBook 的 `Name=钩镶,res=GouXiang` 给出的规则是：锁定技，使用与【杀】同花色或同点数的【闪】响应后，获得对方随机一张手牌。牌册此条的逻辑 `cardid=20833` 与实体行不同，未用它替换来源固定装备 `20883`。花色相同与点数相同为“或”，仅同颜色不满足条件。

实体内容为 `shanhe:gouxiang-armor-20883`，装备授予技能 `shanhe:gouxiang-armor-14088`，实例来源 `equipment:shanhe-gouxiang:<实体编号>`。装备进入、离开和防具失效沿既有原生装备合同处理。它不因仅出现在手牌中就授技。

规则使用每张原生【闪】的 `cardResponseCompleted` 窗口，核对原【杀】父行动、实际响应者和防具实例。原【杀】沿既有原生行动外观捕获；【闪】的有效花色由既有 `FreezeCompletedResponseUseSuit` 在付款前冻结，声明牌另外优先读取原付款收据的花色和点数。普通单实体牌缺少专门点数时，使用该实体不可变的原点数；不在移入处理区后重新计算花色。已有转换与专门规则提供的有效外观优先。没有明确有效花色或正点数时，不把 `None` 或0当成相同值。由其他角色替主公打出的供牌、万箭齐发的响应和没有可比外观的虚拟响应均不借用普通【杀】的来源。

符合条件后，从原【杀】使用者当时剩余手牌中随机取得一张真实实体；随机选择与原子得牌继续使用引擎原生随机数、移动批次和得牌子窗口。双闪要求下，每一张真实【闪】各自完成并可各取得一张，结算始终回到同一个原【杀】。青釭剑等无视防具、当前回合禁甲或装备已离开时不触发。

独立前向检查覆盖同花色、同点数、仅同颜色、无双双闪、真实青釭剑、真实回合禁甲和实际替换防具，核对逐次响应、实体付款、随机取得来源与原【杀】一次完成；不完成整场战斗。
