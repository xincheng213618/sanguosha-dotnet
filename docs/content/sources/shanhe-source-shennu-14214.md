# 山河图源版神怒（14214）

来源为[官方配置包](https://web.sanguosha.com/220/h5_2/res/config/Config.sgs)的 `cha_spell.sgs / GameSpells.spell / a=14214`，资源名 `ShenNuRogue`。`hd_roguelike.sgs / Root.General / a=268701` 将它授予“篡天恶魂”第二阶段。

原文：锁定技，你每次受到伤害时，你将累计1枚“怒”并摸X张牌；当你造成伤害时，每有1枚“怒”，此伤害+1，造成伤害后你丢弃所有“怒”标记。（X为伤害来源当前体力值）

本地使用独立技能身份 `shanhe:source-shennu-14214` 和独立公开标记 `ShanheSourceNu`，显示名为“怒”，不与其他神怒、暴怒或 Rage 共用标记。仅山河图模式且有实际山河图战斗配置时生效。

受伤效果由每次实际伤害的濒死处理前窗口发行；一段三点伤害也只加一枚怒，不按伤害点复制触发。摸牌采用本地执行边界：本次原伤害窗口开始结算神怒时，冻结其真实伤害来源当前体力。来源不存在、体力未定义或当前体力不大于零时摸零张；不借用用牌者或当前回合角色。官方客户端缓存只提供锁定技及标记展示，没有服务器摸牌算法，因此这一采样与零值处理明确作为本地约定。

伤害加成复用原生伤害金额层与公共预测；已经定额的链式传播和伤害转移不再次追加同一份怒。加成不会提前清标记。被防止的尝试没有实际伤害框的付款回执，因而不会清怒。

每次实际伤害应用时，在原 `DamageFrame` 冻结真实来源、原攻击编号、技能实例及伤害身份，怒为零也发行回执。该原框的 `AfterDamageEvent` 到来后再清除其来源角色全部怒，不随中间反伤、来源死亡或失去技能重新选择其他角色。自伤也按受伤先加一怒、原伤害结束再清怒的顺序结算。

回执在文移等已付款体力变化子流程暂停前发行，避免子流程直接返回伤害窗口时跳过后序钩子而漏清怒。回归检查通过真实伤害将目标由三体力降至一体力，进入原生文移提示，合法放弃后验证原体力变化子流程返回、原伤害框恰好清怒一次。

定向前向检查覆盖三点与两点受伤各只加一怒、按五体力真实来源摸牌、每张真实摸牌孩子的原框返回、两怒真实加伤与公共预测一致、首伤被防止后保留怒，以及初始零怒自伤后的加怒与清怒。实际造成伤害后的嵌套反伤会先获得第三枚怒并按反伤来源的十七点体力摸牌，十七个摸牌孩子全部返回后，再由原伤害回执一次清除三枚怒。
