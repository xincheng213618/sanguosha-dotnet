# 移动版界曹彰

规则依据为[三国杀移动版官网界曹彰369](https://www.sanguosha.cn/index.php/pc/hero-detail-369.html)，核对日期2026-10-25。当前完整将驰：出牌阶段开始时，可以选择摸一张牌且本阶段不能使用杀，或弃置一张牌且本阶段杀无距离限制并可多使用一张杀。两项均可不选。

本版为 `boundary:cao-zhang-mobile`、`boundary:jiangchi-mobile`、`boundary-mobile` 变体、`sanguosha-mobile` 规则集，魏、男、4体力。与仓库 OL `boundary:cao-zhang` 的摸牌阶段结束、重铸、整回合次数调整和杀不计手牌上限明确分开。

抽牌与真实HE弃置复用原生 DSL，原始 `ProgramSkillFrame` 在操作前记录真实出牌阶段 token 和次数账期，等待原生摸牌或付款子窗返回后才发行本阶段效果。弃牌分支有实际实体、来源牌区、移动原因和原帧来源证明，不采用重铸。无另设 pending 或付款系统。

已发行效果绑定实际出牌阶段，下一额外出牌阶段或本阶段结束即失效，不跟随源技能的后续失效而提前撤销。进攻分支通过原生次数查询提供一次额外杀，并注册现有 `ProgramDistanceRule` 的杀使用、转换及实体/虚拟/借用等杀距离路由；守势分支禁止实际使用杀，连弩不能绕过，决斗等纯打出杀不因此禁止。

行为检查通过真实准备前额外出牌阶段及随后同回合正常出牌阶段比较期限：守势验证连弩仍不能使用杀、决斗可真实打出杀及源失技后持续；进攻验证白银狮子真弃置回血后的原母帧付款子窗冷恢复、两次真实远距杀及第三张受原生次数约束，随后正常出牌阶段恢复普通距离与一次额度。共享选择、授技变化和付款底层检查不逐人物复制。
