## 原生规则与续接

咆哮以本人的真实出牌阶段内已声明杀为依据，普通、转化、虚拟和提供牌沿同一原生距离管线；正在验证的首张杀不能把自己的声明当成先前使用。不限次数仍复用原生杀次数修饰。

厉勇只在真实杀被足额实际闪抵消后记录本阶段的一次资格，不把未命中、其他取消或已禁止闪抵消的杀视为发动依据。下一张实际使用的杀在原生提交时消耗该资格，权利直接保存在原 `CardUseFrame`，逐目标用原生非锁定技抑制及最终目标杀伤害收据执行。多目标不会另取一张杀的资格，重复抵消也不叠成多份伤害。未消耗资格随原实际阶段失效；已提交的原用牌权利不会因为后来失去技能而重新付款或更换来源。

每个原指定目标实际受到此杀的直接伤害且存活后，才在独立的原 `ProgramSkillFrame` 中自失一点体力。原生HP付款回调先封存实际付款，再处理身份、HP变化、濒死及其类型化孩子；孩子返回沿同一原帧续接，已经支付的HP不再重复支付。伤害被改为失去体力、目标未受伤或已经死亡时不发行该次罚付。连环传导遵循既有原生传播合同，不另给非指定目标发行此杀的逐目标权利。

新操作只提供该版本的取消资格、原用牌权利及罚付衔接，定义形状在加载时集中验证；没有新增规则版本、独立pending或以使用ID为键的旁路状态。通常加伤只在原目标收据消费一次，牌伤害替代层与公开预测读取同一收据，不重复写入通常伤害。
