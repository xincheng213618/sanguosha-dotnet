# 逆京枭雄的地图与集市接线

来源为[官方公开配置](https://web.sanguosha.com/220/h5_2/res/config/Config.sgs)的 `hd_roguelike.sgs` 主组2684。角色605是谋董卓，称号“逆京枭雄”，原基础当前／最大体力20/20，随机起手4张、摸牌2张。原地点为崤函道区域14的关底5148，最低来源难度16。来源入口保留单阶段，不继承本地征程的第二形态。

`att_LY="exshatimes,1;getarmor,1"` 沿既有累计成长处理，固定装备 `equip_KN=20841` 昆仑镜、`equip_EM=20836` 断魂在该地点实际开放时均已具备，按既定合同额外进入手牌。敌军表花色采用用户已确认的本地映射：1黑桃、2红桃、3梅花、4方块；因此为黑桃Q昆仑镜及黑桃5断魂，不将这一约定称为已解码的官方图例。

同组技能为观变3513、凶逆14206、封赏14207、执柄14208。后三个专版技能与普通谋董卓3514／3515／3516分别实现，不能按同名替换。来源 `h=100` 没有已核实的特殊头像映射；使用同角色605的已核实默认60500素材作为明确回退。

默认推荐的三章征程同时提供独立候选 `luoyang:mou-dongzhuo-source-native`。令 `g=本地难度-1`，其第一形态当前／最大体力均为 `20+4g`、额外随机起手 `1+g`、摸牌阶段额外摸 `1+g`，固定装备额外进入手牌。击败后进入已有篡天恶魂，体力同为 `20+4g`、补牌 `3+g`、摸牌加成 `1+g`、额外出杀1，并安装红桃Q修罗炼狱戟与梅花2玲珑狮蛮带。这一两阶段组合及三档成长明确属于本地编排；它不附带来源难度或来源城市，不声称原2684有这套阶段关系。

[公开图鉴商品表](https://s.xiaochao.org/data/cards.json)的4144断魂、4145昆仑镜均为红色等级4、600铜币，分别黑桃5和黑桃Q。本地按这些商品行加入推荐征程与来源入口所用的山河册集市货池；无已核实的固定研习节点，两件采用既有默认货池。商品实体20824／20825与敌军表20836／20841分别保留，凭同名、同资源及同规则核对，不混同编号。牌面来源与原图保真处理见[卡牌素材](../card-artwork.md)。
