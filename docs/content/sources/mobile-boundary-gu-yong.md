# 移动界顾雍

核对日期：2026-10-24。规则来源为[三国杀移动版官方界顾雍页（432）](https://www.sanguosha.cn/pc/hero-detail-432.html)的完整技能正文。采用吴、男性、3体力的移动界身份 `boundary:gu-yong-mobile`，与经典版及OL版分别注册。

慎行在当前实际出牌阶段内最多使用当前体力值次；体力变化后重新计算可用上限，已使用次数仍由现有阶段账本累计。支付为两张手牌或装备牌。付款之前读取原实体的有效颜色并固定收益，随后复用原弃牌与原生摸牌节点；同色摸一张，异色总计摸两张。弃牌子窗不重新支付，也不从已经进入弃牌堆的牌重算颜色。

秉壹在自己的结束阶段可展示全部非空手牌；展示时固定实体、颜色/类型资格与手牌数。只要颜色全部相同或类型全部相同，即可选零至手牌数名存活角色，包含自己；基本牌、锦囊牌（含延时锦囊）和装备牌按三大类型判断。展示不能成功也已经公开全部手牌，但不会继续要求选择收益目标。

全手牌绑定、展示、具名绑定数量的目标选择和各目标摸牌沿用现有程序能力。展示后的手牌增减、自己被选中后先摸牌，以及摸牌触发子窗均不会增加冻结的目标额度或重复已经结算的目标。新增操作只固定本版资格，未引入另一套待结算对象。
