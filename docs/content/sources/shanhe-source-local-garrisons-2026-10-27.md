# 配置复现入口的本地前战与精英支路

官方路线与战斗池目录见[当前S5配置](https://web.sanguosha.com/220/h5_2/res/config/Config.sgs)；地区连边、城市身份和已核首领来源继续沿用既有目录。普通池的服务端资格条件尚未完整执行，本次组合属于明确标注的本地编排，不增加或借用SourceBattleId。

每个实际前战城市有四种不同敌将组合：第一章一至两人、第二章两至三人、第三章三至四人。原步卒、弓手、卫士之外，增加4体力且使用急救的军医、4体力且使用武圣的赤刃卒、6体力且使用英姿的校尉；三者均复用既有技能。普通驻军的额外起手牌为章数减一，第三章另加一张摸牌。普通前战保留实际SourceCityId，洛阳2397木鹿阵仍只使用原有城市资格和来源。

每个来源区域增加一处可选本地精英军营，从区域市场入口与普通前战并列选择，前两章接营地、第三章接既有奇遇。精英依章数为二、三、四敌，额外体力上限和起手牌各为章数，额外摸牌与用杀各一，基础胜利金200；战利品可选择稀有战法或技能奖励。精英没有官方城市或战斗编号，不能因此完成城市来源任务。

每场仍按玩家、同行与敌军合计最多八座执行，沿用既有同行入场容量分配。关底阵容和原二阶段的难度门槛没有调整。配置检查关注真实组合和支路接线，原生检查从预览到地图进入、建立战斗并启动，不以完成战斗或兼容性流程替代验证。
