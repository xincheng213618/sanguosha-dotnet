# 移动版界廖化

## 来源与版本

- [三国杀移动版官网：界·廖化，370](https://www.sanguosha.cn/index.php/pc/hero-detail-370.html)，核对日期：2026-10-25。官网完整给出当先和伏枥正文。
- [移动版 BWIKI：界廖化](https://wiki.biligame.com/msgs/%E7%95%8C%E5%BB%96%E5%8C%96)，页面标注更新日期 2026-05-02，身份版正文与官网一致。采用蜀势力、男性、四体力的身份版，未混用该页面另列的国战版。

独立武将 `boundary:liao-hua-mobile`，当先 `boundary:dangxian-mobile`，伏枥 `boundary:fuli-mobile`；变体为 `boundary-mobile`，规则集为 `sanguosha-mobile`。

## 实现

当先在自己回合开始、正常准备阶段前，锁定地从弃牌堆选择一张真实的杀获得，然后使用已有 `insertPhase(play, beforeNormalPreparation)` 执行额外出牌阶段。杀的范围沿原生杀分类，包括属性杀；多个候选由本人选择，只选择仍在弃牌堆的实际实体，不访问牌堆。没有杀时获得部分无牌可得，仍执行后续额外阶段。这里没有 OL 版的牌堆来源选项、额外距离权限和阶段内未伤害导致自伤。

弃牌候选、选定实体和付款账单均在原当先帧；真实移动后先完成获得牌触发的子窗，再通过原生 typed movement return 继续阶段插入。付款证明精确绑定程序、技能来源、原指令、原实体、弃牌堆到自己的手牌、移动批次和序列范围。确认前未移动，子窗期间读档不会再取得同一张牌。

伏枥沿现有 `selfDyingResponse` 的限定技次数合同。实际发动时，`recoverTo(livingFactionCount)` 计算存活角色当前有效势力的种类数，交给原生回复流程；回复金额在实际回复尝试中保存，并受体力上限约束。回复及其所有原生子窗结算完毕后，独立操作比较当前体力与其他存活且具有体力值的角色，只有严格大于每一名其他角色才翻面。并列最高不翻面；比较不是发动前的快照，也不使用旧版伤害统计，不摸牌。

## 必要检查

新增当先检查使用公开 API 将两张手牌真实弃置，获得其中一张，在实际获得牌子窗暂停并冷恢复，然后确认额外出牌阶段早于准备阶段且回归正常阶段；同时验证空弃牌杀池仍执行额外阶段。

伏枥检查从真实负体力濒死回复至四势力数，保留六点实际上限以区别回满；在回复子窗冷恢复后继续。另一分支让该子窗真实治疗一名其他角色，使其与廖化并列，验证翻面比较使用子窗后的当前体力。共享次数、隐私和存档矩阵不另行复制。
