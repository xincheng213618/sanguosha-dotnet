# 移动版界严颜：拒战、乘势

核对日期：2026-10-24。内容标识 `boundary:yan-yan-mobile`，初始蜀、男性、4体力；完整拒战为一个转换技能 `boundary:juzhan-mobile`。

## 来源与解释边界

- [移动版官网界严颜667](https://www.sanguosha.cn/pc/hero-detail-667.html) 是本版正文来源。官网分别描述阳状态的成为杀目标事件、阴状态的使用杀指定目标事件；两态都有本人身份条件与当前状态第3次的全局条件。官网另给出乘势的出杀次数增加及原杀结算后取得效果。
- [移动版BWIKI技能概念介绍](https://wiki.biligame.com/msgs/%E7%BB%93%E5%85%9A) 的乘势术语说明将其解释为同时满足技能各分支触发条件。该页为社区规则汇编，并非本武将的官方FAQ。实现据此把本人身份与当前状态恰好第3次同时满足作为乘势条件；先选择发动拒战，再强制执行额外收益。
- 官网没有把额外出杀次数限定为本回合或本阶段，因此实现保留可累计的持久次数，不加入文本未出现的期限。该期限选择属于依正文所作的规则解释，不宣称官网另有本武将FAQ。
- 不采用将任意角色第3次都直接视为乘势、或擅加仅本回合次数的攻略；也不采用自称AI生成的攻略作为依据。不以经典版两态拒战替代本版的全场计数与乘势。

## 采用的事件语义

初始势力为蜀时注册为阴；其他初始势力注册为阳。判断使用人物初始定义势力，不随局中势力变更重置转换技。通过原生结构化转换状态切换，每次实际发动建立新的状态周期；每个周期从0计数。

阴以整次实际使用杀并指定目标为一次，即使同一杀有多名目标也只计1。阳以实际逐目标成为杀目标的事件分别计数。两者均保留原生整次Use与当前目标事件的区别，实体杀、转换杀及虚拟杀使用相同生命周期。放弃第3次后计数继续4、5等；第4次不会按模3再次获得全局资格，本人仍可依其身份条件发动。

阴发动时从原杀的当前目标中选1名具有可取得牌的角色，取得其一张手牌或装备牌。这里复用项目中“获得其一张牌”的手牌/装备区域规则，不将未写“区域内”的文案扩张到判定区。完成后记录本人至该目标的本回合定向用牌禁止。阳分别令本人、原杀使用者摸1，即使两者为同一人也执行两次摸牌；完成后记录使用者至本人的本回合定向禁止，同一人情形使用已有自身目标禁止机制。

乘势在拒战完成后向原Use签发一次领取凭据。额外出杀次数立刻通过原生规则查询贡献生效；实体领取必须等该整次杀正式结算完成，不在首次目标、伤害或闪响应后提前取得。领取仍处于处理区或弃牌堆且未被其他合法领取消耗的原始实体；纯虚拟无实体杀只加次数，不制造实体牌。多个实体转换杀按其原始材料领取。

## 实现与恢复

普通取牌、摸牌、转换提交和定向禁止复用现有程序节点/原生助手。仅增加当前状态事件计数、两条件同时满足的乘势签发和完成Use后的原实体领取。当前待付/已付数据分别留在原拒战程序帧、原完成窗口程序帧和原CardUse帧；不用平行pending或use-id侧表。完成领取的移动等待有精确来源、原Use/action、原实体、起止位置、原因及序列区间证明，返回原程序帧后继续，不重付。

公开状态为当前状态次数和已取得的持久出杀次数；界面明确显示阴/阳、计数与出杀加成，不将其显示为觉醒进度。

行为检查 `BoundaryYanYanMobileChecks.StateEpochThirdSelfChengshiOriginalUseClaimCold` 和 `YangTargetOccurrencesAndDirectedTurnBanCold` 通过真实固定实体牌局检查多目标整次/逐目标区别、恰好第3次、两态乘势、定向禁止期限及取牌/结算领取付款后的冷恢复。沿用已有Core过滤器注册，不新增人物专属运行器。
