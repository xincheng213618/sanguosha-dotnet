# 岑昏·移动版

核对日期：2026-10-26。独立身份 `mobile:cen-hun`，吴势力，男性，3体力。

规则核对：[移动官网221](https://www.sanguosha.cn/pc/hero-detail-221.html)、[移动版BWIKI岑昏](https://wiki.biligame.com/msgs/岑昏)（页面版本 oldid=35661，2026-01-08 更新）。BWIKI把本将列入正常武将包“乱世英杰-2016”，注明消耗300将魂合成；所采用的是已公开正式版本，并非测试服或爆料版本。

官网极奢旧文要求手牌上限大于1；当前移动版资料为大于0。因此本实现保留在上限恰为1时仍可发动的规则，摸一张真实牌后令本回合上限减1。结束阶段手空时选择零至当前体力值名角色横置。使用独立 `mobile:jishe`，复用现有摸牌、回合手牌上限修正、选人和连环状态节点；与 `classic:jishe` 的程序差别仅为选人下限从1改为0，明确允许接受发动后仍选择零人。

链祸的当前移动文本与 `classic:lianhuo` 完整一致，直接引用现有技能：连环状态下受到火焰伤害且属于传导起点时增加该伤害，不对后续传导重复作为起点加伤。
