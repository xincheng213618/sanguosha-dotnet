# 移动版界刘禅：享乐、放权、若愚

核对日期：2026-10-25。正式内容标识 `boundary:liu-shan-mobile`；蜀、男性、3体力。三技能分别使用 `boundary:xiangle-mobile`、`boundary:fangquan-mobile`、`boundary:ruoyu-mobile`；觉醒取得现有 `classic:jijiang`。

## 来源与本版差别

- [移动版官网界刘禅297](https://www.sanguosha.cn/pc/hero-detail-297.html)，亦可从[官网同页入口](https://www.sanguosha.cn/index.php/pc/hero-detail-297.html)读取。当前身份/国战页给出享乐基本牌支付、放权跳过出牌并令本回合手牌上限等于体力上限、回合结束可弃手牌给其他角色完整额外回合，以及若愚加上限/回复/取得激将。
- [官网攻略《界刘禅武将解析》](https://www.sanguosha.cn/pc/guide-info-114.html)，2020-06-30。该攻略直接比较经典放权与界放权，指出残血时依旧按体力上限留牌，并说明额外回合包含完整行动机会。当前技能页为规则主来源，攻略仅辅助核实本版差异。

## 实现采用的语义

享乐沿用已存在的原生杀逐目标窗口与 `nullifyCurrentCardEffect`：由原杀使用者选择弃置一张真实基本手牌，支付完成后原杀照常进入该目标的闪响应；不支付则只令原杀对刘禅无效。它不是不可响应、假闪或直接减少伤害。支付等待真实移动子窗口完结，冷恢复返回原刘禅技能帧，不重付使用者的基本牌。

放权复用跳过出牌阶段、公示布尔状态、回合结束手牌支付及原生其他角色额外回合队列。声明和付款保留既有两节点/四节点组合，因此继续使用共享放权AI估值；仅为本版添加手牌上限最终查询阶段。发动后每次查询读取当前 `MaxHp`，而不是冻结发动时数值或增加固定已损失体力数；之后失血、回复和体力上限变更都不能令其偏离当前体力上限。该动态处理是对“本回合等于体力上限”的直接实现，官网并未另给数值冻结规则。

回合状态使用现有 `resetScope:turn`。已发行手牌上限效果查询原生布尔状态键，不依赖当前活跃技能列表；因此发动后正常失技不会提前取消本回合已发生的手限效果。进入下一实际回合时由原生回合重置清除，包括已排队的额外回合。手牌上限最终阶段位于现有安国之后、既有韩嵩特殊覆盖之前，保留既有更外层特殊优先级；本效果自身的数值不叠加其他普通手限增减。

若愚使用准备时的当前最小体力比较，包含并列最小，须具备主公资格，且一局只觉醒一次。增加体力上限、回复、永久技能取得全部复用现有操作及 `GameEngine.ProgramSkillChanges.cs`。所获激将是已有的真实蜀势力供杀机制，供牌者和原使用/响应者保持独立；不复制另一个技能实现，也不只在武将牌上显示名称。

`FangquanDynamicMaximumHandLimitPaidExtraTurnCold` 检查残血声明、回合内真实上限变更、实际弃牌保留数量、已付手牌的冷恢复、完整额外回合与自然回合续接。

`LordRuoyuGrantsRealJijiangUseAndResponseCold` 检查主公并列最小觉醒、共享技能取得，以及获得后真正由其他蜀角色供牌的出杀和决斗杀响应。沿用既有Core过滤器；无人物专属运行器，无新的平行pending或纯定义快照检查。
