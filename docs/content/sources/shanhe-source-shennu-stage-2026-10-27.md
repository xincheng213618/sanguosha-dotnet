- 技能：`e8885a11c46c3b25f37a6fcd8882b0d339ab1d1873c140900d3be93826fdd219`。
- 牌：`05584b30f7986c06158ee6e47f78417b3d5f1c7fbc61174cfad26e12a5ee64ab`。

所用公开配置缓存外层 SHA-256 为 `d663d5542f5a63a61611b5dbc1ae736e5e0328eedaab2c498e18c3287c289ce6`；它与地图记录的另一外包不同，但相关地图成员完全一致。[官方客户端](https://web.sanguosha.com/220/h5_2/sgsGame_a.sgs)的分档算法按基础值累加各档字段，不只读取当前档。

## 身体与实际入口

主组 `2687` 的 `w="268701;1"`、`inStage=1` 明确指向 `inStage=2` 的 `268701`；`CanStage` 包含来源难度 `3–25`。实际关底城市 `5148` 位于第十四来源区域崤函道、本地第三章，该区域从难度 `16` 开放，因此实际来源入口完整提供 `16–25` 的这组两阶段战斗。

第一阶段继续使用既有改朝罪魁：基础 `10/15`、摸牌 `2`、随机起手 `4`，拥有来源 `14210 酒池`、`14211 肉林`、`111 崩坏`、`952 盗书`。酒池、肉林、盗书均复用既有山河专版，崩坏复用 `boundary:benghuai-current`，不混入并列战斗 `22687` 的 `5/10` 数值或普通同名技能。

第二阶段为独立的篡天恶魂，基础 `20/20`、摸牌 `2`、随机起手 `4`，仅有 `14214 ShenNuRogue 神怒`与 `111 崩坏`。来源通用身体编号 `4871` 不能用来继承其他同编号敌军的技能。进入第二阶段沿现有山河图致死替换与阶段发牌合同，替换值来自该阶段自己的数值行。

阶段身体按新模板绑定自身声明的神怒与崩坏，本场已取得的独立技能来源另外保留。撤销旧崩坏来源不代表永久禁止再次取得同一技能；第二阶段明列 `111 崩坏`且没有删技字段。因此新模板可以重新绑定崩坏，同时保留原来取得的再起来源与实例，不清空独立授予，也不把旧来源的撤销扩大成对技能编号的永久禁授。

## 分档累加

| 来源档位 | 第一阶段基础行的附加值 | 第二阶段附加值 | 第二阶段累计装备 |
| --- | --- | --- | --- |
| 中等 `6–10` | 体力与上限各 `+3` | 无 | 无 |
| 困难 `11–15` | 保留前述值 | 无 | `20656` 修罗炼狱戟，红桃 `Q` |
| 噩梦 `16–20` | 保留前述值，摸牌 `+2` | 无 | 再加 `20626` 玲珑狮蛮带，梅花 `2` |
| 炼狱 `21–25` | 保留前述值，出杀次数 `+1`、每轮护甲回复 `+1` | 出杀次数 `+1`、每轮护甲回复 `+1` | 保留两件装备 |

这些是 `att_*` 原字段对各自基础身体的增量，独立于战斗日、章节、人数等来源成长。第一阶段无固定装备；第二阶段装备按原生阶段合同安装为真实实体。花色沿既有来源映射 `2=红桃`、`3=梅花`；牌面原字段分别为 `f=12,g=2` 与 `f=2,g=3`。两件装备及其技能均复用现有原生实现。

两阶段没有 `getspell_*` 附技或删技字段。神怒与崩坏在各档均为同一组技能，不因当前档位重新选取，也不额外添加动荡、神躯或其他首领技能。

## 神怒

来源 `14214` 的主文是：每次受到伤害累积一枚怒并按伤害来源当前体力摸牌；造成伤害时按怒数加伤，造成伤害后清除全部怒。它按每次伤害计数，不按伤害点数计数；不能用已有暴怒标记、其他神将技能或数字别名替代。来源体力的采样与伤害前后返回由独立神怒原生流程承载。

真实阶段检查使用来源城市中的阵容与阶段配方，通过二十点合法原生伤害击穿第一阶段，验证独立 `20/20`、两件装备实体与新首领的实际出牌。该小型原生检查明确保留原分档字段，但不安装征程层的额外成长；来源成长由既有征程配置与共享机制负责，不将检查中的基础面板冒称为完整征程最终数值。

同一检查以未换技的十六档作为对照，二十一档先由原持有者合法发动共享技能替换，确认旧崩坏来源实际移除并取得独立再起，再验证换阶段后新模板的神怒、崩坏与原再起来源并存，后者的来源、实例与数量保持不变。这个前置条件覆盖模板重绑与独立授予的组合，不伪装成未经执行的酒杀；酒杀本身的原生付款及来源撤销由已有专项覆盖。
