# 移动版界蔡文姬

- 独立武将 `boundary:cai-wen-ji-mobile`，技能 `boundary:beige-mobile`、`boundary:duanchang-mobile`，规则集 `sanguosha-mobile`。
- [移动版官网武将详情 292](https://www.sanguosha.cn/index.php/pc/hero-detail-292.html)，核对日期 2026-10-25。悲歌完整正文要求先弃置一张牌，再令受到杀伤害的角色判定；红桃回复本次伤害的实际数值，方块摸三张，梅花由伤害来源弃两张，黑桃令伤害来源翻面。官网只列出断肠标题，没有其正文。
- 缺失的断肠正文由同版 [三国杀移动版 BWIKI：界蔡文姬](https://wiki.biligame.com/msgs/%E7%95%8C%E8%94%A1%E6%96%87%E5%A7%AC) 补齐，页面更新于 2025-12-20：死亡时令杀死她的角色失去所有武将技能。该页悲歌同时与当前官网相符。不能使用国战只失去一张武将牌技能的断肠，也不能套用 OL 界悲歌的先判、再可弃、花色或点数相同取牌分支。
- 同版页面将青学绘制的黑马、持箫、灰白披氅立绘标为“界蔡文姬-经典形象”，原图 530×750；与官网 292 轮播的 `47400` 图对应。轮播第一张 `5700` 是另版蔡文姬，未用作本独立版本画像。

悲歌在原 `afterDamageApplied` 程序帧上使用现有 HE 选择与逻辑弃置，等待真实付款子窗返回才开始原生判定。保存 `outcomeBind` 并按原生最终判定结果分支，即使判定牌被其他技能取得，也不以是否仍持有物理判定牌猜测花色。梅花使用 `selectOwnedCards(eventSource)` 暂存至多两张本人可弃 HE，不足时选尽，再由原生 `moveBoundCards` 一次提交整批；原选择者身份保存在 `SelectionActorSeat`，沿用本人禁弃及装备权限。断肠使用共享 `loseDeathSourceSkills`，失去来源当前所有武将技能，包括已获得的技能，同时保留装备及模式规则能力。

新增的共享数值表达式 `afterDamageAmount` 仅用于 `recover`，加载时限定 `afterDamageApplied` 与实际伤害目标；执行及原生回复恢复检查从原帧冻结的伤害上下文读取数值。沿用原生回复、技能变更和 typed 子返回，没有人物专属 pending 或另起状态。

判定分支使用既有 `judgmentOutcomeMatchesSuits` 条件。允许该条件驱动原生整批弃牌时，加载器证明消费者读取同一最终判定绑定，且消费者花色集合是选择生产者的子集；错花色及无条件消费者均拒绝。本人可弃候选只在原帧的真实最终判定结果已经满足分支时启用，不预判未定结果或放宽单牌移动操作。

行为覆盖真实酒杀两点伤害、先付装备成本再判定、四种结果、代表性付款/判定/回复子窗冷恢复，以及实际死亡的全武将技能失去和装备能力保留；并检查数值表达式不能用于判定窗口冒充伤害上下文。
