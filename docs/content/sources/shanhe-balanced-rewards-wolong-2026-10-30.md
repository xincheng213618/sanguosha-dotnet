# 奇遇分类、战法品质与卧龙图

2026-10-30按实际游玩反馈调整：新征程的三个奇遇优先分别提供队友、战法、技能，先抽类别再抽事件，类别内优先未访问事件，耗尽后可复用。类别没有可领取内容时回退至其他可用类别，避免满员后只有招募。章节次数与六格主线门槛不变。

普通战斗和奇遇的战法从第二档实际奖励起步；四档依次为白色普通、紫色稀有、橙色史诗、红色传说。已有更高档奖励保持其档位，不以改颜色代替真实效果。营地的摸牌或体力上限成长继续沿营地规则。

独立战法奇遇复用冻结官方配置 `hd_roguelike.sgs.Root.Adventure` 的1928及选项192801、192802、192803：前两项通过奖励组202取得稀有战法，第三项领取210铜币。同名1931为技能版本，保留独立身份；本地分别使用 `story:shiyoudaru-tactics` 与 `story:shiyoudaru`。新事件只进入补充池，旧池顺序与旧抽取过程保持原样。

卧龙图来源为同一配置的 `Tactics.plot=2253`，`level=2`、`money=300`，原文为“你将更容易获得你所在流派的战法”。图片字段为 `reward_zhanfa_2331.png`；2331是图片编号。配置成员冻结SHA-256为 `97dbdb465d902e771e575ed5165df3d193e1a689e3dae7ae67b9cb5033f18c72`，公开入口为[官方配置包](https://web.sanguosha.com/220/h5_2/res/config/Config.sgs)。原图按2253保存，下载地址与图片哈希登记在 `docs/content/wushuang-ui-assets.json`。

用户指定的本地规则：商店默认不出现白色商品；实际持有卧龙图时，已携带战法所属流派的白色战法进入候选池，其他白色仍排除。刷新、购买补货与升质使用相同资格。仅账户研习不算持有流派。卧龙图允许奇遇连续出现同一类别，商店更偏向已持有流派。公开配置没有给出概率，以下数值属于本地实现：商店同派候选权重3、其他1；奇遇类别基础权重1，战法类别与当章已出现类别各加1。无卧龙图时优先当章未出现类别。

旧存档先按原选项完整重放，再在地图或待选事件的安全边界追加 `enable-balanced-rewards` 命令。已进入的战斗及其悬置奖励先结算；已揭晓事件选项保留。货架升级仅替换不再合格的位置，保留钱包、刷新次数和同类加价计数，已购买白色位置不会变成免费新货。市场子会话随冻结交易种子继承已启用策略。未增加全局规则版本或改变历史选项。
