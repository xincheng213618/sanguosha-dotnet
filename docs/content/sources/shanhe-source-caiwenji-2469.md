## 精确技能复用

- 3106 `BeiGePo` 对应既有 `boundary:beige`。一名角色受到实际杀的伤害后，持有手牌或装备的蔡文姬可先令受伤角色判定，再选择是否弃一张自己的手牌或装备。按最终判定花色分别回复受伤者1点体力、令受伤者摸两张牌、令伤害来源弃两张牌或翻面；弃牌与判定牌花色相同则取得原判定牌，点数相同则取回原弃牌。两种返还独立检查原实体的当前位置，判定及弃牌的实际子流程复用原生能力。
- 265 `MoShi` 对应既有 `ol:moshi`。记录自己出牌阶段前两张实际使用的基本牌或普通锦囊，结束阶段依次用一张自己的手牌当记录的第一种、第二种牌使用。沿用原生有序记录、目标资格、材料与实际用牌结算；不附带同包陈情。
- 51 `TianDu` 对应既有 `classic:tiandu`。自己的判定牌生效后可取得该原判定牌，沿用原判定主体和唯一实体领取资格。悲歌令他人判定时，该判定仍属于受伤角色；不会因蔡文姬持有天妒就改成她的判定。

三项能力的准入和执行均按技能实例、原父帧、结算主体及真实牌状态判断，没有原将领或山河遭遇编号门槛。本包依赖标准角色包提供上述准确能力，不重复定义技能。3106不能替换为先弃牌再判定且没有同花色、同点数返还的经典悲歌，也不能替换为山河专版3140。原身体的断肠和SP蔡文姬的陈情均不在2469来源技能表中。
