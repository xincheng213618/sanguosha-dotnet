# 勇战Ⅰ2174与勇战Ⅱ2175

固定S5的[tactics.json](https://s.xiaochao.org/data/tactics.json)记录勇战Ⅰ2174为稀有、300铜币，“你脱离濒死时，对所有敌方造成1点伤害”；勇战Ⅱ2175为传说、700铜币，同一时点造成2点伤害。两者归属残血流。S5研习树只有2175的固定节点144，前置143、条件141；2174无固定节点，进入默认供货。两档图标复用已经缓存的2174、2175原图，同一来源图为`ad08a27b168d31bbb8a0467a.png`。

只有原生濒死真正结束且存活后才触发，尚在等待救援或未救活均不触发。沿既有濒死完成帧保留受益者、原濒死父帧及成功完成事实；每次真正脱离濒死都可发动，不另加回合或轮次次数限制。

目标复用山河图公开队伍敌方集合，只取存活敌方，不伤害自己和同行。原生参与者游标在同一技能帧逐名处理普通伤害及其孩子；伤害来源为脱离濒死的持有者。无双模式中同号战法以“所有其他角色”为目标，且受其模式和战法库存约束，不能将该敌我范围搬到山河图；这里只共用现有濒死完成窗口，伤害和选择仍用标准原生操作。
