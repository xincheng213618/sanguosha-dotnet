# 移动版界徐盛

- 独立武将 `boundary:xu-sheng-mobile`，四体力、吴势力、男性，规则集 `sanguosha-mobile`，版本 `boundary-mobile`，完整复用现有技能 `boundary:pojun`。
- 主来源：[三国杀移动版官网武将详情 356](https://www.sanguosha.cn/index.php/pc/hero-detail-356.html)，核对日期 2026-10-25。页面技能介绍只有破军，完整包含扣牌与杀伤害增加两部分。
- 同版交叉核对：[移动版 BWIKI：界徐盛](https://wiki.biligame.com/msgs/%E7%95%8C%E5%BE%90%E7%9B%9B)、[破军／界徐盛](https://wiki.biligame.com/msgs/%E7%A0%B4%E5%86%9B/%E7%95%8C%E5%BE%90%E7%9B%9B)，均列出同样两部分。未采用其他服务器“扣装备后弃装备、扣锦囊后摸牌”的规则，也未采用普通徐盛仅限出牌阶段且不增加伤害的破军。

每次使用普通、火或雷【杀】指定一个目标后，可扣置该目标手牌及装备区内至多其当前体力值张牌。选择沿用原生 `holdTargetCards`：在原技能帧暂存选择，提交后才将所选实体移入该目标的破军区；手牌选择保留隐藏来源。技能没有出牌阶段或次数限制。当前实际回合结束后，持有者获得仍在该区的牌，装备牌也回到手牌，沿用原生回合结束返还及其真实获得牌子窗。角色死亡时沿用现有破军区清理。

杀造成伤害时，分别比较目标与使用者此时的手牌数、装备区牌数；两项均不大于使用者时，此伤害增加一点。无需先发动扣牌，平手满足条件；判定使用实际区域张数，已扣置的实体不再计入手牌或装备。现有 `sourceNotFewerHandAndEquipmentThanTarget` 恰好表达这项规则，且原生伤害修正限定真实使用者的杀。

本次仅新增独立移动版本的武将配置，不复制规则程序或添加运行时节点。破军的真实扣置、原帧选择恢复、装备返手和回合结束返还继续由现有徐盛及回合结束机制检查覆盖；新配置由统一内容加载与图鉴检查验证，不新增重复定义快照或人物行为夹具。
