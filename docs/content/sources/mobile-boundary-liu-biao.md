## 规则来源

- [三国杀移动版官网：界·刘表，372](https://www.sanguosha.cn/index.php/pc/hero-detail-372.html)，核对日期：2026-10-25。官网完整给出本版自守与宗室。
- [移动版 BWIKI：界刘表](https://wiki.biligame.com/msgs/%E7%95%8C%E5%88%98%E8%A1%A8)，页面标注更新日期 2025-01-27。采用身份版群势力、男性、三体力；自守为额外摸牌后的本回合目标限制，宗室包含准备阶段手牌大于体力时本回合无限杀。

独立武将 `boundary:liu-biao-mobile`，技能 `boundary:zishou-mobile`、`boundary:zongshi-mobile`，变体 `boundary-mobile`，规则集 `sanguosha-mobile`。未使用现有 OL 版的伤害用牌债、同势力防伤及交牌效果。

## 原生能力与时效

自守使用已有加法摸牌阶段触发及原生 `draw(livingFactionCount)`。额外摸牌独立于正常摸牌，并保留实际牌移动、获得牌子窗及原帧返回。额外摸牌结束后，通过 `grantTurnCardTargetRestriction(selfOnly)` 发行本回合目标限制。原生合法动作和最终用牌目标都按同一策略判断，保留对自己的装备、无中生有、自身目标及无目标操作；不使用伤害账单或禁止所有用牌代替目标限制。

宗室手牌上限沿现有 `handLimit + livingFactionCount` 查询实时计算。准备入口沿引擎已有 `turnStartBeforeNormalFlow`（准备阶段已经建立的窗口），以当前手牌数严格大于当前体力为条件，发行 `grantTurnRuleModifier(slashLimit, unlimited)`。这是已经发行的实际回合修饰符，后续手牌减少不撤回，额外出牌阶段和正常出牌阶段共用，到实际回合结束再到期，不是当前出牌阶段租约。

人物没有独立运行时或新操作。共享回合修饰符补齐原先缺少的无限杀组合：解析器、发行时动态验证、状态验证仅新增 `SlashLimit + Unlimited + amount 0`，不允许额外牌名过滤；原生杀次数查询将该已发行效果作为无限贡献。既有加法次数及距离修饰符的合同保持。

## 行为检查

一项检查在真实四势力额外摸牌的获得牌子窗冷恢复，验证额外四张与正常两张、手限增加、仅一次目标限制，并实际使用自己的装备、无中生有和重铸铁索；其他角色目标与杀仍被禁止。

另一项检查在准备阶段手牌四张、体力三点时取得一次原生无限杀授予。通过真实弃置使手牌降至两张后冷恢复，在插入的出牌阶段连续使用两张杀，然后返回正常流程、拒绝自守，再使用正常摸到的两张杀。两段真实出牌阶段只发行一次修饰符，且均在手牌低于体力时实际生效。
