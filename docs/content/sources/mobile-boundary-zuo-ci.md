# 移动版界左慈

## 规则来源

- [三国杀移动版官网：界·左慈，294](https://www.sanguosha.cn/pc/hero-detail-294.html)，核对日期：2026-10-25。采用开局三张化身、回合开始或回合结束后改选或交换至多两张未亮化身的版本。官网有新生标题，但未提供该技能正文。
- [移动版 BWIKI：界左慈](https://wiki.biligame.com/msgs/%E7%95%8C%E5%B7%A6%E6%85%88)，页面标注更新日期 2025-11-26；[新生/界左慈](https://wiki.biligame.com/msgs/%E6%96%B0%E7%94%9F/%E7%95%8C%E5%B7%A6%E6%85%88)，页面标注更新日期 2026-01-11。用同一移动版本补齐新生：每受到一点实际伤害，可获得一张新化身，且须仍有化身技能。
- 独立武将 `boundary:zuo-ci-mobile`，技能 `boundary:huashen-mobile`、`boundary:xinsheng-mobile`；变体 `boundary-mobile`，规则集 `sanguosha-mobile`，群势力、男性、三体力。

## 实现

全部复用已有原生私密武将库。`initializePrivateGeneralLibrary` 开局获得三张，显示化身并选择一个非限定、觉醒、主公技能，沿原生投影改变性别、势力并授予真实技能。`acquirePrivateGeneralAvatar` 在逐伤害点的独立可选时机获得一张，以本版化身技能的真实来源定位原库；没有化身资格时不会建立替代库。

`chooseOrExchangeShanheS5Avatar` 虽沿用已有操作名称，其协议并未限定山河或技能 ID，本版直接复用。改选进入原生亮出与借技流程；交换则在原拥有帧上暂存至多两张未亮化身，确认前不移除、不抽取、不改变随机状态。返回只撤销暂选。确认后原库实际移去所选化身，并将本次移去的 ID 排除在等量抽取之外，故得到新化身，保持原亮出牌及其技能。库不足时只能选择能实际替换的数量，并允许零张确认。

现有私库将当前在场武将和所有私库占用的武将排除；隐藏 ID 仅库主可见，其他观察者获得数量及已亮出的信息。确认、来源资格、原帧草稿与随机结果的保存恢复沿同一共享机制，无新操作、pending、私库或格式版本。

BWIKI 另列移动账号永久武将数量对应的解锁范围。本地游戏没有该账号收集进度；候选库沿项目已有约定使用本局模式的实际武将池，不模拟移动账号的收藏门槛。

## 验证边界

既有山河 S5 左慈行为检查已覆盖同一操作的两张实际交换、排除刚移去的旧牌、保留亮出技能、草稿冷恢复及库存耗尽的零交换。本版只补每实际伤害点获得一张的新生接入检查，复用 `BoundaryZuoCiScenario` 的公开 API 场景，冷恢复后继续第二点而不重复第一点。界面的真实交换选择和返回同样复用该场景。
