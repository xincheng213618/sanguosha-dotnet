# 移动版界朱然：胆守

核对日期：2026-10-24。身份为 `boundary:zhu-ran-mobile`，技能为
`boundary:danshou-mobile`，规则归属 `sanguosha-mobile` / `boundary-mobile`。

## 规则来源

- [三国杀移动版官方界朱然介绍](https://www.sanguosha.cn/pc/hero-detail-389.html)，
  [同站当前可读取入口](https://www.sanguosha.cn/hero-detail-389.html)。页面标题明确为
  “界·朱然”，势力为吴；胆守依据其他角色本回合是否曾以使用牌指定自己为目标，
  在该角色结束阶段执行摸牌或可选弃牌伤害。
- 本实现独立于经典朱然的主动递增弃牌胆守，也独立于谋朱然的其他技能。

## 落地语义

- 仅在其他存活角色的结束阶段检查。该实际回合内，从未成为该结束阶段角色
  所使用牌的目标时，朱然强制摸一张牌，没有“取消发动”的选项。
- 否则，可以弃置等同于该次数的手牌或装备牌，然后对该角色造成一点伤害。
  无法付足时不提供付款分支；整个批次在确认前仅暂存，确认后使用原生逻辑弃牌，
  经实际移动子窗返回后才授权原生伤害。没有人为的固定选牌张数上限。
- 次数以原生实际使用动作和整张牌的指定事实为单位。同一张决斗的多轮响应、
  同一张牌的多次效果访问不重复计数；纯打出不属于使用。目标随后因仁王盾等
  原因效果无效，仍保留其曾经成为目标的事实。
- 原生动作记录实际使用者、实体提供者及目标指定。变更使用者后归于实际使用者，
  不把实体提供者算作使用者；借刀杀人的成对角色中仅其原生指定目标计数。
- 历史按实际回合号及实际回合拥有者限定，下一实际回合重新计数。原结束阶段
  与观察者的已开始事实防止嵌套摸牌子窗使同一个结束阶段改走另一分支。

## 持续状态与验证

自定义指令只冻结原结束阶段身份、历史截点和可选付款状态；摸牌及伤害继续使用
既有程序节点。支付保留原 `ProgramSkillFrame`、技能来源与内容哈希、原生逻辑弃牌
发票及逐实体移动证明；恢复通过原帧的类型化 movement/resume 返回，不建立旁路
pending。代表性检查涵盖强制摸牌、实际使用者替换、决斗纯响应去重、无效杀的既有
目标事实，以及手牌和装备混合支付在暂存及付款子窗中的冷恢复。

检查使用既有 Core 名称过滤，不新增运行器或版本号来源。规则/表示层 schema、
存档格式与包版本均沿用各自 catalog 和包常量。
