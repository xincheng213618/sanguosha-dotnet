# 移动版界钟会：身份版权计、自立、排异

核对日期：2026-10-25。内容标识 `boundary:zhong-hui-mobile`；魏、男性、4体力。技能标识 `boundary:quanji-mobile`、`boundary:zili-mobile`、衍生技能 `boundary:paiyi-mobile`。

## 来源与版本边界

[移动版官网368](https://www.sanguosha.cn/pc/hero-detail-368.html) 标为身份模式，给出完整权计与自立：每点伤害后及自己出牌阶段结束手牌大于体力时的摸牌/存权、按权数增加手限，以及准备阶段至少3权的选择收益、减上限、获得排异。官网没有展开衍生排异。

因此另核对[移动版BWIKI界钟会](https://wiki.biligame.com/msgs/%E7%95%8C%E9%92%9F%E4%BC%9A) 的身份/经典段（页面最后更新2025-10-21）和[排异/界钟会独立页](https://wiki.biligame.com/msgs/%E6%8E%92%E5%BC%82/%E7%95%8C%E9%92%9F%E4%BC%9A)。两者均明确身份排异为每出牌阶段限1次，移1权令一名角色摸2，再比较其手牌与本人，较多则对其伤害1。该补充为社区规则资料，不能冒称官网正文。

特别区分[国战排异页](https://wiki.biligame.com/msgs/%E6%8E%92%E5%BC%82/%E7%95%8C%E9%92%9F%E4%BC%9A%28%E5%9B%BD%E6%88%98%29)：按权数摸X（至多7）列在国战历史版本；国战当前另列限2次、摸2。它们的权计条件也不同，不属于官网368所列身份版。本实现独立注册经核实的移动身份排异，不把国战历史或现行规则混入，也不通过授予 `classic:paiyi` 省略本版来源核准。

## 实现

完全复用现有能力，无新增操作枚举或运行时pending。权存于原生 `Authority` 区，公开显示为“权”，手限使用现有按该区实体数相加的modifier。受伤窗口按原生 `perDamagePoint` 每点分别自选；新增自己实际出牌阶段结束窗口，只有当时手牌严格大于当前体力值时才可发动。摸1后必须从自己的真实手牌选1存入权区；存权等待原生移动子窗口返回。

自立在原生准备窗口以至少3张权为资格，两项收益使用共享觉醒选择组，一局只选一次；受伤时可选回复，摸2分支同样可选。收益结束后减上限1，再通过 `GameEngine.ProgramSkillChanges.cs` 的已有技能取得操作获得本版排异，不复制技能变更实现。

排异用原生选中牌付款从权区弃置1张原实体，等待其付款子窗后，令当前目标摸2，最后比较真实当前手牌数并执行原生伤害。目标可以是自己，此时自身手牌不可能大于自身，不会造成伤害。次数按 `usesPerPhase:1` 绑定实际出牌阶段，而不是整回合限制。付款、原生摸牌与伤害均沿用已有帧与typed返回，恢复不会重付权牌。

## 行为检查

`BoundaryZhongHuiMobileChecks.PerDamagePointAndOwnPlayEndAuthorityAwakeningPaiyiPaidCold` 用一次真实2点伤害分别存2权、自己的实际出牌结束存第3权，验证实体权牌/手限、下一准备的觉醒选择与共享授技，再以原权支付排异，验证摸2和条件伤害、每阶段额度以及存权与已付款排异子窗的冷恢复。既有共享机制检查覆盖通用觉醒、技能变更与付款边界，不新增纯配置快照或跨角色矩阵。
