# 逆京枭雄2684：专版谋董卓

来源为[官方配置包](https://web.sanguosha.com/220/h5_2/res/config/Config.sgs) `hd_roguelike.sgs / Root.General / a=2684`，武将605、原始皮肤字段 `h=100`，20/20体力，技能串 `3513;14206;14207;14208`。实际来源位置为崤函道区域14、城市5148，最低来源难度16。本地独立武将为 `shanhe:source-mou-dongzhuo-2684`；肖像复用现有 `mou-dong-zhuo-ol` 对应的同角色默认60500素材，作为展示回退，不声称已取得该关底的专用皮肤原图。

普通谋董卓与本专版保留不同技能身份。观变3513原文与现有 `mou-ol:guanbian` 一致，直接复用其开局人数冻结、手牌上限和双向距离加成及首轮结束失技。专版凶逆与封赏在真实付款或给牌后，通过现有 `GameEngine.ProgramSkillChanges` 的精确来源删除原语失去观变，并清除原观变标记；不复制普通运行时的直接授删技能方式。

## 凶逆14206

源名 `FaYi2Rogue`：出牌阶段开始时可弃一张牌，其他每名角色需弃五张同花色牌，否则体力上限降低一点。

`shanhe:source-xiongni-14206` 在本人真实出牌阶段开始窗口发动。本人从手牌或装备区真实弃一张，冻结这张实体的牌面、有效花色与移动来源；其余当时存活角色按座次依次处理。每人可完整选择五张同花色手牌／装备，选齐后才一次支付；不足五张或放弃时降低体力上限，不造成伤害。不允许只付部分牌。付款、装备移出引发的恢复、体力变化和实际移牌子流程返回后，才推进原参与者游标，不重复弃牌。

最大体力下降复用原生最大体力、体力夹取与相关替换规则；降至零时走原生死亡流程，而非伪造成伤害或普通濒死。单个角色死亡不会借其座次重复处理其他人。

## 封赏14207

源名 `DangTong2Rogue`：出牌阶段限一次，或一名角色进入濒死时，可以将本回合弃牌堆中的任意张同花色牌分配给一名角色。若本人没有以此法获得牌，视为使用一张不计次数的酒。

`shanhe:source-fengshang-14207` 仅从本实际回合已经真实进入弃牌堆、选择和付款时仍在其中的实体中选择，至少一张、全部同花色，交给一名存活角色，允许选择自己。它不要求恰两张、不要求不同接收者，也不继承普通版本的每轮花色限制或濒死每回合一次限制。主动入口沿原生实际出牌阶段限一次；濒死入口独立触发。

给牌使用原生 Give 完成记录、公开实体移动和其子流程。是否本人得到牌按这次真实付款的移动结果判断；未得到才发行原框所属、零实体的真实酒 Use。该酒遵守实际禁用和目标规则，自身濒死时使用原生酒回复，否则获得酒效果。酒与其回复／用牌子流程必须返回原封赏框；不以布尔酒效替代真实用牌。`BeforeAlcoholDebit` 精确豁免该回执对应的酒，因此即使商店额外酒额度或荐计账本已加载，该酒也不消耗额度。

## 执柄14208及止息绑定

源名 `ZhiBing2Rogue`：每个回合，其他角色使用黑色牌达到三张时，该使用者失去一点体力；六张时，持有者将手牌摸至或弃至九张；九张时，令该使用者直到本回合结束获得止息。

`shanhe:source-zhibing-14208` 按每个真实回合、每个其他实际使用者分别记账。记录只来自真实已声明的 Use 和共享原生事实证明为 Use 的响应（例如对杀使用闪、使用无懈）；纯打出不计。实体付款前冻结的 `CardActionContext.EffectiveSuit/EffectiveIsRed` 决定黑色；不在装备移出或失技后重新计算原牌花色。无实体虚拟牌没有花色时保持无色，不臆造黑色。公开不可变事实保存动作、原用牌框、演员、真实回合及牌面身份；不新增旁路 Use-ID 待处理表。

各阈值仅对原动作触发一次。三张的真实失去体力、六张的摸牌或实际弃手牌、九张的授技及其孩子均在原执柄框结算；第九张已经声明的原牌继续结算。止息经既有原生授技生命周期绑定本实际回合结束，到期仅撤销本次来源。

本地明确采用候选来源技能14209的锁定“不能使用牌”版本，独立身份 `shanhe:source-zhixi-14209`。禁止真实 Use，包括实际属于 Use 的响应，保留纯 Play；不用258的按体力用牌限制，也不将 `14208.m="111,752"` 当作正确的派生技能身份证据。当前缓存没有服务器将14208显式绑定14209的证据，这一候选绑定属于明示的本地执行选择。

所有新规则限山河图模式且有山河战斗设置时生效，不改变普通谋董卓。前向检查以真实弃牌、五张同花色付款、体力上限损失、同回合同花色的阶段／濒死封赏、Give、零实体酒及其额外额度账本验证主链。本人真实濒死时另将一张原弃牌交给他人，酒沿实际回复恢复一点体力、返回原封赏框，再由原濒死框确认存活。执柄在同一实际九张黑色装备 Use 序列下分别从零张与十一张手牌出发，核验第六张时真实摸九张或选择并弃两张，全部移牌孩子返回后才继续原牌；第三、第九张及回合结束授技期限同样保留原断言。不执行存档、恢复、回放或完整对局结算。
