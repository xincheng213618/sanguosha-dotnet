# 推荐三章征程的阵容接线

2026专属形态仍是默认推荐征程，采用本地三档、三章路线。已实现的来源武将需要显式加入其遭遇池，不能仅登记在25档配置复现入口。

普通与山河册两种构建入口均在队友成长层之后、开场池与地形支路生成之前接入补充层。因此大谷、轘辕及其五条地形支路使用相同的完整候选，旧角色、奖励与已完成的章节结构继续保留。

令 `g=本地难度-1`，第二章新增：

| 地点 | 阵容 | 当前体力／上限 | 资源与技能 |
| --- | --- | --- | --- |
| 大谷 | 徐盛 | `7+2g / 7+2g` | 专版全手牌破军、鬼龙斩月刀 |
| 大谷 | 狂暴枪王 | `7+2g / 7+2g` | 初始动荡、原版限定雄乱、无双方天戟、玲珑狮蛮带 |
| 轘辕 | 孙策 | `6+2g / 6+2g` | 激昂、受伤准备阶段觉醒的魂姿、黑光铠 |
| 轘辕 | 荀彧与卫士 | 荀彧 `3 / 6+2g`，卫士 `6+g / 6+g` | 荀彧保留驱虎的低体力发动条件，初甲与上限 `2+g`、第二轮起每轮回复1甲；钩镶、节命及卫士共同提供续战 |

四位主将均在四张随机起手之外增加 `1+g` 张随机牌，摸牌阶段额外摸1张，固定装备再额外进入手牌；卫士额外起手 `g` 张。以上体力曲线沿既有第二章本地编排，荀彧的低当前体力、护甲、卫士和装备搭配也是本地选择。武将原始定义不变，没有给征程设置来源难度，也不伪造来源城市或人数成长字段。

黄巾余匪与改朝罪魁的真实身体转换见[阶段桥接](shanhe-returning-native-stage-bridge.md)。既有初始动荡、二阶段原席替换、回合中断、实体装备和技能授予流程直接复用。第一章依然以单将、双将为主，所有席位仍受八人上限约束。

洛阳另有[逆京枭雄](shanhe-source-mou-dongzhuo-map-2684.md)独立候选，接入专版谋董卓、断魂与昆仑镜，并在本地击败后接续篡天恶魂；该本地两阶段编排与来源2684的单阶段保持区别。

大谷、轘辕及其五条地形支路另有[百战老兵、乌桓骑手、武卫兵、荀悦、江东老兵、林中鹘和辛评](shanhe-source-ordinary-troops-2026.md)七组普通敌军。两种推荐入口均按本地三档选择其完整技能组合，使用本地第二章体力和起手曲线；每种身体保留自己的原始体力，上限加成据此计算。

同一投放层另补羌人劫匪至第一章虎牢、广成与其开场候选，荀悦至第二章大谷、轘辕与五条地形支路。二者均保留完整档位技能；荀悦的3体力原始身体与本地第二章上限加成分开，详见[普通敌军投放](shanhe-source-ordinary-troops-2026.md)。

江东老兵2497本批也已接入上述第二章地点。本地1／2／3档选来源1／11／21档，按档位累计旋风、奋励、平寇和青釭剑、白银狮子、照骨镜，固定装备额外入手；高档宝物的原生流程已实现，不再因照骨镜缺项延后整组。该投放为本地三档编排，真实开局的定向检查已通过。

第一章广成、虎牢及其开场克隆又补入联军斥候2455、联军细作2459、本地豪强2460，第二章另补林中鹘2476、辛评2489。五组均保留完整来源技能档，使用独立身体而不是同名普通将替身；本地1／2／3档选来源1／11／21档。联军细作原始3体力，第一章本地体力与上限仍为 `4+本地难度`，上限加成按3体力身体计算，避免少1点上限。

第三章最后营火可选择“京畿巡军”前战，遭遇乌鹊暗杀者2493或校事典刑官2495。完整技能和最高档护心镜随本地1／2／3档选择来源1／11／21档，采用独立第三章体力与起手曲线，详见[普通敌军投放](shanhe-source-ordinary-troops-2026.md)。清剿后仍可进入原三条最终路线、东吴精锐或木鹿支路；普通前战可领取战利品，原关底继续直接结算。
