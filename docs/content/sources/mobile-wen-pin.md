# 移动版文聘

> 此版本与 `ol:wen-pin` 技能规则等价，独立武将定义已删除。本文保留规则和素材来源；处理名单见 [武将技能去重](../GENERAL_RULES_EQUIVALENCE.md)。

核对日期：2026-10-26。正式身份 `mobile:wen-pin`，魏、男性、四体力，版本 `mobile`，规则集 `sanguosha-mobile`，画像键 `mobile-wen-pin`。

[移动版官网文聘97](https://www.sanguosha.cn/pc/hero-detail-97.html)记载杀或黑色锦囊牌的其他唯一目标体力低于自己时，弃一张牌选择摸一张并转移目标，或令牌无效并在当前回合结束时由使用者获得。[移动版Wiki文聘](https://wiki.biligame.com/msgs/文聘)（2025-10-24更新）进一步明确牌的使用者也必须是另一名其他角色，与现有OL资格相同；采用此明确主体约束，不能保护自己用牌的目标。

完整规则复用 `ol:zhenwei`。现有运行时会将实际原生材料隔离到游戏外，在原实际回合结束的帧上返还使用者；并非仅取消效果或把材料留在普通弃牌堆。现有OL展示说明省略“返还使用者”的尾句不代表规则不同，其实际执行已包含该步骤。本次仅增加独立移动版资料。

独立经典画像为[官网13600](https://www.sanguosha.cn/storage/uploads/images/skins/13600.jpg)，资源文件 `src/CardGame.Wpf/Assets/official-mobile-wen-pin.jpg`，由批次统一绑定及核验。
