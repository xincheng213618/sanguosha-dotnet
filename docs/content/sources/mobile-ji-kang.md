# 移动版嵇康

核对日期：2026-10-26。正式身份 `mobile:ji-kang`，魏、男性、基础三体力，人物 `character:ji-kang`，版本 `mobile`、规则集 `sanguosha-mobile`、画像键 `mobile-ji-kang`。移动Wiki归入乱世英杰2017，图库 `fame-7`。技能清弦80900、绝响80901、衍生残韵80902；人物与当前将池80999。

规则来源为[移动官网229](https://www.sanguosha.cn/pc/hero-detail-229.html)原始HTML的完整技能页签及[移动BWIKI嵇康](https://wiki.biligame.com/msgs/嵇康)（oldid38075，2026-04-15更新）、[清弦](https://wiki.biligame.com/msgs/清弦)（oldid38071）、[绝响](https://wiki.biligame.com/msgs/绝响)（oldid38073）、[残韵](https://wiki.biligame.com/msgs/残韵)（oldid38074）。人物经典栏有实际合成获取方式；这里采用正式普通移动版，不能复用本库经典版伤害/回复后选失血或回复、随机装备和四种弦技能继承。

官网明确清弦是自己的出牌阶段一次，选择不超过当前体力值的其他存活角色，弃置与人数相同数量的牌，再依次与自己比较装备区的牌数：少者回复一点，相等者摸一张，多者失去一点体力；选满X名目标时自己摸一张。当前BWIKI人物、清弦及残韵页把摸牌分支再次排作“小于你”，与同一条目的三分结构冲突。本实现采用官网明确的“等于”分支；没有将该排版错误擅自解释成同时回复和摸牌。

绝响在真实死亡时先让实际杀手弃尽装备区可弃的牌，再失去一点体力；上述原生子结算结束后，死亡来源可以选择一名其他存活角色永久获得残韵。受益者随后可以弃置场上一张梅花牌，支付和实际移动子结算完成后获得绝响。没有杀手时跳过杀手惩罚部分，后续选择仍可进行。死亡清理前仍位于原死者装备区或判定区的梅花牌属于此时场上的牌，可以作为可弃材料；不把手牌视为场上牌。

残韵沿同一主动流程，但每名目标在对应真实残韵来源下每局限一次。账本保存实际拥有者、技能、绑定、实例与已支付目标，不用全局owner布尔标记，支付成功后的目标发行事实参与后续查询。目标死亡或没有合法目标、没有合法弃牌时不提供新发动；动态原帧开始还会针对它的精确来源重新检查，不以另一个来源可用代替本来源资格。

清弦/残韵在原程序帧冻结选择时的X与目标，按当前桌面行动顺序结算。先支付真实HE实体并处理弃装、回复、移牌等原生子窗，随后在每个目标实际结算时读取当时双方装备数量；装备付款可以改变比较结果。满数奖励使用选择时的X，不因付款子结算改变体力后重新收款或改写目标数。上述“依次”取值点及已付款效果失去来源后继续返回属于对原生结算约定的实现解释，官网未列举每种组合。

两个人物自有操作沿原帧状态与标量事实记录付款、逐目标比较和返回游标；摸牌复用 `BeginOperationProgramDraw` / `NativeDrawOutcome`，弃牌复用逻辑弃牌调用与多源实体移动，体力流失/回复复用原生健康管线，不另设平行pending。授技复用 `GameEngine.ProgramSkillChanges.cs` 新增的目标seat重载：验证原活动帧、向真实受益者取得永久技能，不增加回合或轮前置条件，保留经典owner重载默认路径。新事件仅含标量或不可变来源身份；待决集合在所属帧中冻结。

focused仅覆盖新主动三分支和支付子窗返回、死亡惩罚与真实受益者两次永久授技、残韵跨阶段的来源目标限次及代表冷恢复。共享技能变化原有三项检查继续作为旧owner路径与动态帧边界回归，不复制完整共享矩阵。
