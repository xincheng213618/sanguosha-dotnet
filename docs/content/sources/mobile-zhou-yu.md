旧 `classic:fanjian` 使用整回合一次，并在取得前由周瑜公开随机手牌；不能整体引用来承诺当前移动流程。旧随机赠牌操作的null策略保持此历史默认。新增可选 `randomTransferRevealPolicy:recipientAfterGain`，只由普通移动反间启用，不增操作码或重写普通伤害。

新策略仍沿原程序帧随机取一次当前手牌，把原实体、原目标和真实移牌序列保存在同一个不可变收据上。真实获得和对应卡移动子窗返回前，不创建公开牌集、不预发周瑜展示事实。接收者实际展示时，牌已经在其手牌区；公开事实的展示者及原生展示奖励归属接收者，花色也按该角色此时的真实有效花色冻结。
