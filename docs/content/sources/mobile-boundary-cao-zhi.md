# 移动版界曹植

- 独立武将 `boundary:cao-zhi-mobile`，初始技能为 `boundary:luoying-mobile`、`boundary:jiushi-mobile`、`boundary:chengzhang-mobile`；升级酒诗为 `boundary:jiushi-mobile-upgraded`。规则集 `sanguosha-mobile`。
- 主来源：[三国杀移动版官网武将详情 364](https://www.sanguosha.cn/index.php/pc/hero-detail-364.html)，核对日期 2026-10-25。页面完整列出落英、酒诗两个等级以及成章三项，不能漏掉成章。落英获得其他角色因弃置或判定入弃的梅花牌；基础酒诗可以翻背使用酒，受伤后翻正获得一张随机普通或延时锦囊；成章在准备阶段累计造成与受到的伤害值达到七后回复一并摸一，再升级酒诗；升级版的随机锦囊改为每次翻面后获得。
- 同版补充：[移动版 BWIKI：界曹植](https://wiki.biligame.com/msgs/%E7%95%8C%E6%9B%B9%E6%A4%8D)、[酒诗／界曹植](https://wiki.biligame.com/msgs/%E9%85%92%E8%AF%97/%E7%95%8C%E6%9B%B9%E6%A4%8D)。后者更新于 2025-08-31，明确受伤后的翻正需“受到此伤害时”与“此时”均背面朝上，补齐官网简写。这会排除本次正面受致命伤、随后濒死酒诗才翻背的情况。

落英复用现有判定／逻辑弃置来源证明，按原始角色和最终有效花色领取实体。保留原生 claim 的清理尾节点，但本版本不配置 OL 的落英牌策略、回合外累计翻正或背面落英牌无距离且不可响应等效果；移动版也不具有乐曹植的能力。

普通出牌及自身濒死时使用酒均沿用现有原生零材料酒与翻面成本。受伤朝向以实际 `DamageAppliedEvent` 时唯一原生 `DamageFrame` 冻结，随后对照同一帧核对；观察入口覆盖普通卡牌、程序伤害、判定伤害、连环传导和无来源伤害，不限于杀或某个单一攻击家族。

随机获取从真实牌堆的锦囊实体中按引擎可重放随机数选择，保存为现有不可变卡牌绑定，再交给 `moveBoundCards` 实际获取并等待原生子窗；不存在锦囊时绑定为空。没有新 pending 或额外付款状态。成章的回复与摸牌先结算，随后通过共享 `GameEngine.ProgramSkillChanges` 替换酒诗并记录觉醒，保留落英、成章及原生的一局限一次状态。

必要行为检查包含落英的弃置与判定来源、基础零材料酒和延时锦囊获取、真实卡牌及程序致命伤的原朝向、成章累计伤害值、回复／摸牌先于原生升级、升级后酒诗成本与任意原生翻面的获取，并在真实获取、准备阶段摸牌及翻面成本子窗验证代表性冷恢复。
