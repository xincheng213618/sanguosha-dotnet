# 移动版马忠

核对日期：2026-10-26。身份 `mobile:ma-zhong`，人物 `character:ma-zhong`，蜀、男、4 体力，肖像键 `mobile-ma-zhong`。

来源：[官网武将页 211](https://www.sanguosha.cn/pc/hero-detail-211.html)、[移动版 BWIKI 人物正文（oldid=8133）](https://wiki.biligame.com/msgs/index.php?title=马忠&oldid=8133)及[抚蛮技能页（oldid=38865）](https://wiki.biligame.com/msgs/index.php?title=抚蛮&oldid=38865)。人物页显示 2022-06-03，技能页显示 2024-02-16；两处当前技能正文一致，未将该移动版替换为其他产品的同名版本。

采用的完整规则：出牌阶段每名角色限一次，你可以将一张【杀】交给一名其他角色，然后其于其下个回合结束前使用此【杀】时，你摸一张牌。官网略去“下个回合结束前”期限，BWIKI 人物及技能正文均明确给出该期限，故予以保留。

与库内 `ol:fuman` 有三处实质差异：移动版只能赠送真实手牌杀；只在受赠者下一个实际回合结束前有效；受赠者真实使用时固定摸一张。OL 版可以赠任意手牌并视为杀，结算后按是否造成伤害摸一或两张。因此使用独立 `mobile:fuman`，不复用同名 OL 技能。

实现保留普通杀、火杀和雷杀的原实体、花色及属性，不把任意手牌转为杀。零初选入口先消耗每目标阶段记录，再私下选择一张真实手牌杀；冻结原选择后复用标准 `moveBoundCards` 赠牌和原帧的移动后子窗与类型化返回，恢复不会重复支付。延后来源由原技能实例、内容指纹、原赠牌帧与真实 Hand→Hand 移动证明，不另存一套可变待决对象。

奖励在原生 `CardUseCommitted` 时冻结并通过标准摸牌操作执行，先于此次杀的伤害，造成伤害也仍只摸一张。只打出杀响应决斗、南蛮或势力提供请求不属于真实使用，不奖励。资格针对原受赠者手中的该实体，离开这段受赠手牌驻留后不因重新取回而复活；第三人使用也不奖励。期限按受赠者下一次真实 `TurnEnded`，包含额外回合，不按牌面回合计数估算。

独立行为检查覆盖真实杀限制、赠牌付款子窗冷恢复、赠牌完成后经合法终止主动操作真实失技、原实体实际使用时固定摸一张、摸牌付款后的冷恢复、仅打出不奖励，以及原实体保留通过受赠者下回合结束后的到期行为。其他纯复用武将不增加重复定义夹具。
