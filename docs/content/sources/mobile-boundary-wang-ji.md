# 移动版界王基

本目录对应 `boundary:wang-ji-mobile`，使用当前移动版“蓄力奇制／进趋”，与仓库保留的经典王基相互独立。人物为魏势力、男性、3体力，立绘键为 `boundary-wang-ji-mobile`。

## 规则来源

- [三国杀移动版官网：界王基，编号671](https://www.sanguosha.cn/pc/hero-detail-671.html)，2026-10-24核对完整技能正文及玩法说明。奇制的初始／上限为1／2；出牌阶段每角色一次，消耗1蓄力，令其原生摸2。本阶段每使用基本牌或普通锦囊指定目标后，依次观看因此摸牌角色的全部当前手牌，并各弃1。进趋每于自己的回合内使用两张基本牌或普通锦囊后，令一名角色获得1蓄力；结束阶段摸本回合自身蓄力最高值张。
- [移动版WIKI：进趋](https://wiki.biligame.com/msgs/%E8%BF%9B%E8%B6%8B)的旧版正文明确写有“有蓄力技的角色”，只用于解释蓄力接收者须有实际蓄力池。该页所列“每使用三张牌”是不同版本，不作为本实现的计数依据，当前官网的两张基本／普通锦囊优先。
- [移动版WIKI：王基](https://wiki.biligame.com/msgs/%E7%8E%8B%E5%9F%BA)的人物资料用于核对性别、势力和3体力；其经典技能正文不用于本版。

## 实现裁定与复用

- 奇制可以选择自己。阶段限制使用实际出牌阶段标识，记录已支付的目标，而非回合计数；同一阶段即使后来补充蓄力，也不能再次给原目标发动。
- “因此摸牌”按真实原生摸牌结果解释：原生请求2张，至少实际摸到1张才登记后续受益对象；完全替换且实际摸牌数为0时仍已扣点、消耗此次阶段资格，但不把纯目标登记为摸牌者。这是技能用语与现有原生摸牌替换合同共同得出的实现裁定，官网没有另列替换FAQ。
- 多名受益角色按当前行动顺序依次处理，包含自己。每次用牌重新观看各角色全部当前手牌；已死亡、空手或没有可合法弃置手牌的角色跳过。所观看牌仅通过发动者的既有 `PrivateCards` 投影显示，私密提示的真实卡牌选择复用现有CardPicker。事件只记对象、数量和已公开的实际弃牌，不公开所看手牌清单。
- 计数使用完成的真实 `Use`，含自己的回合内真正作为使用结算的响应牌；普通打出、重铸、装备、延时锦囊和技能发动本身均不计入。每个原生动作只计一次，多目标牌也只计一次。指定目标窗口与使用完成窗口各负其责，奇制的私看不会另计用牌。
- 进趋接收者复用当前已实现蓄力技能的真实池与容量：本版奇制、谋姜维挑衅、谋公孙瓒义从、谋孟获再起、势钟会肆恣、势邓艾屯田。没有蓄力技能的角色不能凭空产生池；满蓄力者仍可被选择，按对应容量截断。外来充能不冒充原技能的专属收益触发。例如势钟会的“挟志”溢出来自体力变化，进趋补点不发行挟志溢出奖励。若同一角色确实持有多个蓄力池，选择明确到对应池，实际只补1点。
- 结束阶段的数量在原指令发行时冻结，等于当回合开始的蓄力与其后实际变更记录中的最高值；随后扣点不会降低它。所有摸牌走原生摸牌生产者；私看弃牌走真实逻辑弃置，保留原帧、实际实体、付款事件、子窗、类型化返回及已支付游标。

## 必要行为覆盖

`BoundaryWangJiMobileChecks` 覆盖初始与支付、本人完整私看及另一观众隐藏、后续多名受益者顺序弃置、实际付款子窗冷恢复后续到下一对象、阶段每角色限制；另覆盖装备／重铸不计数、真实普通锦囊与基本牌两张充能、充能选择冷恢复、实际谋孟获蓄力池补点与谋姜维满池截断、消耗后的历史最高值原生摸牌。WPF通过同一公开API场景验证实际私看卡牌与选择付款，不另造一套夹具。
