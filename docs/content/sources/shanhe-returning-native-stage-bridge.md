# 推荐版真实首领阶段接线

`lords-dong-2026` 是保留三章路线的本地编排入口。此桥接复用已实现的来源武将与原生阶段切换、补牌、装备安装，不将本地普通／中等／困难解释为来源25档中的某三个档位。来源入口的数值、地区、技能阈值和阵容保持独立。

两个普通／山河册工厂在章节成长之后、开场池与地形支路复制之前调用 `WithReturningNativeBossStages`。该方法只接受 `shanhe:zhuhou-2026-` 系列且 `SourceDifficultyId` 为空的定义，仅替换以下两个既有遭遇的名字、玩家简介与阶段配方；节点、遭遇ID、路线、奖励、同行和其他阵容均保留。地形支路沿现有克隆逻辑获得同样的张燕阶段。

## 黄巾余匪

目标遭遇为 `huanyuan:zhangniujiao-s5`。令本地成长量 `g=本地难度-1`：

| 配方 | 普通 | 中等 | 困难 |
| --- | --- | --- | --- |
| 张牛角已实现技能形态 | Medium | Hard | Nightmare |
| 张牛角当前／最大体力 | 6/6 | 8/8 | 10/10 |
| 张牛角额外随机起手 | +1 | +2 | +3 |
| 张牛角摸牌阶段额外牌数／额外出杀 | +1 / 0 | +1 / 0 | +1 / 0 |
| 张燕已实现技能形态 | Medium | Hard | Hard |
| 张燕当前／最大体力 | 12/12 | 14/14 | 16/16 |
| 进入张燕时补牌 | 3 | 4 | 5 |
| 张燕摸牌阶段额外牌数／额外出杀 | +1 / +1 | +2 / +1 | +3 / +1 |

全部三档的张燕入场均原生安装一张红桃Q三首。形态中的 `Medium/Hard/Nightmare` 只是对应内容包常量的身份名称；本地三档选择这些技能集合是明确的本地方案，不宣称官方存在这套难度映射。张牛角的印刷基础上限为3，张燕为4，配方同时写明 `MaxHpBonus` 与当前体力，避免其来源 `InitialHp` 优先级将首领重新压回原始体力。

雷劫、天妒、鬼才、炎狱、蔽日、动荡及三首的来源与原生边界见[张牛角与张燕来源说明](shanhe-source-zhangyan-stage-2026-10-27.md)和[三首装备](shanhe-sanshou-armor-3278.md)。三首牌仅放入阶段的 `StartingEquipment`，不在 `Combatant` 复制一份，避免双付实体。

## 西凉霸主

目标遭遇为 `luoyang:gaichao-s5`。第一形态改朝罪魁及同行、资源完整保留；原先重复同一改朝身体的本地第二阶段，改为已实现的独立篡天恶魂身体。

本地当前／最大体力继续使用原关底曲线 `20+4g`，即20/20、24/24、28/28；阶段补牌改为 `3+g`，即3、4、5张。阶段摸牌加成 `1+g`，额外出杀+1。其印刷基础上限为20，阶段 `Combatant` 同时明确当前体力与相应上限加成，入场原生安装红桃Q修罗炼狱戟和梅花2玲珑狮蛮带。

篡天恶魂使用独立源版神怒14214与现有崩坏。神怒的实际伤害、来源体力采样、怒标记、反伤孩子和清怒时序见[神怒来源说明](shanhe-source-shennu-14214.md)。这些复用有来源技能依据，但本地路线投放、三档成长、阶段补牌和固定装备组合属于本地编排。

桥接不调用 `Source2026BossEncounter`、`Source2026StageCombatant` 或来源成长计算器，不附加 `SourceDifficultyAttributes`，不伪造来源城市或难度标签；既有真实来源编号若已存在则原样保留。实际进入阶段仍沿 `ShanheBossTransition` 的原有付款与生命周期，不新增运行时状态或旁路切换。
