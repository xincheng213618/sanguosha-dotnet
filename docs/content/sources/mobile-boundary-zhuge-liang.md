# 移动版界诸葛亮

- 独立身份武将 `boundary:zhuge-liang-mobile`，蜀势力、男性、三体力，版本 `boundary-mobile`，规则集 `sanguosha-mobile`。观星复用 `boundary:guanxing-current`，空城复用 `classic:kongcheng`。
- 主来源：[三国杀移动版官网武将详情 234](https://www.sanguosha.cn/index.php/pc/hero-detail-234.html)，核对日期 2026-10-25。页面标注“界·诸葛亮”“身份”，完整 HTML 的技能介绍分别包含观星正文及隐藏的空城正文；只读取当前可见技能会遗漏空城。
- 同版官方交叉来源：[经典再现——诸葛亮](https://www.sanguosha.cn/pc/guide-info-111.html)，发布于 2020-06-30。该移动版官方攻略并列普通观星、界观星和空城，界观星、空城与当前详情页一致。此处以当前移动版身份详情为规则主来源，未使用国战或其他服务器规则替代。

准备阶段可观看牌堆顶五张牌；发动时存活角色少于四人则观看三张。将这些牌按自选顺序分别放至牌堆顶或牌堆底。只有准备阶段本次观看的牌全部放至牌堆底，才有本回合结束阶段再次发动观星的资格；拒绝准备阶段观星或保留任意一张在牌堆顶均不产生该资格。结束阶段发动时按当时存活人数重新计算观看数量，仍可任意分配顶、底，不再递归产生额外发动。

现有 `boundary:guanxing-current` 的准备、结束两个原生触发精确表达以上规则。原准备帧的 `reorderTopCards` 使用人数阈值四、低于阈值数量三及上限五；在整个排序提交后，仅实际全置底才写入本回合私有的结束资格。结束触发检查这项资格，分别限制两个窗口各一次，结束排序没有再次发行资格的字段。观看、分配、顺序暂存及恢复继续使用原生 `ProgramTopReorder`、原指令及内容指纹校验。

空城为锁定技：手牌为空时禁止被指定为普通杀、火杀、雷杀和决斗的目标。复用技能的原生目标禁止策略按当前手牌数检查，获得手牌后立即不再满足条件。它不禁止无手牌角色成为其他牌的目标。

本次仅增加完整移动版武将的内容登记和来源说明，未新增技能定义、节点、运行时状态或共享接线。已有原生观星排序与恢复、空城目标合法性检查继续覆盖这两个技能；新增内容由统一加载、武将登记及图鉴检查验证，不为完全相同的配置复制行为夹具。
