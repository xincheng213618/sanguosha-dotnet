# 赌徒Ⅰ／Ⅱ的来源与执行约定

[固定S5战法表](https://s.xiaochao.org/data/tactics.json)列出赌徒Ⅰ2217为普通、200铜币，战斗获得的铜币在50%—200%内随机；赌徒Ⅱ2218为稀有、300铜币，区间为0%—300%。两档均属资源流、适用S1—S6，`relatedIds`分别仅为自身的2217和2218。S5研习树节点142虽带2218引用，但其奖励类型及名称是随机开启一个稀有战法，不能登记为固定解锁赌徒Ⅱ；两档进入默认供货。

只读核对[官方公开配置包](https://web.sanguosha.com/220/h5_2/res/config/Config.sgs)的已有客户端缓存，解码成员`hd_roguelike.sgs`的SHA-256为`97dbdb465d902e771e575ed5165df3d193e1a689e3dae7ae67b9cb5033f18c72`。其`Root.Tactics`中2217的`pra1/pra2`为50/200、`relel`为`2217`；2218为0/300、`relel`为`2218`，与上述区间和各自关联一致。该配置没有随机步长、两档并持或与其他经济战法先后顺序的字段。客户端脚本中的数字2217、2218还用于协议版本判断，不能把数字命中当成这两项战法的执行证据；此次没有服务端算法证据。

以下均为明确的本地执行约定：

- 区间含两端，按整数百分比抽样，沿用现有确定性生成器的有界抽取。两档可各持有一份；同时持有时只采用Ⅱ的0%—300%区间，不把两个绝对区间相乘或相加。
- 先对本次战斗的基础铜币应用打秋风等收入百分比，并截去不足一枚的部分；再应用本次赌徒倍率并截整；收入加入原有本金后，按现有利滚利规则对总额计算一次利息。已持有的两档利息仍沿现有百分比求和规则，不因赌徒修改。
- 随机样本由征程种子、节点标识及遭遇序号独立派生，使用`battle-income`命名空间，不消耗商店、奖励或遭遇抽取的随机流。查询余额不入账，也不改变之后的抽样；零倍率只清零本次战斗收入，原有本金及正常利息保留。
- 直接铜币奖励、装备顶替返还和商店实际付款不经过这项随机倍率；它只接入现有战斗收入余额计算入口。常驻集市取得的战法沿现有实际持有状态进入该入口。
