# 移动版界程普

- 武将：`boundary:cheng-pu-mobile`，独立于经典程普、OL界程普和始程普。
- 主来源：[移动版官方武将页 367](https://www.sanguosha.cn/index.php/pc/hero-detail-367.html)，核对日期 2026-10-25。官网标题为“界·程普”；“疬火”为页面字形，游戏内采用通行名“疠火”。页面同时完整列出醇醪。
- 同版补充：[移动版 BWIKI 疠火](https://wiki.biligame.com/msgs/%E7%96%A0%E7%81%AB)。该页将技能明确分成①普通杀转火、然后判断该杀目标连环加伤，②任意火杀结算后按伤害总额的一半向下取整失血。它支持下述分支解释；不以混合旧版 Fandom 或 OL攻略替代官网当前技能。

## 规则与实现

疠火第一分支仅接受普通杀，转换为火杀，不增加目标数，也不把雷杀改成火杀。连环加伤属于此转换分支，天然火杀不自动享有它。代码依据原生用牌的公开转换链确认该来源，在直接伤害确定时读取目标的当前连环状态；加伤是这张杀的牌伤害，公开预测和替换伤害的牌层计算均采用同一值。连环传导继承原生最终伤害，传导本身不再次叠加疠火。官网没有另列“传导再加一次”的文本，此处遵循引擎已有连环传导合同，不把每个传导受害者当作该杀新指定的目标。

第二分支针对所有实际使用的火杀，包括天然火杀和疠火转换的火杀。在整个原生用牌和连环传导结束后，以 `DamageAppliedEvent.SourceCardUseResolutionId` 汇总该次用牌真实造成的所有正伤害，再按 `总额 / 2` 向下取整一次性失去对应体力。没有造成伤害、只造成1点或伤害被替换为失去体力的部分均不会凭空记作伤害；护甲吸收不把原生已造成伤害改成失血量。未借用旧版“转换杀造成过伤害就固定失去1”的逻辑。

失血收据和原生濒死孩子留在该次结算的原 `ProgramSkillFrame`，付款前已固定本次用牌、行动ID和实际伤害总额，付款事实在濒死公布前落盘。冷恢复返回后只完成尚未结算的孩子，不重复失血。既有用牌事件已包含归属ID，因此不新增用牌ID旁挂缓存或平行付款pending。

醇醪复用原生公开醇区与濒死酒能力。结束阶段无醇时，可选择任意正数张当前手牌中的任一属性杀（含已有寒冰杀）存为醇；不设置20张的人为上限。存牌先实际移动并等待孩子。濒死时移去一张醇，实际发出由濒死者作为使用者、以自身为目标的酒，适用原生濒死回复及返回规则。它既不是程普对目标直接回复，也不受OL轮次涨价、邻座弃杀收取或按醇属性附加收益的影响。同一次濒死内的发动次数沿用现有原生绑定资格。

## 验证范围

针对新增行为检查转换杀对连环直接目标的加伤只传导一次、天然火杀不加伤但仍按同一次用牌真实总额取整失血、1点伤害不产生付款；并用真实结束阶段存醇、疠火付款致自身濒死、本人实际使用酒、付款后/酒完成孩子冷恢复覆盖原帧返回。既有公开牌区、私密选牌和酒机制的通用边界由已有机制检查承担，不复制配置快照或跨角色矩阵。
