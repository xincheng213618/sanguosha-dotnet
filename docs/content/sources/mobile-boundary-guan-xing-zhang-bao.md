# 移动版界关兴张苞

- 独立武将：`boundary:guan-xing-zhang-bao-mobile`，技能 `boundary:fuhun-mobile`，规则集 `sanguosha-mobile`。
- 规则来源：[三国杀移动版官网：界·关兴张苞（137）](https://www.sanguosha.cn/index.php/pc/hero-detail-137.html)，核对日期 2026-10-25。该页完整列出父魂，两张**手牌**可转换为**普通杀**使用或打出。只有在自己的出牌阶段以父魂使用的杀实际造成伤害，才获得武圣、咆哮，持续至该实际回合结束。
- 此版本没有 OL 界父魂的同色闪限制，也没有“任意杀造成伤害”授技。取得的是武圣、咆哮基础技能；官网没有界武圣、界咆哮的追加效果，故复用 `classic:wusheng` 与 `classic:paoxiao`。

实现复用原生两手牌转换、响应和实体付款。伤害观察器使用现有 `subject: source`、`sourceSkillId`、`sourceViewAsId`，匹配伤害携带的父魂转换来源，再核对实际使用者为当前回合角色且当前阶段为出牌阶段。不会将其他转换、普通实体杀或决斗中纯打出的杀作为父魂杀授技来源。实际伤害后的授技通过现有 `grantTurnSkills`，显式指定 `actualTurnEnd`；由共享技能变更层管理来源、存续和到期，不新增人物运行时或并行状态。

行为检查覆盖普通杀不授技、真实父魂杀付款后伤害子窗的冷恢复、武圣实际转换与咆哮的实际超额用杀、回合结束失去授技，以及红色父魂杀可被黑闪响应和原生决斗中的两手牌打出不授技。测试只请求现有原生观察子窗，不引入新 pending 状态。
