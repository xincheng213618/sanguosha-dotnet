核对日期：2026-10-25。独立身份 `boundary:zhang-ni-mobile`，规则归属
`sanguosha-mobile` / `boundary-mobile`。

  明确怃戎为出牌阶段限一次，与其他角色进行镇压/安抚、反抗/归顺的四分支谋弈。

- [规则集的区域术语镜像](https://gltjk.com/sanguosha/rules/glossary/zone.html)：
  “角色的牌”通常指该角色拥有的手牌和装备牌，判定区内的牌不归该角色拥有。
  因此新版“获得其一张牌”使用 HE，不沿用旧经典实现的区域 HEJ；这是通用
  术语依据，不视为手杀当前版本另有专门 FAQ。

## 规则落地

双方的策略保存在原程序帧，第一份承诺不会在事件、日志或另一方提示中公开其
内容，待双方提交才揭晓。四种结果为：

| 本人 | 对方 | 后果 |
| --- | --- | --- |
| 镇压 | 反抗 | 本人对其造成1点伤害，然后本人摸1张牌 |
| 镇压 | 归顺 | 本人获得其1张手牌或装备牌，然后本人交给其2张牌；不足时交出当前全部 |
| 安抚 | 反抗 | 本人受到1点无来源伤害，然后本人摸1张牌 |
| 安抚 | 归顺 | 其交给本人2张手牌或装备牌；不足2张时整项改为跳过其下一个摸牌阶段 |

“你受到1点伤害”没有指定来源，使用既有无来源原生伤害流程，不把对手记作
伤害来源。矢志使用现有卡牌身份规则，不保留闪的原始使用或响应入口。

获得对方一张牌使用既有选取与移动指令；两张交牌按赠牌者自己的私密手牌和
装备实体暂存，确认后整批移动到对方手牌，保留移动及移出白银狮子的恢复子窗。
暂存和已付款状态始终属于原 `ProgramSkillFrame`，由类型化 movement/resume
返回承接；新事件均为标量，支付实体集合冻结并与真实移动记录对应。

牌不足的归顺分支不先交走剩余牌。跳过债以发行事实保存，在目标的真实下一个
摸牌阶段开始时消费并调用既有原生阶段跳过流程；整个回合被跳过不提前消费。
已发行义务不依赖原张嶷继续存活或持有技能，同一目标当前已有的下一阶段义务
在那个阶段共同兑现，后续摸牌阶段恢复正常。

规则/表示层 schema、存档格式和包版本继续由现有 catalog 与包常量管理。
行为检查覆盖四分支的原生伤害/摸牌/交牌、两张 HE 整批付款的暂存和已付款
冷恢复，以及技能失去后真实下一摸牌阶段的一次性跳过。
