# 移动版界曹丕：行殇、放逐、颂威

核对日期：2026-10-25。独立身份 `boundary:cao-pi-mobile`，规则归属
`sanguosha-mobile` / `boundary-mobile`，魏势力、男性、3体力。

## 来源与版本区分

- [移动版官网界曹丕当前页](https://www.sanguosha.cn/pc/hero-detail-282.html)：
  行殇为其他角色死亡时选择获得其所有牌或回复1点体力；放逐由目标本人选择
  摸 X 张后翻面，或弃 X 张后失去1点体力。X 为曹丕已损失体力值。
  当前页列颂威标题但缺正文，玩法明确说明其他魏势力角色的黑色判定可以让
  主公曹丕摸牌。
- [移动版 WIKI 的界曹丕颂威条目](https://wiki.biligame.com/msgs/%E9%A2%82%E5%A8%81/%E7%95%8C%E6%9B%B9%E4%B8%95)：
  补齐主公技正文及选择者，其他魏角色黑色判定牌生效后，由该角色选择是否令
  主公摸一张。此补充只覆盖官网缺失部分，与当前官网玩法一致。
- [区域术语规则集镜像](https://gltjk.com/sanguosha/rules/glossary/zone.html)：
  “角色的牌”是拥有的手牌与装备牌，判定区牌不归该角色拥有。行殇只取真实
  死亡清理中的 HE，不把判定区或武将牌上的牌混入。

本实现不沿用经典曹丕只有收尸的行殇，也不使用谋曹丕的颂标记、技能封锁或
追思规则。三个技能各有独立移动版 ID，颂威保留原生 Lord 标签与资格判断，
不把主公身份硬塞入普通角色。

## 结算与持续状态

行殇使用原死亡帧和原清理实体：有可取 HE 时才提供收牌，受伤时才提供回复。
两者均可用时由曹丕二选一。源区过滤是既有收尸指令的可选参数，省略时保持
已有历史定义行为；不改死亡清理账册或其他技能的收尸语义。

放逐在原伤害后程序帧记录本次 X 与已选的其他角色，之后不随嵌套结算中的
曹丕体力变化改写数值。目标实际本人看到私密的整批 HE 付款与摸牌选项；
弃牌分支必须付足 X 张，暂存后确认一次支付，原生移动和白银狮子等恢复子窗
返回后才失去1点体力。另一分支由原生摸牌请求返回，再执行翻面，保持官网
“摸牌并翻面”的顺序。所有 pending、发票与类型化返回留在原程序帧。

颂威只观察原生最终生效判定的黑色结果，检查实际判定者是其他存活魏角色。
Lord 来源按已有主公技及显式模式资格规则生效；由判定者本人作可选回答，
再调用主公的原生摸牌，不多加一次主公本人的同意窗口。

行为检查聚焦死亡二选一及 HE 来源过滤、判定者选择权与主公资格、放逐冻结 X、
原生摸牌后翻面，以及 HE 付款暂存/已付款子窗的代表冷恢复。schema、存档格式
和包版本继续使用各自 catalog 与包常量。
