# 移动版界于禁

- 独立武将 `boundary:yu-jin-mobile`，魏势力、男性、四体力，规则集 `sanguosha-mobile`，版本 `boundary-mobile`。只有技能 `boundary:jieyue-mobile`，不附加 OL 镇军、毅重，也不使用谋于禁的护甲节钺。
- 主来源：[三国杀移动版官网武将详情 363](https://www.sanguosha.cn/index.php/pc/hero-detail-363.html)，核对日期 2026-10-25。技能介绍完整列出结束阶段交给其他角色一张牌，然后收牌者选择各保留手牌与装备区一张、弃置其余，或令于禁摸三张。
- 同版交叉核对：[移动版 BWIKI：界于禁](https://wiki.biligame.com/msgs/%E7%95%8C%E4%BA%8E%E7%A6%81)、[节钺／界于禁](https://wiki.biligame.com/msgs/%E8%8A%82%E9%92%BA/%E7%95%8C%E4%BA%8E%E7%A6%81)，均列出相同身份版本，后者更新时间 2026-01-13。没有采用国战军令或普通于禁的节钺牌堆转换技能。

技能在于禁本人的实际结束阶段发动，原生 `selectTarget` 选其他存活角色，原生 `selectAndMoveOwnedCard` 从本人手牌或装备区交给其一张牌。真实交牌、收牌触发和卸下装备的子结算先返回，随后 `chooseOption` 由实际收牌者选择；不是于禁替其选择，也不把给牌当作弃牌。

留牌分支让收牌者分别用原生 `selectOwnedCards` 从本人手牌、装备区选一张保留，缺少某区时原生选择产生空绑定。有牌的区域保留恰好一张，收到的礼物也可作为保留手牌。补集节点核对两个保留绑定的实际选择者和原位实体，生成其当前可自弃 HE 的完整补集，再由原生 `moveBoundCards` 一次整批弃置。判定区不参与，不能把两区弃牌拆成两次顺序费用；禁弃限制继续沿用原生筛选和最终支付复验。

另一分支仅使于禁原生摸三张，不弃收牌者的任何牌。所有选择及支付均留在原技能帧，复用真实获得牌、整批弃牌及摸牌子窗和类型化返回，没有新增 pending 或用牌 ID 状态表。必要行为检查使用真实四人身份的多个人类操作者，验证收牌者选择、H/E 实体保留、缺失装备区、交出白银狮子的恢复先于选择、同批 HE 弃置、摸三张分支，并在已经支付的交牌、弃牌及摸牌子窗代表性冷恢复，证明不重复支付。
