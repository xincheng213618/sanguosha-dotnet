# 后期流套装2255

固定S5 [tactics.json](https://s.xiaochao.org/data/tactics.json)条目2255描述为“每过一轮则首张杀伤害+1”。同版manifest把它作为后期流组合效果，需求为2普通、2稀有、1史诗；9999价格条目不是可购买的组件。[原作者攻略](https://bbs.4399.cn/thread-view-tid-46871693)同样只写每过一轮、首张杀加伤，未提供首轮数值或独立计数起点的说明。

本地将“每过一轮”解释为本场已经结束的全局轮数：第1轮+0、第2轮+1、第3轮+2，之后依此增加。此起算解释属于本地约定，不把未明确的首轮数值作为官方事实。战斗中凑齐后按当前实际轮数生效，不另起一套购买后的轮数计数。

“首张”沿用原生每轮真实用杀声明序号：被闪避仍占首张，虚拟或转化使用同样计数，其他角色的回合不重置，进入新全局轮才重置。加成进入原牌的卡牌伤害层，多目标共享同次声明，铁索传播携带已经算好的伤害，不为同一张杀再加一次。公开伤害预测使用同一序号和全局轮数，查询不消耗首张资格。

套装通过原有取得流程派发，依赖本局实际持有的同流派四品质战法；只有同名程序、没有真实组合，或者处于普通对局时不能使用此组合效果。

## 组成战法缺口

为使生产货池能凑齐原需求，补入同一固定`tactics.json`的2373愈战愈勇Ⅱ（稀有300，从第2轮起杀伤害+1）、2374愈战愈勇Ⅲ（普通200，从第3轮起杀伤害+1）及2380战斗学习Ⅲ（普通200，从第3轮起出杀次数+2）。三条均无固定S5研习节点，沿用本地默认供货。组成战法按明确的“从第几轮”含当轮生效，独立叠加；这是各组成战法的原文门槛，与套装2255的每轮首杀成长分开。
