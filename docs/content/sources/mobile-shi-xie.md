# 移动版士燮

核对日期：2026-10-26。正式身份 `mobile:shi-xie`，群、男性、三体力，人物 `character:shi-xie`，版本 `mobile`，规则集 `sanguosha-mobile`，画像键 `mobile-shi-xie`。图库归入 **SP**；[移动Wiki身份栏](https://wiki.biligame.com/msgs/士燮)明确属于SP武将组7，不能沿用OL资料中尚未核定包分类的 `other`。

[官网197](https://www.sanguosha.cn/pc/hero-detail-197.html)与移动Wiki当前身份版一致，正式武将列表亦有该角色。身份规则的[避乱](https://wiki.biligame.com/msgs/避乱)在自己摸牌阶段开始时检查其他角色到自己的距离为1，可以放弃正常摸牌，其他角色到自己的距离增加当时存活势力数；[礼下](https://wiki.biligame.com/msgs/礼下)为锁定技，其他角色结束阶段若士燮不在其攻击范围中，二选一让自己摸一张或当前角色摸一张，然后入距离减1。Wiki人物版本oldid27969，技能页分别oldid29205/19018；没有发现已上线新改版与官网正文冲突。

新增 `mobile:biluan`、`mobile:lixia`。现有OL避乱在自己结束阶段弃牌，OL礼下则有自己一张、当前角色两张、回复一体力且可选两项，均不等价。官网“玩法介绍”的双方均摸牌与其技能正文和移动Wiki互斥两项不一致，采用技能正文；国战装备数增距及准备阶段礼下也属于另一规则版本。

避乱采用原生 `drawPhaseStarting` 的完整正常摸牌替代，放弃全部正常摸牌数，包括既有额外数量修正；不是固定减二，也不将已进入的摸牌阶段改写为整阶段跳过。+X在结算时按当前有效存活势力去重计算一次，随后不随势力消失追溯变化。礼下以原生DSL选择互斥的一牌受益者，随后同一人物指令从真实结束阶段父帧取当前角色，沿 `BeginOperationProgramDraw` / `NativeDrawOutcome` 发起和接收原生摸牌，排空原帧的移动及其他子链后才发行-1。不会把普通结束阶段借作伤害专用的eventSource参与者上下文。

永久入距离只用人物标量事实与既有 `ProgramDistanceRule` 加法层，计算方向为其他角色到士燮；士燮到其他角色的方向不受改变。累计量保留正负，最终实际距离仍由原生数值层投影到至少1。无新的全局回合状态、并行pending或摸牌副本；原生摸牌请求回执或实际摸牌后发行的标量事实证明收益已发行后，窄化失技/死亡续接只结清这次原帧，不授予新的触发。事实不包含私有牌实体ID。历史无期限距离事实不随失技清除，沿项目现有已发行义务语义；当前同版正文未给专门失技FAQ，此项记录为实现解释。

独立定向检查覆盖真实有向距离资格、五张完整正常摸牌的放弃、两个互斥的一牌收益、原生摸牌子返回后才累计减距，以及已发行收益子链失去礼下后的原帧续接和代表冷恢复。未为纯资料增加重复定义快照。
