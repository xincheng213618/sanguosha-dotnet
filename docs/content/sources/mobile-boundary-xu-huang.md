# 界徐晃（移动版）

核对日期：2026-10-25。完整人物为魏势力、男性、4体力，技能为断粮、截辎。

- [三国杀移动版官网武将页（徐晃，275）](https://www.sanguosha.cn/pc/hero-detail-275.html)：断粮可将黑色基本牌或装备牌当兵粮寸断；对手牌数不少于自己的其他角色使用兵粮寸断无距离限制。页面隐藏技能正文明确截辎为锁定技，其他角色跳过摸牌阶段后自己摸一张牌。
- [移动版 BWIKI 界徐晃](https://wiki.biligame.com/msgs/%E7%95%8C%E5%BE%90%E6%99%83)（页面最后更新 2025-11-28）、[断粮细则](https://wiki.biligame.com/msgs/%E6%96%AD%E7%B2%AE/%E7%95%8C%E5%BE%90%E6%99%83)：与官网完整规则相符。检查官网后续公告，未发现替代这一技能定义的修订。

移动版与本仓库 OL 界徐晃不同：不使用“本回合未造成伤害”的无距离条件，不设置“辎”标记或额外摸牌阶段；截辎不允许指定受益人，且不响应自己的跳过摸牌。

黑色基本牌、装备牌的转换沿用原生 view-as；距离豁免同时适用于印刷兵粮和转换兵粮，仍执行正常目标、判定区和重复延时锦囊资格。原生付款后复验时将同一张已付款手牌计回使用前手牌数，装备付款不计入手牌。截辎使用真实 drawPhaseSkipped 窗口，按每次实际跳过结算一次原生摸牌。
