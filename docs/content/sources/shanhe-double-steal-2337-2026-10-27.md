# 双掠2337

固定[战法表](https://s.xiaochao.org/data/tactics.json)的2337为双掠，原文“你使用的【顺手牵羊】额外结算一次”，稀有度2、300铜币、锦囊流9，适用赛季包含S5且未弃用。所用快照SHA-256为`209ce819d57fc8985308376ecc24fe12d2c3ca94dec75b775578f34543774c0e`。固定[S5研习树](https://s.xiaochao.org/data/tactic-tree.json)无对应2337节点，沿用无固定节点进入本地默认货池的约定。

在原生使用顺手牵羊完成声明时，双掠为原CardUse追加一次效果结算。额外效果重新进入原生无懈与目标牌选择流程，每次至多取得目标一张实体牌；若目标已无可取牌，则按原生无牌流程结束。同一原牌只支付一次、只结束一次，不另开新用牌，不在用牌结束时静态补发一张牌。

额外效果复用已有CardUse上的山河图普通锦囊额外轮：原锦囊流套装仅处理伤害锦囊、双掠仅处理顺手牵羊，两者牌种互斥。奋梓仍持有其原有的独立已付额外效果，因此双掠与真实奋梓支付可以合计结算三次。源文同名的本地无双2337也使用原生额外效果，本实现保留山河图自己的授予与来源资格。
