# 动员令2203

固定S5[战法表](https://s.xiaochao.org/data/tactics.json)给出动员令2203：队友流、史诗、500铜币，原文为“队友阵亡后，下一轮开始时复活队友”。本期没有固定山河册节点，进入默认供货。官方配置对应技能13191、资源键`ZhanChangJiJiu`；`pra1=1`没有自带体力标签，不能单凭该字段推出复活体力。本批补入[源图](https://s.xiaochao.org/data/images/e64e62c2b0f244179442c583.png)至`src/CardGame.Wpf/Assets/Shanhe/2203.png`：PNG格式、116×116、20519字节，完整SHA-256为`e64e62c2b0f244179442c583f16aac34331c5e847fe8aec3705a3402fdf3db3b`。

用户明确补充本地规则：按复活时的当前最大体力满血复活，不额外获得手牌；恢复正面、解除横置并清除酒效果。复用通用生命恢复边界，不视作回复体力，不重做初始派牌、装备或武将技能次数。

只在山河图配方与模式中由存活持有者发动，筛选真正完成阵亡、当前仍死亡的公开同队其他角色；不复活持有者自己或敌军。以原生全局轮次事实和死亡事实判断，在下一真实新轮处理，普通的其他角色回合及额外回合不提前复活。战中取得该战法时，已经阵亡的队友也可在取得后首个真实新轮受益；没有额外的单局次数限制，之后再次阵亡可再次等待新轮。

复活名单和逐席游标置于原始技能帧。真实翻面、解链及其观察技能子流程结算后才推进下一名；已处理角色不会因子流程返回而重复复活。复活不插入额外回合，原座次继续经过自然回合账本。
