# 移动版界郭淮

- 独立武将 `boundary:guo-huai-mobile`，技能 `boundary:jingce-mobile`，规则集 `sanguosha-mobile`。
- [三国杀移动版官网：界·郭淮（392）](https://www.sanguosha.cn/hero-detail-392.html)，核对日期 2026-10-25。精策在结束阶段检查此实际回合内因使用或打出进入弃牌堆的牌数量，达到自己当前体力值即可选择摸两张牌。
- 同版 [移动版 BWIKI：界郭淮](https://wiki.biligame.com/msgs/%E7%95%8C%E9%83%AD%E6%B7%AE)，2025-10-21 更新，技能文字与官网一致。结束阶段指本人的结束阶段；统计对象没有“你使用或打出”的限制，故本实际回合其他角色的真实响应实体同样纳入，例如一张杀及目标的一张闪各计一张。不能套用 OL 界精策按花色增加手牌上限、按类型数摸牌的规则。

使用原生 `NativeTrueUseProcessingEntry` 与真实用牌清理批次核准使用、闪和无懈实体；纯打出及多材料响应从原生 `ProgramResponseCompletionReturn.NativeCosts` 获取实际付款完成记录。只有确实从处理区进入弃牌堆的实体才记一张，虚拟零材料牌不凭空计数，判定牌、重铸、普通弃置、装备安装及替换装备也不作为使用或打出实体清理。同一条真实移动序号只记录一次，成功取走而未进入弃牌堆的材料不计；回收后重新使用、再次真正入弃的实体按新移动序号计数。

计数事实仅含实际回合、原生父帧、动作与移动序号等不可变标量。精策本身在原结束阶段技能帧记录核准条件，然后使用共享原生 `draw` 摸两张，沿用原帧的 typed 摸牌子返回，不增加人物 pending 或付款状态。
