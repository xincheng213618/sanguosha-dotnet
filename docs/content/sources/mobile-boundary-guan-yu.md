## 完整技能

**武圣**：你可以将一张红色牌当【杀】使用或打出；你使用方块【杀】无距离限制。

**义绝**：出牌阶段限一次，你可以弃置一张牌，然后令一名其他角色展示一张手牌。若为黑色，其本回合非锁定技失效且不能使用或打出手牌，你本回合对其使用的红桃【杀】伤害 +1；若为红色，你获得此牌，然后你可以令其回复 1 点体力。

## 实现

新武将 `boundary:guan-yu-mobile` 完整复用现有 `boundary:wusheng`、`boundary:yijue`。武圣可使用手牌或装备区的红色牌，方块距离策略作用于真实有效花色；义绝沿真实弃置、目标本人选手牌、公开展示和颜色分支执行，黑色分支的技能压制、手牌禁用与来源定向红桃杀增伤均持续到实际回合结束，红色分支先真实获得再可选回复。

现有 `BoundaryGuanYuChecks.ExtraPlayQuotaAndNamedHeartBenefit` 覆盖实际额外出牌阶段的阶段次数、同来源增伤不叠加及冷恢复；共用禁手牌和非锁定技能压制机制继续沿原有覆盖。本次纯人物配置不重复新增规则或人物矩阵。

武将及当前牌池注册顺序 60400，版本为 `boundary-mobile` / `sanguosha-mobile`。
