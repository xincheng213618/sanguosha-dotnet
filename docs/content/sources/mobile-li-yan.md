# 移动版李严

核对日期：2026-10-26。正式身份 `mobile:li-yan`，蜀、男性、三体力，版本 `mobile`，规则集 `sanguosha-mobile`，画像键 `mobile-li-yan`。

[移动版官网李严218](https://www.sanguosha.cn/pc/hero-detail-218.html)完整HTML与[移动版Wiki李严](https://wiki.biligame.com/msgs/李严)当前身份正文一致：督粮出牌阶段限一次，取得其他角色一张手牌后，令其私看牌堆顶两张并取得基本牌，或令其**下个摸牌阶段**额外摸一张。腹鳞让本回合获得的牌在弃牌阶段不计入手牌限制。未发现已上线的新改版与上述正文冲突。

腹鳞完整复用 `classic:fulin`。督粮新增 `mobile:duliang`，私取真实手牌及牌堆顶两张的私看/分类取得复用原生DSL；期限与存量经典配置明确分开。`classic:duliang` 使用下回合修正，会在下回合开始施加并按回合结束到期；当前移动版不能用它冒充下个真实摸牌阶段。

移动版发出绑定原技能帧、来源、受益人与一张数量的公开标量许可；下一条该受益者的真实Draw阶段token把许可分配给该阶段，正常和插入Draw沿同一原生数量冻结入口使用。被跳过而未产生真实Draw token的阶段不消耗；先发生的插入Draw优先取得，多次许可叠加，之后自然Draw不再次受益。权益已经发出后，不依赖李严仍存活或仍持有督粮。整个流程无新的全局回合容器或并行pending对象。

跳过的范围按实际进入阶段区分：回合开始或判定阶段已确认跳过摸牌时，流程不进入Draw，许可保留；若已进入Draw，再于 `drawPhaseStarting` 窗口付费替代、跳过或替换正常摸牌，则这个已到来的摸牌阶段已经接收许可，之后不会转移到再下一阶段，即使本阶段最终没有正常摸牌。官网及当前移动Wiki正文没有该组合的专门FAQ；这是依照“下个摸牌阶段”与仓库实际阶段开始语义采用的裁定，不能表述为所有跳过摸牌均保留。

定向检查采用两个实际出牌阶段分别督粮、真实手牌付款后叠加许可，并移除原技能；覆盖进入前跳过摸牌时保留、下一真实Draw只用一次、插入Draw优先而自然Draw不再增加，以及Draw起始窗付牌跳过时已到期且不顺延。许可、实际Draw起始选择和付牌替代窗口均检查接受命令冷恢复。
