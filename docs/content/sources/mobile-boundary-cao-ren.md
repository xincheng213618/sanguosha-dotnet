# 界曹仁（移动版）规则来源

核对日期：2026-10-25。魏势力、男性、4 体力，移动版身份场。

- [移动版官网武将页：界曹仁](https://www.sanguosha.cn/index.php/pc/hero-detail-310.html)：据守为翻面并摸四张牌，然后选择手牌，装备牌改为使用；解围的成本明确为手牌，后续可以移动场上的一张牌。玩法说明还明确写有解除延时锦囊。
- [移动版 Wiki：界曹仁](https://wiki.biligame.com/msgs/%E7%95%8C%E6%9B%B9%E4%BB%81)：身份场两技能与官网一致。Wiki 据守表述为“摸四张牌并翻面”，官网为“翻面并摸四张牌”；本实现沿用官网结算顺序。没有把国战的势力数摸牌或谋曹仁的护甲技能混入本版。
- 定向检索未发现与上述移动版身份场规则冲突的后续官方修订。

## 完整技能

**据守**：结束阶段，你可以翻面并摸四张牌，然后弃置一张手牌；若此牌为装备牌，改为使用之。

**解围**：你可以将装备区里的一张牌当【无懈可击】使用；当你的武将牌从背面翻至正面时，你可以弃置一张手牌，然后移动场上的一张牌。

## 实现边界

- 据守使用独立 `boundary:jushou-mobile`，以既有 `turnOver` 真正翻转武将牌。既有 `boundary:jushou-current` 使用固定设置为背面朝上的节点，不能覆盖结束阶段原本已背面朝上的移动版情形；旧版保持原状。翻面引起的解围子结算完成后，原据守继续摸四张牌并支付成本。
- 据守选择范围为自己的手牌；非装备牌按真实弃置付款，装备牌走 `BeginCardUse`、Processing 以及原生装备使用窗口，既不是从弃牌堆捞回，也不是直接移动装备替代使用。
- 解围使用独立 `boundary:jiewei-mobile`，保留装备区转无懈的原生视为技。翻正面后的成本限定手牌，付款等待移动子结算；不允许用装备区的牌代付。
- 付款后选择不同的两个存活角色，移动前者装备区或判定区的一张牌至后者对应区域；源或目标都可以是曹仁。复用 `selectedTargetCorrespondingZone` 的真实实体移动、判定区合法性及装备空槽检查，不替换已有装备。
- 原 `boundary:jiewei-current` 的装备移动及 HE 成本行为保留原版本；移动版没有共享运行时改动，也不增加独立待决状态或重复付款路径。

武将及当前牌池顺序 60200，解围技能顺序 60201，据守技能顺序 60202；版本为 `boundary-mobile` / `sanguosha-mobile`。新增代表检查用真实据守从背面翻正，覆盖解围手牌成本、真实判定牌移动和付款后的冷恢复，并回到原据守完成摸四张与装备实际使用。
