# 酣战2111、蓄力箭2242

固定[战法表](https://s.xiaochao.org/data/tactics.json)快照的SHA-256为`209ce819d57fc8985308376ecc24fe12d2c3ca94dec75b775578f34543774c0e`。两项均为稀有度2、300铜币、锦囊流9，适用赛季包含S5且未弃用。

|源ID|战法|原文|
|---|---|---|
|2111|酣战|与你【决斗】的角色每次需打出两张【杀】|
|2242|蓄力箭|你使用的【万箭齐发】其他角色需要打出2张【闪】来响应|

固定[S5研习树](https://s.xiaochao.org/data/tactic-tree.json)均无对应节点，沿用无固定节点进入本地默认奖励、集市池的约定。两项复用原有无双模式同源条目的`minimumResponseCount`定义，分别限定决斗/杀与万箭齐发/闪；只有实际持有的山河图技能参与计算，不借用无双模式的持有资格。

酣战在原生决斗中按每次应答的对手计算要求。因此持有者主动使用决斗或被决斗时，都由另一方每组打出两张杀，持有者仍正常应答一次；不是给被决斗者加一条必须自己支付双杀的目标策略。数量与无双等既有同类策略取最大值，不相乘。原决斗持有响应轮次和每张杀的实体付款，任何一组不足两张仍按原生失败应答结算伤害。

蓄力箭按万箭齐发的每个目标分别建立原生攻击时冻结要求。复用该攻击的`RequiredDodgeResponses`和`SuccessfulDodgeResponses`，普通实体闪、响应子窗口返回、八卦和护驾的成功闪均汇入同一完成入口。第一张真实响应只推进一次游标，要求未满足时回到原群体牌的同一目标；两张齐全才结束这个攻击，第二张不足则正常受伤。购买发生在目标已发行应答要求之后，不改变该目标的数量；后续尚未发行的目标立即使用新取得的战法。
