# 蔡邕·移动版

核查日期：2026-10-26。普通移动身份版，群、男、3体力，乱世英杰2017。不是乐蔡邕。

## 来源与版本差异

- [移动官网人物232](https://www.sanguosha.cn/pc/hero-detail-232.html)提供身份与经典立绘；其辟撰仍写“使用黑桃牌后”。
- [移动BWIKI蔡邕，固定版本27137](https://wiki.biligame.com/msgs/index.php?title=蔡邕&oldid=27137)及[辟撰，固定版本20380](https://wiki.biligame.com/msgs/index.php?title=辟撰&oldid=20380)明确为“使用♠牌指定目标后”；通博为摸牌阶段结束时交换等量书、四花色后必须分给其他角色。
- [2020年移动官网攻略](https://www.sanguosha.cn/pc/guide-info-39.html)是旧“使用后”正文，并说明通博能以手牌或装备交换，书公开、分发可分给多人、打出杀不触发。它不能证明当前BWIKI时机文字与旧正文等价。

本实现采用当前移动BWIKI的指定目标后时机：`mobile:bizhuan`在真实目标最终确定窗口、原生效果执行前存书；原有`classic:bizhuan`继续在使用完成后存书。两来源的时机差异在此明确保留，不声称官网已更新为新文字，也不以旧攻略覆盖当前移动技能页。没有直接“指定目标”的打出或响应不会凭使用完成补触发。

## 实现

辟撰复用真实堆顶移牌、公开持久区、4张上限、拥有区数量的手牌上限。自己的多目标牌按现有actor候选规则每次使用产生一个候选；其他角色对本人指定的黑桃牌仍按现有target候选规则。无需新指令或运行时状态。

通博的交换和强制分发行为与已有机制一致；因其必须显式引用对应的书来源，本包使用`mobile:tongbo`引用`mobile:bizhuan`，而不让经典通博误消费经典书来源。两项操作和原帧恢复完全共用原生公开堆机制。

新增检查只覆盖移动版提前存书、经典完成时机保留，以及移动来源的真实等量交换和代表冷恢复。已有公开堆的移牌、分发和隐私检查继续复用。
