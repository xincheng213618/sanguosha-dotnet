## 规则与版本差异

OL祈禳依赖使用装备、普通锦囊追加目标及延时锦囊的未来看顶额度，OL羽化还有准备阶段看顶入口。当前移动版没有这些规则；移动技能均独立声明，不引用 `ol:qirang` 或 `ol:yuhua`。

祈禳按实际装备入区的每个实体结算，使用装备、他人放置装备等实际入区路径均可触发；只移动到手牌或使用装备被取消，不产生入区权益。取牌沿实际牌堆向手牌移动，所得必须是实际锦囊实体，包含普通、延时锦囊。没有可取得锦囊时不虚造实体。

“使用时”摸1落在原生 `cardUseCommitted`，先真实支付该实体，再在牌效果前摸1；并非结算完毕后摸牌。原生响应使用的无懈也经过该入口，纯响应、零实体和把此实体当其他牌使用不获奖励。匹配来源、实际实体、印刷牌名与本次有效牌名；另一张同名锦囊不能共享距离或摸牌。无目标使用同样不依赖有效指定目标的数量。

官网仅说“此锦囊牌”，BWIKI说“以此法获得的锦囊牌”，均未明确实体离手再取得时的标识期限。本实现采用**连续持有**裁定推论：从该次祈禳取得后至首次离开本人手牌有效；正式使用在付款前冻结本次原生动作，因此本次正常离手付款不会抹去已经发行的距离许可与摸牌。实体离手后经其他方式重新取得不复用旧权益。此期限是实现裁定，不能声称来源明确写有该限制。

羽化弃牌限额豁免复用已有按实际非基本牌种类授予的原生上限豁免；不把锦囊、装备视作必须弃置的数量。结束阶段入口比较当时真实手牌数与体力值，只有严格大于才观看；观看张数冻结为当前手牌三大类别（基本、锦囊、装备）的不同种数，延时与普通锦囊属于同一类别。没有准备阶段入口，不承接OL的延时锦囊债务。观看、任意数量置顶和其余置底都沿既有 `ProgramTopReorder` 的私密原帧和实际牌堆操作。
