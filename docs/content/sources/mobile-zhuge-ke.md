- [移动版官网诸葛恪80](https://www.sanguosha.cn/index.php/pc/hero-detail-80.html)：完整HTML列出傲才与黩武。傲才回合外按实际基本牌需求观看牌堆顶两张并可使用、打出；黩武在攻击范围内选择其他角色，按其体力支付至少一张牌并造成一点伤害，目标因此进入濒死则自己失去一点体力且本回合不能再发动。
- [移动版Wiki诸葛恪](https://wiki.biligame.com/msgs/诸葛恪)，2026-01-13更新：傲才始终两张；黩武明确在本次濒死结算结束后支付失去体力及回合失效，没有“被救回后存活”条件。本次采用身份正文，不混用国战限定军令版本。

两项能力与现有 OL 版存在实际差异，分别登记 `mobile:aocai`、`mobile:duwu`；不是对同规则技能重新命名。OL 傲才空手改看四张，移动版空手仍看两张。OL 黩武只在目标被救回并存活后罚体力，移动版只要该次伤害实际导致目标进入濒死，就在本次濒死完整返回后处罚，即使目标已经死亡。

傲才仍使用原 `privateTopBasicRequest` 卡牌政策、原 `RequestedDeckBasicFrame` 以及原始响应或求桃请求账单。版本条件只改变原生观看张数；少于两张的非空牌堆不额外补足。未选牌保持原顺序与区域，所选牌通过原需求实际使用或打出，不先加入手牌；私看内容只发给发动者。原需求游标、原提示及真实付款继续沿既有 typed return 和只付款一次合同维护。

黩武复用原 `discardTargetHpCardsAndDamage`。原帧冻结目标体力、距离与攻击范围，选择完整的本人手牌或装备费用，实际弃置后才能发出一点伤害；已付费用及其回复、移动孩子不重新收费。移动版条件只把罚体力资格改为原帧捕获的本次濒死入口，而非其他伤害或其他孩子的濒死。罚体力和失效账单继续登记在原始帧与本实际回合，下一实际回合恢复可发动。

不复制傲才、黩武整套运行时，不新增 effect、帧字段、pending 容器、全局版本或测试开关。最小固定身份场景保留实际费用移动孩子与罚体力孩子的冷恢复，再以空手回合外真实杀响应证明只私看两张并真实打出其中的闪，最后检查实际回合失效范围。
