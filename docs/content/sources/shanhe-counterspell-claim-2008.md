# 草船借箭2008

[固定S5战法表](https://s.xiaochao.org/data/tactics.json)记录2008为“草船借箭”，稀有、300铜币、锦囊流，原文为“【无懈可击】获得抵消的锦囊牌”。适用S1—S6，`relatedIds`仅为2008，未弃用；本期研习树没有固定节点，加入默认供货。沿用[源表原图](https://s.xiaochao.org/data/images/a2a5de49b3dc452697627648.png)及已有2008缓存，23409字节，SHA-256为`a2a5de49b3dc452697627648efe4b911aff2ad147f46f8c6ebce603637726f71`。

结算沿用原生无懈链：整条链结束、原锦囊效果最终确被抵消时，由最终使其抵消的响应者取得原牌；偶数次反无懈恢复原效果时不取得。对有独立目标窗口的锦囊，第一处满足条件的抵消立即移动仍在处理区的全部原实体，后续目标照常结算。两张实体转化出的锦囊也取得这两张原材料，不生成同名替代牌；没有实体的虚拟锦囊不会生成牌。以上链归属与多目标材料处理是本地明确的执行合同，简短来源文字没有给出更细的服务端算法。

即时获得采用原锦囊`CardUseFrame`上的类型化凭据，绑定原使用动作、原材料、最终无懈窗口／层数／响应者及技能实例。凭据在移牌前登记；实体直接从处理区进入实际响应者手牌，之后的真实获得牌子结算挂在原无懈窗口上，结束后原位续接。后续目标继续通过原使用帧表示这张已转移的牌，原使用完成时不再次移动或领取。没有等待整个锦囊结束，也没有从弃牌堆补领的替代路径。新增事实逐实体保存标量移牌证据，不向事件观察者暴露可变集合；原使用帧上的实体列表对构造与`with`赋值统一复制为只读集合。

该新战法仅在山河图模式及其真实战斗配置同时成立时生效。普通身份局即使实际持有同一程序也不会启用；既有无双模式同名能力继续走原有流程。

来源没有排除延时锦囊。判定阶段的乐不思蜀、兵粮寸断和实体闪电由当时的原生无懈窗口持有，原使用帧已结束；其凭据因此留在该无懈窗口上，保留真实`DelayedReturn`父帧、回合及阶段身份。最终抵消后直接将当前判定区实体移入手牌，获得牌孩子完成后才继续后续判定及自然回合。已被取得的实体闪电不再转移到下一名角色判定区；其无命中结果不包含下一目标。无实体的原始使用闪电附件仍沿既有传递流程，不生成实体牌。判定区中的转化延时锦囊只取得当时实际持有的实体，不追回上个使用阶段已正常离开的其它材料。

定向检查使用真实常驻集市300铜币购买，覆盖未持有基线、独立多目标决斗第一名被抵消后第二名继续受伤、三层真实无懈链最终归属、两层反无懈不领取、两张原实体转万箭后立即完整取得、真实获得牌子窗口原位返回，以及普通身份隔离。延时检查先经真实用牌放置乐不思蜀及兵粮寸断，再自然结束回合进入其持有者的判定阶段，逐张无懈取得并继续后续判定和出牌；实体闪电同样在下个自然回合无懈取得且不传递。反无懈恢复的乐不思蜀仍走实际判定和正常离开判定区流程。每张无懈响应牌和原锦囊材料均检查实际付款与唯一完成移动。检查不执行存档恢复或战后凭据流程。
