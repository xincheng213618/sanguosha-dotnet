# 拔刀术2188与拔刀术Ⅱ2189

固定S5的[tactics.json](https://s.xiaochao.org/data/tactics.json)记录：拔刀术2188为史诗、500铜币，“若上一轮你未造成任何伤害，则你本轮造成的所有伤害+1”；拔刀术Ⅱ2189为稀有、300铜币，“若上一轮造成的伤害小于3，则你本轮造成的所有伤害+1”。两者均为后期流，本期研习树没有固定节点，进入默认供货。沿用已有缓存2188、2189图标，来源图为`728e6946406f27397fcf439e.png`。

沿现有无双同源规则，两项均从第二个实际全局轮次起判断，第一轮没有“上一轮”资格。只按上一完整轮次的真实公开伤害完成事实汇总来源：技能和反伤归给其实际伤害来源，链传播各实际受伤者都计入。统计量复用当前Core与原无双拔刀术的正`DamageApplied.Amount`；护甲是该次伤害的支付方式，不从已应用伤害量中扣除，即使体力未减也仍按正伤害事实计数。失去体力与真正被阻止而没有正伤害完成事实的请求不计。

伤害条件和公开预测共用同一公共事实计算，不另存活动状态。每轮资格不因本轮已经造成伤害而变化。加成覆盖持有者的卡牌和技能伤害，只在根段加一次；后续铁索传播继承已确定的根伤害，不在每名传播目标再加一次。两档各自限获得一份，满足各自条件时可同时生效。
