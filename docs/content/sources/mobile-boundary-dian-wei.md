# 界典韦（移动版）规则来源

核对日期：2026-10-25。魏势力、男性、4 体力，移动版身份场。

- [移动版官网武将详情263](https://www.sanguosha.cn/pc/hero-detail-263.html)只列强袭，成本为失去体力或弃武器，目标在攻击范围内，每名角色每出牌阶段限一次。
- [移动版 Wiki：界典韦](https://wiki.biligame.com/msgs/%E7%95%8C%E5%85%B8%E9%9F%A6)（2025-12-18 更新）、[强袭技能页](https://wiki.biligame.com/msgs/%E5%BC%BA%E8%A2%AD/%E7%95%8C%E5%85%B8%E9%9F%A6)与官网一致。定向检索后续移动官方调整公告，未发现取代该规则的修订。

## 完整技能

**强袭**：出牌阶段对每名角色限一次，你可以失去 1 点体力或弃置一张武器牌，然后对攻击范围内的一名其他角色造成 1 点伤害。

## 实现边界

移动版 `boundary:dian-wei-mobile` 使用独立 `boundary:qiangxi-mobile`。它没有 OL 现有版本的狞恶，也不采用“受到 1 点伤害”、无距离限制、出牌阶段总共两次或同一回合不能重复目标的限制。

失体力与弃武器为两项原生付款入口，共用同一技能的每目标出牌阶段账本。薄操作 `ConsumeMobileQiangxiTarget` 通过既有 `SkillUsageScope.Phase` 和 `SkillUsageConsumedEvent` 记录，选择器用同一原生账本过滤已使用目标；新出牌阶段按既有阶段作用域重置。人物不持有另一份回合或阶段状态。

失体力走原生 `loseHp`，不能被记为受伤或触发卖血技能；弃武器允许手牌与装备区，真实弃置后先完成移动子结算，再对冻结目标造成伤害。已付成本保留在原技能帧和 typed return 上，冷恢复不能重新失体力或弃武器。

武将及当前牌池顺序 65300，强袭技能顺序 65301。新增必要检查覆盖两个付款分支共享目标次数、第三名不同目标仍可用、真实失体力和武器付款孩子冷恢复，沿用共用伤害与阶段次数机制。
