# 曹真·普通移动版

核对日期：2026-10-25。魏、男、4体力。

- [移动版官网完整图鉴174](https://www.sanguosha.cn/pc/hero-detail-174.html)，包括完整技能项。
- [普通移动曹真 BWIKI](https://wiki.biligame.com/msgs/%E6%9B%B9%E7%9C%9F)，标示2024-02-24更新；普通“经典”栏与官网一致。

司敌有两个独立时机：本人使用闪，或其他角色于本人实际回合内使用闪后，可以将牌堆顶一张牌置为“钤”；其他角色实际出牌阶段开始时，可以移去一张钤，令其本阶段使用杀的次数上限-1。本人回合外使用闪也符合第一项；他人回合内其他人使用闪不符合。每次真实闪独立获得机会，移去钤不是弃置手牌，也不附带新杀或伤害。

`mobile:sidi` 复用真实 `cardResponseAccepted` 事实、原生看顶牌和持久区移动。钤以原生公开持久区保存，展示名为钤；支出从其原实体来源移动至弃牌堆，当前原程序帧在其真实移动子结算返回。次数修正由付款时发布的标量事实绑定当前实际出牌阶段标识，而非全回合；支付后失去技能不会撤销该已发阶段效果，也不会在恢复时再支付一张。

没有复用 `classic:sidi`，因为本地该版本是弃装备牌限制颜色，并可能视为使用杀；也没有复用界曹真的秘密目标版本。[2021-12-13界曹真调整公告](https://www.sanguosha.cn/pc/news-detail-1126.html)明确针对界版，不能覆盖当前普通版的存钤和杀次数上限规则。检索未发现后续公告替代普通版该正文。
